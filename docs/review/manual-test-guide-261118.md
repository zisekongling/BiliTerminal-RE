## H01 安卓 8.x 上打开蓝牙伪装页不再崩（崩溃 #370）

- **怎么做**：在 Android 8.0/8.1 的设备上，从设置里进「蓝牙伪装」页面（伪装成蓝牙配对界面的那个浮层）。
- **应该看到**：页面正常弹出、底下页面透出来，可以照常关掉；不再闪退。
- **不算 bug**：开着自动旋转的设备上，浮层会跟着设备转（改前是锁死不转的，这是本轮为绕开系统限制**有意**的取舍）；浮层内容本身与改前一样。
- **AI 断言**：`adb logcat -b crash -d | findstr /C:"Only fullscreen opaque activities"` 应为 0 行；`adb shell pidof com.RobinNotBad.BiliClient` 在进出该页面前后不变。
- **预计**：1 分钟

## H02 我的页面快速进出不再崩（崩溃 #367）

- **怎么做**：登录后进「我的」页面，**数据一出来就立刻按返回**，连续做 10 次（头像/昵称刚显示的那一下最危险）。
- **应该看到**：全程不闪退；偶尔一次头像没加载出来属于正常（页面已经关了）。
- **不算 bug**：返回太快时头像空白、不显示占位图，不是 bug。
- **AI 断言**：`adb logcat -b crash -d | findstr /C:"cannot start a load for a destroyed activity"` 应为 0 行。竞态窗口很窄，机器只能靠「跑完没有这条」判断，**人判**：10 次里有没有闪退。
- **预计**：2 分钟

## H03 表情连续进出多个页面不崩、不缺图（崩溃 #366 / #368 / #369 / #371）

- **怎么做**：① 打开任意视频的评论区，等表情加载出来；② 连续进出一个带表情的页面 10 次（评论区 / 动态 / 私信任选，最好三个都走一遍）；③ 顺手在弱网（关一会儿 Wi-Fi 再开）下再刷一次评论区。
- **应该看到**：表情图正常显示、不闪白；进程不崩。
- **不算 bug**：弱网下表情比文字晚出现几秒是正常的；个别表情因源站 404 缺图，不计入本条。
- **AI 断言**：`adb logcat -b crash -d | findstr /C:"Cannot recycle a resource while it is still acquired"` 应为 0 行。
- **预计**：3 分钟

## H04 视频详情页表冠一格滚一行（反馈 #197，OPPO Watch 4 Pro 那类设备）

- **怎么做**：用表冠在视频详情页的**简介区**滚动，前后各转 10 格；再切到评论页转 10 格。
- **应该看到**：一格滚一行左右，能停在任意位置；不再出现「一转就跳过大半页」。
- **不算 bug**：接了蓝牙鼠标的手表上滚一格约等于一行（改前框架给的是十几行，这是**刻意**的行为变化）；滚到最顶/最底会有边界回弹。
- **AI 断言**：人判——只有手感，机器读不出来。日志里 `RotaryEncoderSupport` 的失败行应不再出现「本页找不到可滚容器」。
- **预计**：2 分钟

## H05 详情页三页来回切后表冠仍作用在当前页（反馈 #228，小米手表）

- **怎么做**：进视频详情页 → 左右切到评论页 → 再切回简介页 → 用表冠滚动；重复 3 轮。
- **应该看到**：看到的那一页跟着滚；不再出现「屏幕上不动、看不见的那页在后台滚」或「怎么转都没反应」。
- **不算 bug**：切换瞬间（页面还没画完）转动的第一格可能被丢掉；旧包（26.11.09 之前）里「只有 0.5 倍速」那条问题早已修掉，本轮不再处理。
- **AI 断言**：人判——手感；日志里 `ScanStats` 的 `offscreenPage` 计数若持续 > 0 且整页不动，把那一行抄回来。
- **预计**：3 分钟

## H06 缓存页「自动刷新」开关全流程（反馈 #211）

- **怎么做**：① 进缓存页与文件夹页，确认与改前一样（默认开着）；② 设置 → 缓存与下载 → 缓存选项 → 关掉「缓存页自动刷新」，再进缓存页/文件夹页；③ 关掉状态下**下载一个新视频**，回缓存页看；④ 删掉一个已缓存的视频，回缓存页看；⑤ 在这两页分别下拉一次；⑥ 设置页搜「自动刷新」。
- **应该看到**：②关掉后两页秒开、并弹一次「自动刷新已关闭，用的是上次结果；下拉可刷新」；③新下载的视频出现；④删掉的消失；⑤下拉都能真的刷新（转圈后内容是最新的）；⑥搜索能命中这条设置。
- **不算 bug**：提示每次启动 App 只弹一次；刚建过新文件夹的那一次仍会重扫一遍（下一轮才命中缓存）；换过缓存位置后旧根里的集数是否出现取决于指纹，若没出现下拉一次即可。
- **AI 断言**：`adb logcat` 里缓存页扫描相关日志在「关掉开关 + 二次进入」时不再出现；人判——秒开的手感与内容是否正确。
- **预计**：6 分钟

## H07 字号与尺寸在页面、Toast、播放器里一致（反馈 #225）

- **怎么做**：设置 → 界面适配里把「界面缩放」设成非 1.0（比如 1.15），或设一个绝对 DPI（比如 220）；然后对比看：①同一个列表页的标题与正文；②随便触发一个 Toast（比如点个需要登录的操作）；③进播放器看顶栏标题、进度条高度、底部按钮行。
- **应该看到**：Toast 文字与页面文字大小一致（改前 Toast 明显小一档）；播放器顶栏与进度条不重叠、不被切；没有哪一页的按钮文字溢出按钮。
- **不算 bug**：同一排按钮字号不完全相等，是因为按「不折行不裁字」自动缩到 7~14sp 之间的不同档，这是既有设计；「设置」里的绝对 DPI 改完要退出重进才生效，也是既有行为。
- **AI 断言**：人判——文字大小与排版只能看画面。
- **预计**：4 分钟

## H08 换了界面缩放后各页仍正常（回归，反馈 #225 的连带面）

- **怎么做**：在界面缩放非 1.0 的状态下依次打开：首页、视频详情、评论区、私信列表、设置首页、下载列表、缓存页。
- **应该看到**：每页都能正常打开、文字不重影不裁切、列表能滚、圆屏上不贴边。
- **不算 bug**：个别页面元素略大属于缩放的预期效果。
- **AI 断言**：`adb logcat -b crash -d` 应无新崩溃；人判——裁切与贴边。
- **预计**：3 分钟
