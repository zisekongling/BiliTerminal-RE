# 26.11.09 头像暗边人工验收单（H05 / H06）

> 对应改动：`docs/review/fix-progress.md` §1「『关注的人』头像条出现黑色边框」（PR #24）、「『动态页作者旁有灰边』第三次定位：不是阴影，是卡片填充色」（26.11.10）、「同一类阴影暗边的第二处：关注页列表项去掉 2dp 抬高」（26.11.10）。
> L0 已过：`:app:assembleDebug` BUILD SUCCESSFUL（26.11.09 实测，head `f843aa21`；26.11.10 两轮同样通过）。下面每项都**只能靠真机看画面**下结论。
> 预计 15 分钟；需要一张自定义背景图 + 至少两套主题。

## H05 动态页顶部头像条的暗边 / 灰边（用户反馈 #17；26.11.10 第三次修）

**改的是什么**：用户报「自定义背景下，关注界面的『关注的人』列表头像有黑色边框，边框颜色推测由主题决定」，补充「只有滑动时出现，其他页面没有」。这条横条 = 动态页顶部「最近更新的UP主」（`cell_recent_up_list` → `RecentUpAdapter` → `cell_up_avatar`）。

- **26.11.09 第一刀（`f843aa21`）= 错的一半**：当时只把 `app:cardElevation` 压成 `0dp`（描边 `app:strokeWidth="0dp"` 自 `a7fb06be` 起就已经是 0）。用户 26.11.10 复验：**没修好**。
- **26.11.10 真根因**：那一格原来用 `MaterialCardView` + `app:cardCornerRadius="28dp"` 只为把方头像裁成圆。而 `AppearanceApplier.applyRadius()` 在「圆角」档会把**全树所有卡片**的圆角改成 12dp/6dp，28dp 被覆盖 → 卡片变成**圆角方卡**，它的 `cardBackgroundColor`（`@color/card_dark` / 玻璃主题的半透明卡色）在圆头像四角露出来，就是用户看到的那圈灰/黑边。所以只改 elevation 和描边永远消不掉——残留是**填充色**。
- **本次改法**：这一格换成 `FrameLayout` + `@drawable/bg_avatar_circle`（全透明 oval 轮廓）+ `clipToOutline="true"`，卡片整个拿掉（主题卡色、描边、阴影、圆角覆盖四个源一起消掉）。

1. 设置 → 界面与外观 → 背景图：选一张**有明暗细节**的图（纯色 / 纯深色图上看不出边，会出现假阴性）。
2. 设置 → 界面与外观 → 圆角：**选「圆角」档**（不是默认档）——这正是原来触发圆角覆盖的条件，必须在这一档下验。
3. 进动态页，看顶部「最近更新的UP主」横条：
   - [ ] 每格头像**四角没有方块色**（改前是与卡底色相同的圆角方块，只在四角露出）
   - [ ] 头像仍是正圆、边缘没被裁掉一圈，「有更新」的粉色小圆点位置不变（距卡片上/右各 2dp）
   - [ ] 手指在横条上**划过或按住**（别松手点到跳转）时也不冒出边
4. 换主题再各看一遍：暗色 / 亮色至少各一套，其中一套用玻璃质感（1dp 描边 + 半透明卡色）的主题——那一套卡色是半透明粉，最容易露。
5. 关掉自定义背景（用默认背景）扫一眼：与改前一致，没有多余描边。
6. 回归：点头像与名字都能跳到用户空间；横条左右滑动流畅；超长名字仍是省略号；更新点该显示时显示、不该显示时不显示。

**判据**：第 3 项任何一条不满足 → 说明还有第三个源。下一处要查的是按下态的 `translationZ`（卡片已不存在，此源已消）与横条外层 `LinearLayout` 的 `?android:attr/selectableItemBackground` 按压底纹（那是主题色，不是卡色）；先截图对照卡色/描边色再改。

## H06 关注页列表项的阴影暗边（同案第二处，26.11.10）

**改的是什么**：`cell_user_list.xml`（关注 / 粉丝列表行，另被搜索用户页、充电鸣谢页复用）原写 `android:elevation="2dp"`，`cell_follow_group.xml`（关注分组标题行）原写 `app:cardElevation="2dp"`。这条卡底是全仓唯一手绘的不透明卡色（`@drawable/bg_card_rounded`），抬高后阴影会沿卡片轮廓在自定义背景照片上投出一圈暗边。本次把两处抬高归 0，**卡色、圆角、内容、点击都没动**——所以下面只看「暗边没了」和「排版没被带坏」。

前置：登录本人账号（关注列表要数据）；设置 → 外观 → 背景图选一张**带明暗细节的亮色照片**（纯色 / 纯深色图上看不出阴影，会假阴性）。

1. 我的 → 关注（普通模式），逐行看卡片外沿：
   - [ ] 卡片四周**没有**一圈向外渐暗的暗边（改前有 2–4px）
   - [ ] 头像仍是圆的、圆角仍是 12dp、行间距与改前一致
2. 设置 → 界面与外观 → 打开「关注分组」后回关注页，看分组标题行（「全部关注」/ 自定义分组名）：
   - [ ] 同样没有暗边，展开 / 折叠分组都正常
3. 换主题再各看一遍：暗色 / 亮色至少各一套（亮色下卡色是暖白 `#FEF7F1`，暗边与底色反差变小，要凑近看）。
4. 关掉自定义背景（默认纯色底）扫一眼：与改前一致，看不出差别。
5. 回归两个共用同一份布局的页面：
   - [ ] 搜索 → 用户：能输入关键词，结果卡片变平但头像 / 昵称 / 粉丝数 / 特别关注徽章都在原位
   - [ ] 视频详情 → 充电鸣谢：列表卡片同上
6. 交互回归：长按 / 拖动分组、点进用户页、上下滑动列表都正常；低端设备上滑动不掉帧（去掉 elevation 只会更省）。

**判据**：第 1、2 项任一处仍能看到暗边 → 说明残留不是 elevation，回到「卡底不透明 + 照片直透」这条设计取舍上（要改就是给 `bg_card_rounded` 换成半透明卡色，需先加 ARGB 颜色 token，`minSdk=19` 不能用 `layer-list` + `android:alpha` 取巧）。
