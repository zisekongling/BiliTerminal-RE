## F01 弹幕屏蔽词

覆盖 `player/DanmakuBlockWordPolicy.kt`、`player/DanmakuBlockWordParser.kt`、`DanmakuManager` 两处接线、设置项 `player_danmaku_block_words`。

- **怎么做**：①进「设置 → 内置播放器设置 → 弹幕 → 弹幕屏蔽词」，填 `前方高能，哈哈哈`，返回；②随便开一条弹幕多的视频（热门/排行）；③再改成 `sc` 开一条英文弹幕多的视频；④把屏蔽词清空，重开同一条视频。
- **应该看到**：②③两种填法下，含这些词的弹幕**一条都不出现**（中文、英文都算，英文不分大小写）；其它弹幕照常滚动；④清空后不再过滤。
- **顺带确认「自己发的弹幕不被吞」**：在填了屏蔽词的视频里发一条正好含屏蔽词的弹幕，**自己那条应该照常出现**（只过滤看别人的弹幕）。
- **生效时机**：改完屏蔽词**不会立刻作用于当前视频**，要换视频 / 切分 P / 重进播放页才生效（设置项说明里已写）。
- **不算 bug**：`sc` 会把 `script` 一起屏蔽（朴素包含，刻意不做分词）；屏蔽词只影响弹幕，不影响评论、不影响字幕。
- **AI 断言**：`adb logcat -d | findstr 屏蔽` 不应出现异常堆栈；切视频后 `DanmakuManager` 的 prepare 日志正常。

## F02 快退 / 快进按钮

覆盖 `player/PlayerSeekStepPolicy.kt`、`PlayerButtons` 两个 textOnly 按钮、`activity_player.xml` 两个 TextView、`PlayerActivity.initSeekButtons/seekByStep`。

- **怎么做**：①播一条视频，点控制栏「更多」，找「快退」「快进」两格，看格子里写的是不是 `«10s` / `10s»`；②各点一下，看进度是不是正好 ∓10 秒；③进「设置 → 内置播放器设置 → 默认值 → 快退/快进步长」改成 30，返回播放页（不用重进）；④在片头 5 秒处点快退、在片尾 3 秒处点快进。
- **应该看到**：①两格文字随步长变化；②每次正好跳 10 秒，拖动条位置同步；③不改也得改——返回后格子文字立刻变 `«30s`，点一下跳 30 秒（**不用重进播放页**）；④落点被钳在片头 0 / 片尾，不会越界也不会崩。
- **放进控制栏**：这两枚默认收在「更多」里；用「更多 → 播放器界面」把它们拖到左列/右列，应该能在控制栏直接看到并点。
- **不算 bug**：两枚按钮在**未 prepare** 的加载阶段不显示（与「跳到指定时间」一致）；直播间不显示。
- **AI 断言**：`adb logcat -d | findstr "±N秒"` 应打印 `±N秒` 一条带目标位置与片长的日志。

## F03 长视频后半段有弹幕

覆盖 `DanmakuStreamLoader.updateDuration` 与 `PlayerActivity.onPrepared` 回填。

- **怎么做**：找一条**超过 1 小时**的录播/长视频（弹幕别太少），进播放器后直接拖到 1 小时之后的位置，等 5~10 秒。
- **应该看到**：拖过去之后**有弹幕**（以前拖到 60 分钟以后就一直是空的）。日志里能看到「时长回填：3600s → 实际秒数，总分段数 N」。
- **不算 bug**：那条视频本身后半段弹幕就少的时候，看着稀属正常；缺口段要等窗口加载（几秒），不是瞬间满屏。
- **AI 断言**：`adb logcat -d | findstr 时长回填` 必有一条，数字大于 3600。

## F04 高能曲线按弹幕密度兜底

覆盖 `player/DanmakuDensityHighEnergy.kt` 与 `PlayerActivity.applyDensityHighEnergyFallback`。

- **怎么做**：①开启「内置播放器设置 → 弹幕 → 显示高能进度条」；②找一条**官方没给高能数据**的视频（大部分普通投稿都是），播 10 秒以上；③再找一条官方有高能数据的（番剧/热门），对比。
- **应该看到**：②在播放约 6 秒后，进度条上出现起伏的曲线（不是一条平的灰线），弹幕密的段落更高；③仍然显示官方的粉/主题色曲线，两者不打架。
- **不算 bug**：整条视频弹幕少于 30 条、或片长不足 1 分钟时**不画**曲线（保底不糊弄）；曲线是本地估算，形状不会和官方一模一样。
- **AI 断言**：`adb logcat -d | findstr 高能` 应能看到「未获取到有效数据」后紧跟本地兜底的结果日志；不应出现反复重试。

## F05 进度条按封面取色

覆盖 `player/CoverTintPolicy.kt`、`HighEnergyProgressBar.setAccentColor`、`PlayerActivity.applyCoverTint`。

- **怎么做**：①随便开几条封面颜色差别很大的视频（蓝色系 / 橙红色系 / 黑白封面各一条），看进度条的高能曲线与填充色；②分别切「浅色模式」和「深色模式」各看一次；③开一条直播间，再开一条本地缓存视频。
- **应该看到**：①曲线颜色跟着封面走（蓝封面偏蓝、橙封面偏橙），不同视频不一样；②两套模式下都**看得清**、不刺眼、不发白；③直播 / 本地视频保持主题主色（它们没有封面 extra），不闪不崩。
- **不算 bug**：封面是纯黑白 / 大留白时取不到色，回落主题主色属预期；同一视频两次进入颜色应一致（同一封面）。
- **AI 断言**：`adb logcat -d` 无 `CoverTint`/Glide 相关异常；弱网下封面加载失败也不崩。

## F06 华为/鸿蒙首次默认软解

覆盖 `player/PlayerCompatPolicy.kt` 与 `IjkNativeLibs.seedCompatDefaults`（**需要华为/荣耀/鸿蒙设备**；没有就跳过并在结果里写「无设备」）。

- **怎么做**：①清除 App 数据（或卸载重装）后第一次进播放器；②看「设置 → 内置播放器设置 → 解码方式」的当前值；③手动改成硬解，退出再进播放器、重启 App 后再看。
- **应该看到**：①第一次进播放器能正常播；②解码方式是**软件**；③改成硬解后**永远是硬解**，不会被自动改回软解。
- **顺带**：非华为设备（小米/OPPO/三星）重装后解码方式仍是**硬件**（默认值不变）。
- **不算 bug**：`ShortVideoPlayerActivity`（短视频页）不吃这套播种，仍按自己的逻辑走。
- **AI 断言**：`adb logcat -d | findstr 软解` 应有一条播种日志（仅首次）。

## F07 全局转场动画开关

覆盖 `util/PageMotion.kt`、`BaseActivity` 三处接线、设置项 `ui_disable_page_transitions`。

- **怎么做**：①进「设置 → 外观设置」，滚到最下面找「转场动画」开关（默认**关**＝有动画）；②来回进出几个页面（主页 → 消息 → 返回 → 收藏夹），看有没有淡入/滑动；③打开开关，再进出同样几个页面。
- **应该看到**：②③明显差别——打开后页面切换**立刻**换、没有淡入滑动；关掉恢复原来的动画。列表滚动、Loading、弹窗动画**不受影响**。
- **不算 bug**：播放器、启动页、「从外部打开」入口本来就不走这套，开关对它们无效（属预期）。
- **AI 断言**：无崩溃；`adb shell dumpsys window | findstr mWindowAnimations` 在开关打开后对应窗口为 0。

## F08 主菜单未读角标回菜单刷新（要登录）

覆盖 `util/MessageUnreadRefresh.kt`、`BiliTerminal` 启动块、`MenuActivity.onResume`。

- **怎么做**：①登录后进一次消息页，把私信/回复都读掉（或先让别人给你发一条私信）；②退回主菜单，看「消息 (N)」；③再进消息页读完，退回主菜单；④把另一条设备上的账号切掉（或在设置里退出登录），退回主菜单；⑤在「设置 → 通知设置」关掉「消息未读提醒」，再进消息页退回来。
- **应该看到**：②③退回主菜单后 1 秒内角标就动（读完应变成 0 或真实剩余数），**不用重进 App**；④退出登录后角标清零；⑤关掉开关后回菜单不再发请求（角标保持上次的值）。
- **不算 bug**：5 秒内连续两次退回菜单只查一次；断网/接口失败时**保留旧数字不清零**（这是有意的）；「动态 (N)」本轮**没做**刷新，仍是启动时那份。
- **AI 断言**：`adb logcat -d | findstr 未读` 每次回菜单最多一条请求日志；关开关后不再出现。
