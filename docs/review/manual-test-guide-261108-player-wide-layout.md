# 26.11.08 播放器宽屏布局回退 · 人工验收单（6 条，约 10 分钟）

- 安装包：`app/build/outputs/apk/standard/debug/app-standard-universal-debug.apk`
  （手表装 arm64 或 universal；MD5 `702921BF64AB77E5A32D1DB3C13E4688`）
- 版本：`versionName 26.11.07` / commit `e4c4c38`
- 前置：**不需要登录**。用任意视频起播即可（本地视频也行：任意一个 mp4 从「本地」页进播放页）
- 对照：同一条视频在 **26.11.02** 上的观感（底栏薄、按钮小、按钮簇整体居中）
- 回结果：通过写 `- [x]`；不通过留空，并在旁边写一句「看到的是什么」

## H01 宽屏（手机 / 大屏）上底栏厚度和按钮大小回到 11.02

- **怎么做**：在手机或大屏设备上打开播放页 → 点一下画面唤出控制栏 → 看最下面那条半透明底栏
- **应该看到**：底栏是薄的一条（约占屏高 1/40），里面一排按钮都不大；整排按钮（含中间的播放键）**作为一个整体居中**，不是被摊到两头、也不是两边等距夹着播放键
- **不算 bug**：不同视频比例下播放区高度不同，底栏位置跟着播放区底部走
- **AI 半自动**：`adb shell uiautomator dump` 读 `bottom_control` / `videoprogress` / `button_quality` / `button_video` 的 bounds，换算 dp 应为底栏 59dp、进度条 20dp、按钮 32×37dp；人判：整排看起来是否紧凑居中
- **预计**：1 分钟

## H02 左右两列按钮回到紧凑尺寸、贴屏幕边缘

- **怎么做**：同 H01 的控制栏，看画面左右两侧竖着排的按钮（弹幕、旋转等）与左下角锁定键
- **应该看到**：这些按钮都是小的方形（28×28dp），紧贴屏幕边缘，不压住画面中间；不会出现「一排很大的方块把画面挤窄」
- **不算 bug**：某一侧没放按钮时那一侧就是空的
- **AI 半自动**：dump 读 `right_control` 宽度与列格高应为 28dp、`lock_btn` 为 28×28dp；人判：视觉上与 11.02 是否一致
- **预计**：1 分钟

## H03 底部按钮放满时整行横向滚动仍可用

- **怎么做**：设置里把底栏两侧槽位都放满（若「播放器界面」设置入口在正式包里不可见，请开发者版手动改布局后再试）→ 回播放页看底栏
- **应该看到**：按钮多到一行放不下时，整行可以左右滑动看到剩下的按钮，**贴着中间的播放键向两边生长**，不会有两个按钮被裁掉一半卡在屏幕边缘
- **不算 bug**：按钮少时不会滚动（本来就不用滚）
- **AI 判不了**：需要先构造「底部槽位放满」的布局存档，本轮没有构造出这个场景，横向滚动的手感只能人判
- **预计**：2 分钟

## H04「更多」按钮展开后图标不再竖着拉长

- **怎么做**：同上，把某一侧的按钮数放到超过该侧容量（出现「更多」按钮）→ 点「更多」展开
- **应该看到**：展开条上的「更多」图标是**方正**的（旧版在底部区会被竖向拉长 1.19 倍，看起来像一条竖着的长方形）
- **不算 bug**：展开条里按钮本身的尺寸与正式槽位一致，不额外放大
- **AI 判不了**：同样需要溢出场景，只能看画面
- **预计**：2 分钟

## H05 横屏 / 分屏 / 平板上布局不跑偏

- **怎么做**：把设备转成横屏（或进分屏、或在平板上）后打开播放页唤出控制栏
- **应该看到**：底栏仍是一条薄条、按钮仍紧凑居中；左右两列仍贴边、不压住画面
- **不算 bug**：横屏时底栏可能盖住部分画面底部（与 11.02 行为一致）
- **AI 判不了**：横屏 / 平板形态本轮没实测，需人看画面
- **预计**：2 分钟

## H06 字幕与底栏不再重叠

- **怎么做**：打开一个字幕明显的视频（或弹幕调成「底部固定」更容易看边界）→ 唤出控制栏
- **应该看到**：字幕最后一行与底栏按钮行之间有约 17dp 的空隙，字幕不会压在按钮上
- **不算 bug**：字幕本来就允许与视频画面重叠
- **AI 半自动**：dump 读 `text_subtitle` 底边与 `bottom_control` 顶边，间隙应 ≥15dp；人判：观感上是否还挤
- **预计**：2 分钟
