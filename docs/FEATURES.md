## 1. 打开 App 与主菜单

### 1.1 启动页（开机画面）

- **开机动画**：打开 App 时，屏幕会以"打字机"效果一个字一个字地打出欢迎语（默认是「欢迎使用 RE:哔哩终端」，内容可在设置里改）。
- **自动检查登录状态**：启动时会后台检查登录信息是否过期，过期会提示重新登录；同时检查有没有新版本、有没有新动态/新消息（用于菜单上的红点数）。
- **公告弹窗**：启动时会拉取公告，有新公告就弹一次（只弹上次之后新增的那几条，已经看过的不会重复弹）。公告统一由本项目自建服务器下发：上游原版公告由服务端拉取、维护者逐条审核后才透传，透传公告点开时正文顶端会注明来源（详见 14.16 与 19）。
- **匿名使用统计**：启动时顺手报一次「有人在用」（一天最多一次），详见 20.2。
- **设备时间检查**：手表时间不对（比如没电重启后回到出厂日期）时，所有网络请求都会因为证书校验失败而连不上。启动时如果发现系统时间早于本应用的发布日期，会提示去改时间；使用中遇到证书时间错误，也会提示「请检查设备的日期和时间」，而不是笼统的「网络错误」；能问到服务器时间时，还会直接列出「设备时间」和「实际时间约」，时间拨早、拨晚都看得出来。
- **首次启动（含升级后第一次）的隐私说明**：会弹一次隐私说明，点「同意」或「不同意」都能进入 App，区别只在于是否上报（详见 20.3）。
- **启动后进入哪一页可自定义**：默认进入「推荐」页；在「设置 → 内容与浏览 → 菜单设置」里点一下任意已启用菜单项（右侧复选框随之选中），下次启动就直接进入那一页。选中项后来被移入「未启用」区时，会自动改回「推荐」，不会指向进不去的页面（详见 14.11）。

### 1.2 主菜单（首页九宫格）

- **进入各功能**：主菜单列出 14 个入口：推荐、短视频、热门、入站必刷、全站排行榜、热搜、直播、时间线、搜索、动态、我的、消息、缓存、设置。点一下即可进入对应页面。
- **菜单顺序可调**：在「设置 → 内容与浏览 → 菜单设置」里可以调整菜单项顺序、把不常用的移入"未启用"区。
- **未登录时**：菜单顶部会出现「登录」按钮，同时隐藏「动态」「消息」「我的」三个入口。
- **红点提示**：「动态」和「消息」按钮上会显示未读数量（有更新时显示数字）。
- **退出菜单**：按实体菜单键，或点屏幕顶部，即可收起菜单。

### 1.3 用链接打开内容（分享/跳转）

- 从浏览器或其它 App 点击 B 站视频/专栏链接，可以用「RE:哔哩终端」打开（支持 http、https、bilibili 开头的链接）。装了共存版时，两个版本都会出现在选择列表里，选哪个都行。
- 也支持直接打开指定类型：视频（AV/BV 号）、专栏、用户主页。

### 1.4 普通版与共存版（26.10.11 起）

- **同一份代码出两个安装包**：普通版与**共存版**，两版**名字完全一样**（都叫「RE:哔哩终端」），靠**图标**区分——共存版用的是原项目那枚图标。共存版包名不同，所以**可以和普通版同时装在手表上**，互不覆盖。
- **数据完全隔离**：登录状态、设置、缓存、下载文件各自独立——装了共存版要**重新登录一次**，两边也不共享设置。
- **更新各自独立**：两版从同一个 Release 取自己的包更新，装了哪个就更哪个。
- **外链**：两版都注册了 B 站链接，点链接时系统会问用哪个打开（这是有意保留的行为）。

## 2. 看视频：推荐 / 热门 / 排行榜等

### 2.1 推荐页

- **往下拉刷新**：手往下拉，换一批新推荐。
- **一直往下滑**：滑到底部会自动加载更多推荐视频。
- **自动去重**：同一个视频不会重复出现在推荐流里（已看过的不会反复推）。
- **首次使用提示**：第一次进推荐页会有新手引导气泡。

### 2.2 热门页

- 看 B 站热门视频，往下拉刷新，滑到底自动加载下一页；滚动时图片按需加载（更省流量、更流畅）。

### 2.3 入站必刷页

- 看「入站必刷」经典视频，用法和热门页一样（下拉刷新、滑动翻页）。

### 2.4 全站排行榜

- 看全站排行榜（一次加载完整榜单，不分页）。
- 说明：当前版本榜单固定为"全站"类别，没有分区切换。

### 2.5 时间线（追番日历）

- 按天展示追番的播出时间线（当前固定展示"追番"类型）。
- 往下拉刷新；没有数据时显示空提示；加载失败会提示。

### 2.6 热搜榜

- 看 B 站热搜词，往下拉刷新。
- 注意：热搜词点击后跳转的行为由列表项自身处理。

### 2.7 短视频（竖屏信息流）

- **上下滑动**：像刷抖音一样上下滑切换短视频，松手自动播放当前视频。
- **左右滑动（与手机版一致，四页一条线）**：右滑依次是「视频详情 → 评论 → 相关推荐」；在短视频页右滑退出本页，在右侧详情页右滑退回短视频。本页已关闭系统右滑返回，避免手势被窗口层抢走。详情/评论/相关推荐跟随「当前这条视频」切换（相关推荐关掉时没有第 4 页）。
- **播完自动续播**：列表里还有下一条就自动切到下一条；到底后按当前视频拉一批相关推荐追加到列表末尾继续播；拉不到就停下提示「没有更多短视频了」，不再循环重播当前条。
- **预加载**：提前加载后面几条，切换更流畅。
- **单击画面**：显示/隐藏底部控制栏。
- **双击画面**：播放/暂停。
- **长按画面**：按住期间 3 倍速播放，松手恢复原来的倍速档位（与手机版一致）；详情页改由上面的左右滑动到达，长按不再另开详情页。
- **双指缩放**：双指捏合可把画面放大 1~3 倍。
- **底部控制栏**（不操作 10 秒自动隐藏）：
  - 播放/暂停按钮（快看完时点播放会从头再播）。
  - 弹幕开关（开/关弹幕）。开播时的状态跟随「播放设置 → 播放默认值 → 弹幕」（开 / 关 / 沿用上次），和长视频共用同一个设置；刷到下一条时保持你刚切换的状态。
  - 音量加/减（调系统音量，会提示"音量：N%"）。
  - 倍速（循环切换 0.5~2.0 倍）。
  - 进度条（拖动快进快退）。
  - 顶栏返回（退出）。
- **只播当前页**：滑走的视频会暂停，节省流量。
- **推荐去重**：同一批里重复的、已经刷过的视频不会再次出现（最近 300 条记在本地）；横屏视频直接过滤。

## 3. 视频详情页与播放器

### 3.1 视频详情页（整体）

- **左右滑动翻页**：详情页内可以左右滑动，在「简介 / 评论 / 相关推荐」之间切换（相关推荐可在设置里关闭）。
- **从评论定位**：如果是从某条评论链接进来的，会自动跳到评论区并定位到那条评论。
- **长按顶栏返回首页**：在视频详情页长按顶部，可以一键关闭所有详情页、回到主页面（可在「设置 → 内容与浏览 → 通用偏好 → 长按顶部标题栏」选「不响应」彻底关掉这个手势）。
- **番剧详情**：打开番剧时展示的是番剧版详情页（封面、评分、选集等）。

### 3.2 视频简介页（详情首页）

- **封面**：点封面直接播放（可在设置里改成"点击看大图"）；长按封面看大图。
- **标题徽章**：充电专属、互动视频、全景视频、联合投稿的视频，标题旁有对应小标签。
- **长按复制**：标题、BV 号、简介都可以长按复制。
- **标签**：点一下标签文字可展开/收起全部标签；点单个标签会用这个标签去搜索。
- **点赞 / 投币 / 收藏**：分别点对应图标即可；**一键三连 = 长按点赞图标 2 秒**（期间松手可取消），成功后三个图标全亮。
  - 未登录时点击会提示"还没有登录喵~"。
- **数据统计**：显示播放量、点赞/投币/收藏数（上万会显示成"xx万"）、弹幕数、发布时间、时长；有"独家/争议"提示时会显示提示条。
- **UP 主区**：横向展示全部 UP 主（含联合投稿），点一个进他的主页。
- **简介**：点一下在"3 行 / 全部"之间切换；简介里的网址、@用户名可以直接点；长按复制。
- **播放按钮**：点播放直接进播放器；多 P 视频会先让你选分 P；长按播放按钮可换播放器。
- **稍后再看**：点"稍后再看"加入列表；长按它直接查看稍后再看列表。
- **下载**：点下载开始缓存（默认缓存目录按系统版本自动选择、无需存储权限；安卓 13+ 会请求一次通知权限，**即使拒绝也照常下载**，只是进度通知不可见；目录写不进去时会自动改存到应用专属目录并提示）；多 P 视频先选分 P；长按下载按钮 = 清除这个视频的缓存文件夹。
- **转发**：点转发可以把视频转发成动态（支持 @ 人）；长按转发 = 复制视频链接。
- **AI 视频摘要**（需登录）：点"视频摘要"一键生成这个视频的 AI 内容总结，弹窗显示。
- **合集入口**：视频属于某个合集时显示「合集 · 标题」，点击进合集页。
- **自动上报观看进度**：进入详情页就会预取播放地址并上报播放历史。

### 3.3 相关推荐

- 详情页第三页，展示和当前视频相关的推荐，滑到底加载更多。

### 3.4 番剧详情页

- **基本信息**：封面大图（点开看大图）、标题、地区/类型、评分、播出状态（已完结/连载中）、播放/收藏/追番数、标签、备案号。
- **简介 / STAFF（制作人员）**：点标题头展开/收起。
- **季切换**：同一部作品的第二季、剧场版、OVA 会在选集上方显示成一排季名，点一下整季选集一起换；切回某一季时会回到你在这季上次看的那一集（只有一季时这一行不显示）。
- **选集**：横向两行卡片——第一行是集号与「会员 / 限免」角标，第二行是这一集的长标题，正在看的那一集带播放中标记并高亮；点哪集看哪集（评论区也会跟着切到那一集）。选集标题右侧显示「已完结，全N话 / 连载中」这类状态，点开可以一次跳到该季任何一集（含花絮、PV）。
- **追番 / 取消追番**：播放按钮旁边就是追番按钮，按钮上直接显示「追番 / 已追番」；未登录点它会提示先登录。
- **播放**：点播放进播放器；长按播放可换播放器。
- **看完一集会自动标"已看完"**：番剧的心跳比普通视频密（5 秒一次），一集播完立刻按"已看完"上报，这样下次点开是接着看下一集，而不是停在这一集末尾。

### 3.5 添加收藏

- 从视频详情页点"收藏"进入：勾选要加入的收藏夹（能看到每个收藏夹已存/上限数量），点返回即完成；全部取消勾选 = 取消收藏。
- 结果会即时反映在详情页的收藏图标上（收藏成功/删除成功会有提示，可在设置里关）。

### 3.6 视频播放器（最核心的页面）

**进入播放器后，你能做的操作：**

**手势（多数可在设置里开关）：**

- **单击**：显示/隐藏控制栏（4 秒无操作自动隐藏）。
- **双击屏幕中间**：播放/暂停；开启“有缩放时，双击优先恢复缩放”后，仅画面放大时先恢复原大小与居中位置，再次双击播放/暂停。只切换横竖屏不算缩放，双击始终保持当前方向。
- **双击屏幕左右 1/3**：快退/快进（默认 10 秒，秒数可调）。
- **横向滑动**：在画面上左右滑动直接调进度，拖动过程中实时显示进度提示（可在设置里开关）。长按加速期间横滑不调进度，松手后恢复。
- **长按画面**：3 倍速快进，松手恢复原速。按住期间手指稍微横移不会触发滑动调进度。
- **双指缩放**：画面可放大 1~5 倍。
- **双指/单指拖动**：放大后可以拖动画面位置；开启缩放优先恢复后，快速双击可复位画面。
- **右滑返回**：播放页**不响应**系统的右滑返回手势（26.10.22 起无条件关闭），看视频时误滑不会退出播放页；退出请用顶栏左上角返回按钮或返回键。短视频页的「右滑退出」是另一套自己的手势逻辑，不受影响。**两类右滑不受此保护**：① 用「模拟按下返回键」实现右滑的手表（如米兔等，见设置里「禁用返回键」的说明）——那一下到应用里就是一个返回键，本页不拦，返回键仍可退出；② 手机 / 平板的系统返回手势也仍可退出播放页。

**控制栏按钮：**

- 播放/暂停；循环（单集循环）；旋转（横竖屏切换）；"更多"菜单（展开第二排按钮）。
- 发弹幕（输入文字，在当前进度发送）；弹幕开关（隐藏/显示弹幕）。
- 字幕（选择字幕轨道，支持 AI 字幕）；听视频模式（关画面只听声音）。
- 分 P 选择（多 P 时出现）；自动连播（多 P 播完自动下一 P）。
- 清晰度切换；分段（看点）跳转；音量加/减。
- 短视频模式下有"查看视频详情"按钮；互动视频有"调试"按钮（需在设置开启）。

**触摸锁定（防误触，26.10.20 新增）**：

- 控制栏左侧有一个锁按钮（形状是合上的锁），点它锁定画面：所有控制栏、顶栏、进度条立刻隐藏，画面上的点击、滑动、长按、双击都不再操作播放器，误触不会暂停、不会跳进度。
- 锁定按钮在左侧单独一列，与右侧那列竖排图标（弹幕 / 旋转 / 更多）对称：同样 28dp、离屏幕左边 4dp、上下居中。
- 锁定后点一下画面，左侧会浮现开锁图标（3 秒无操作自动隐去）；再点它解锁，控制栏恢复。
- 锁定期间**字幕照常显示**（字幕不跟随控制栏一起隐藏）。
- 锁定期间不能离开播放页：顶栏的返回图标不可见，返回键、蓝牙返回都会被拦下（拦下时浮现开锁图标提示先解锁），必须先解锁才能退出。手表右滑返回在窗口层就被关掉了（见上面的「右滑返回」），锁定与否都不会因此退出，也就不会有「浮现开锁图标」这一步反馈。
- 切集（自动连播、换 P、切清晰度）后保持锁定；退出播放页后自动解除，下次进入是正常状态。
- 第一次锁定时会弹一条提示，说明怎么解锁。

**倍速**：控制栏显示当前倍速（如 x1.0），点它弹出滑条，0.5~3.0 倍随便调，松手自动收起。

**进度条**：

- 拖动跳转；显示缓冲进度。
- 高能进度条（设置里开启后显示粉色高能曲线）。
- 续播：上次没看完的，再打开自动从上次位置播放（可设置关闭）。
  - 番剧按"集"校验：服务端返回的续播位置如果其实属于别的集，会被丢弃（宁可从头开始，也不从上一集的位置接着播）。
  - **本地/缓存视频也能续播（26.10.22 起）**：位置记在视频自己那个缓存目录里（`.video_meta.json`），不联网；单文件、DASH 双文件、多 P 的每个分 P、虚拟合集、听视频各记各的位置。暂停/切后台/退出/被系统杀进程最多丢 15 秒；看到距结尾 5 秒内或播完算看完，下次从头播。

**弹幕**：

- 自动加载弹幕（新版接口，失败自动退回旧接口）。
- 弹幕样式（行数、字号、透明度、速度、是否重叠、是否合并重复等）都在"内置播放器设置"里调。
- 可以发送弹幕。

**直播模式**：看直播时隐藏进度条等控件，显示在线人数，走直播弹幕通道；弹幕会显示发送者昵称（可关）。

**网络不好时的自愈（26.10.11 起）**：

- 读数据卡住不会再无限黑屏：读超时 10 秒就报错并进入重试，直播断流会自动重连（退避 5 秒）。
- **位置停滞看门狗**：播放位置卡住不动（直播 20 秒、点播 30 秒）会自动重试 —— 直播换一条线路（提示「网络不佳，正在切换线路」），点播原地重建并接着原位置播；最多自动重试 3 次，之后提示「网络似乎已断开，可稍后手动重试」，不会一直转圈。
- **切到别的软件再回来不再回跳位置**；被系统回收后重进也能回到切走前的位置（而不是回到进入页面那一刻）。

**互动视频**：播放到选项时会弹出选择卡片，选了分支继续播；条件分支按你之前的选项自动跳。

**系统按键（遥控器/实体键）**：

- 确认键：播放/暂停；左右方向键：快退/快进 10 秒；上下方向键：音量。
- **无极调音**（26.10.24 起）：长按音量加/减会弹出 0~100% 的软件增益滑条（1% 一档，松手或 4 秒后自动收起，数值会记住）；短按仍按老手感调系统音量 ±1 档，增益被拉到 0% 时短按「音量+」会顺手把它救回 100%。

**其它**：

- **后台 / 熄屏继续播放**：切到别的应用或按下手表熄屏后声音继续播，通知栏可以暂停、继续、切上一集/下一集。
- 支持系统媒体控制（锁屏/通知栏可控制播放暂停、切 P）。
- 看直播/视频时可显示"实时观看人数"（设置里开）。
- 圆屏手表上播放界面会重新适配布局。
- 退出时把当前进度、弹幕开关、清晰度等状态回传给上一个页面。

### 3.7 分 P 选择、清晰度选择、互动调试

- **分 P 选择**：多 P 视频在详情页点播放/下载时，先弹分 P 列表选择。
- **清晰度选择**：下载视频前选择缓存清晰度（360P/720P/1080P 等）。
- **互动视频调试**：仅开发者/调试场景使用，用于查看互动视频的隐藏变量。

### 3.8 视频笔记

- 填名称（必填）、简介；保存成功/失败都有提示。
- **编辑时回填**（26.10.24 起）：打开编辑页会先拉 `x/v3/fav/folder/info` 回填简介与「公开/私密」（`attr` 的 bit0），保存时原样带回，不会再像以前那样把私密夹改成公开、把简介清空；默认收藏夹不可编辑。
- 删除要**点两次确认**（第一次提示"再次点击删除按钮确认删除"，3 秒内再点一次才删除）。
- **内容管理**（26.10.29 起）：管理页里有「批量删除内容」和「清空失效内容」两行，默认收藏夹同样可用（这两件事只认 `media_id`，与能否改名无关）。
  - 批量删除内容：跳到夹内内容页并**直接进入多选态**，勾选后删除；返回时收藏夹列表会重拉一次（数量变了）。
  - 清空失效内容：确认后 `POST x/v3/fav/resource/clean` 一次清掉夹内所有失效条目（稿件被删/私密/下架）。服务端没有"可清理数量"的接口，所以不做数量预检，也不会告诉你清了几条。

### 8.3 收藏夹里的视频

- 看收藏夹内视频列表，滑到底加载更多。
- **排序**：顶部可以按「收藏时间 / 播放量 / 投稿时间」重排列表。
- **批量管理**：进入多选后可以一次勾选多条，把它们「复制到其他收藏夹」「移动到其他收藏夹」或「取消收藏」。
- **虚拟合集连播**（默认开启）：点收藏夹里任意一个视频，会把整个收藏夹变成"合集"连续播放，从你点的那条开始。
- **遇到「文件夹」可以主动进去**：多P 视频和属于 UP 主合集（`ugc_season`）的视频都像"目录"。**点它们只会正常播放（不会自动换列表）**；打开选集卡片时，若当前这条能进得去，卡片上会多一行「进入分P（N 个）」或「进入合集 · 名字（N 集）」，**点了才进去**。进去后同一行变成「← 返回主合集」：点它回收藏夹继续；不点的话，里面的分P/剧集播完也会自动回到收藏夹。
  - 为什么不自动进：你只是想顺着收藏夹听的时候，自动进会被换成一门 105 讲课程的分P 列表，收藏夹里排在后面的条目全被跳过。
  - 合集进去后按**官方顺序**、并把合集里全部剧集（含你没收藏的、以及 UP 后补的）纳入列表；分P 进去后从**第 1 个分P** 开始（不记忆上次看到哪个分P）。
- **删除视频**（自己的收藏夹）：长按条目走「取消收藏」菜单，或进多选后批量删除；看别人的收藏夹是只读的，不能删。
- **长按菜单**：长按条目可「视频详情」（自己的收藏夹另有复制到/移动到/多选/取消收藏；别人的收藏夹只给「视频详情」）。
- **从管理页进来会直接开多选**：收藏夹列表长按 → 管理页 → 「批量删除内容」，进页面就是多选态（`selectMode` extra），少点一次。
- 说明：收藏夹内的**手动顺序调整**、给收藏夹本身排序、编辑夹封面等能力**本轮未实现**，列入下方 §8.5 计划。

### 8.4 图文收藏夹

- 分页看收藏的图文/动态：收藏时间、标题、封面；点击打开详情（内容已失效的会提示）。

### 8.5 尚未实现的收藏能力（计划）

## 9. 消息与评论

### 9.1 消息中心

- **四个通知入口**：回复我的、收到的赞、@我、系统通知，点哪个看哪个。
- **私信会话列表**：显示最近会话，有未读的排前面（显示头像、昵称、未读数）。
- **长按会话**：可以「置顶会话」「删除会话」或「查看对方主页」。置顶的会话会固定排在最上面。
- **设置入口**：右上角进"消息设置"。

### 9.2 消息设置

- 6 个开关（由 B 站服务端控制，可能随版本变化）：
  - 消息提醒（接收/不接收）；收起未关注人消息；折叠应援团消息；接收应援团消息；接收未关注用户消息；私信智能拦截（AI 过滤骚扰私信）。
- 改完自动保存，失败会提示并恢复。

### 9.3 通知列表（回复/赞/@/系统）

- 分别展示对应类型的通知，滑到底加载更多；系统通知一次加载全部。
- 「收到的赞」里能看到视频、评论、动态、专栏和**弹幕**被点赞；弹幕那条显示弹幕原文，点开跳到弹幕所在的视频。
- 「回复我的」里同样能看到**弹幕被回复**（别人回复你发的弹幕）：卡片显示弹幕原文，点开同样跳到弹幕所在的视频。

### 9.4 私信聊天

- **进入提示**：进入私信会提示"私信有可能被拦截，尽量不要用终端发私信喵"。
- **发文本消息**：输入内容点发送；成功提示并刷新；空输入提示"你还木有输入喵~"。
- **发图**：输入行有「图」按钮，点它打开内置选图页（见第 15 节）选一张图发出去。
- **撤回**：长按自己 2 分钟内发出的消息（文字或图片），菜单里选「撤回」；超过 2 分钟 B 站不允许撤回，菜单里就不会出现这一项。撤回后会话里显示「XXX 撤回了一条消息」，被撤回的原文不再显示（双方都是）。
- **长按复制**：长按别人的消息或超时的消息，直接进复制页（和以前一样）。
- **自动已读**：进入会话自动标记已读（可关）。
- **自动刷新**：每 15 秒自动拉新消息，新消息自动滚到底部。
- **加载更早**：滑到最顶部自动加载更早的消息。
- 说明：目前私信**不支持**发表情。

### 9.5 评论列表

- **排序**：最热 / 最新 切换。
- **下拉刷新 / 上滑加载**：加载更多评论。
- **楼中楼**：看某条评论的回复。
- **点赞 / 踩**：点赞和"踩"都能点，点了再点一下可以取消。
- **置顶自己的评论**：长按自己发的评论，可以「置顶」或「取消置顶」；同一个评论区只会保留一条置顶，被置顶的评论上有「置顶」标记。
- **举报别人的评论**：长按别人的评论（或点它末尾的操作按钮），面板里有「举报评论」。先在列表里选理由（违法违规 / 色情 / 低俗 / 赌博诈骗 / 违法信息外链 / 涉政谣言 / 虚假不实信息 / 涉社会事件谣言 / 人身攻击 / 侵犯隐私 / 垃圾广告 / 引战 / 剧透 / 刷屏 / 视频不相关 / 违规抽奖 / 青少年不良信息 / 其他）——这份列表**以服务端下发的为准**，连不上时用官方同一份兜底列表。选「其他」时还要补一句具体理由，**2-200 字符**，不够会提示并把你已经打的字留在输入框里，不用重打。提交成功提示「举报已提交，感谢你的反馈~」。**未登录时这一项照样显示**，点它会提示「请先登录后再举报」（不会白跑一次请求）；自己的评论、以及你能管理的评论不出现这一项（管理手段是删除）。
- **发评论即时显示**：发送成功的新评论会立刻插到列表里（不用刷新）。
- **UP 主/楼主标记**：UP 主或楼主自己看自己的评论时会有管理操作。
- **翻译（暂未开放，入口已隐藏）**：功能已实现，但「文A」按钮当前默认不显示（`ReplyTranslateApi.UI_ENABLED = false`）。原本的行为：点每条评论操作行的「文A」，把这条评论翻成**简体中文**（固定中文，不跟随系统语言），再点一下切回原文；译文只替换正文，点赞/回复/删除等操作不受影响。评论已经是中文、或服务端不支持翻译时提示「该评论暂无译文」。按条懒翻译（只翻你点的那条），不预取整页。外语评论→中文这条链路还没有样本做过真机验证，验证通过后把开关改回 `true` 即恢复显示。

### 9.6 评论详情（楼中楼）

- 某条根评论 + 它的所有楼中楼回复；排序可以在「时间 / 热度」之间切换；滑到底自动加载更多；回复成功即时插入。
- 详情页的根评论与下方每条回复行原本都带「文A」翻译按钮（入口暂未开放，见 §9.5），可各自单独翻译；根评论卡片里内嵌的楼中楼预览（纯文本行）没有按钮。

### 9.7 写评论

- **支持**：文字、@回复预填（"回复 @xxx :"）、表情、**带图评论**（仅大会员，最多 9 张图，选图自动压缩上传）。
- **KY 保护**：评论里提到"哔哩终端/终端"（还带 B站/bili/哔 等词）时会弹一次确认框（15 秒倒计时），确认后继续发送。
- **错误提示**：未登录、被拉黑、敏感内容、字数过多、重复刷屏等都有对应文案提示。

## 10. 缓存与下载

### 10.1 本地缓存（缓存管理）

- **两级目录**："未分类区 + 自己建的文件夹"，点文件夹进入，点顶栏/返回键退出。
- **顶部入口**：列表里的「下载列表」卡与「新建文件夹」按钮，随列表一起滚走。
- **空态**：没有视频时提示「啥都木有~」排在「未分类视频」标题下方的列表内，不再压住「新建文件夹」按钮。
- **下拉刷新**：重新扫描已下载的视频。
- **长按弹窗**：长按文件夹卡或视频卡弹出功能菜单（统一走 `util/TerminalDialog.kt`），不再是旧的右滑设置面板；点弹窗外空白或菜单底部「点空白处取消」都能关掉。
- **文件夹操作**：新建文件夹（名字 ≤30 字、不能有特殊字符）；长按文件夹卡弹「重命名 / 拆散文件夹（把里面的视频移回未分类）」。
- **视频操作**（长按视频卡弹出菜单，末项「删除视频」是危险色）：
  - 点击播放；**虚拟合集连播**：在文件夹里点一个视频，整个文件夹变成合集连续播放。
  - **断点续播**：缓存视频看到一半退出，下次点进来接着看（与在线视频共用「从历史位置播放」开关）；播完或看到最后几秒则下次从头播。
  - 菜单里依次是：更新弹幕（重新下载弹幕文件）、切换清晰度/重新下载（弹画质选择）、移动到文件夹（文件夹内则是「移出文件夹」）、查看详情（进视频详情页）、删除视频（弹确认框，不可恢复）。
- 缓存根目录、图片下载路径等都可以在设置里改。图片默认保存在应用专属目录，下载完成后会登记进系统媒体库（相册里能看到「哔哩终端」）；Android 10 以下仍直接写公共图片目录。只有把图片路径改到自定义公共目录时才需要「所有文件访问」权限——设置里为此保留了「去系统设置授予「所有文件访问」」入口，手表等没有该设置页的设备会继续用应用专属目录，下载不会因此失败。

### 10.2 下载列表（下载管理）

- **屏幕常亮**：下载时屏幕保持亮着。
- **点任务按状态操作**：下载中点一下=暂停；已暂停点一下=继续；失败点一下=重试。
- **长按删除任务**：长按两次确认（会先暂停、删文件、删记录）。
- **底部总进度条**：显示总体进度（已完成/总任务 百分比）、总速度（高速模式有"高速"前缀）、预计剩余时间；多个任务并行时显示"N并行"。
- **实时刷新**：每 0.4 秒自动更新进度。

### 10.3 缓存分 P 选择

- 本地合集视频选分 P 播放；长按分 P（两次确认）删除该分 P。

### 10.4 通用下载页

- 下载 APK/更新包时显示进度；下载完自动调系统安装器安装。
- **安装前校验**：装之前会核对这个包是不是本应用、签名对不对，不匹配就不装并给出提示（下载到一半的残片会被清掉，不会留着占地方）。
- 没下完就退出会自动清理残留文件。

### 10.5 下载服务（后台）

- **并行下载**：可设置同时下载 1~10 个任务。
- **多线程高速下载**：默认开启（可在设置里关），大文件自动分片多线程下载，失败自动重试；下载中途暂停不会丢进度。
- **高清缓存自动合成单文件（26.10.25 起）**：1080P 及以上是 DASH 音画分离的两条流，下载完成后自动**重封装**（只换容器、不重新编码）成一个 `video.mp4`，形态和 720P 单文件一样，播放器不用再挂外部音轨。
- **合并失败不毁结果**：容器层合并不了（极旧设备 / 特殊编码 / 磁盘不足）时保留原来的 `video.mp4` + `audio.m4a` 双文件，照样能播，这次下载也不算失败；以前的旧缓存双文件同样继续可播。
- **自动下附件**：封面、字幕（多语言）、弹幕。
- **通知栏进度**：下载时通知栏显示进度；下载完有完成通知。
- **防重复**：同一个视频已经在下载队列里会提示，不会重复加。

## 13. 登录与账号

### 13.1 登录（三种方式，可左右滑动切换）

- **扫码登录**：WEB 端 / TV 端两种（TV 端登录后权限更全，比如短视频功能）。扫一下手机 B 站 App 确认即可；二维码失效可点刷新，点二维码可切换大小。
- **密码登录**：账号 + 密码（加密传输），需要过极验人机验证。
- **短信登录**：手机号 + 验证码（60 秒倒计时重发），也需要人机验证。

### 13.2 账号切换

- 查看所有保存过的账号（头像、昵称、UID，当前账号有标记）。
- **点一下切换账号**；**长按删除账号**（确认后删除）。
- 底部"添加新账号"进登录页。

### 13.3 特殊登录（Cookie 导入/导出）

- **导出登录信息**：把自己的登录凭证打包成一段文本，可以复制出来，粘到另一台设备上用"特殊登录"导入，实现免密码换机登录。
- **导入登录**：粘贴那段文本即可登录。
- **粘贴并登录**：不想手动粘贴的话，直接点这个按钮，它会读你剪贴板里的登录信息帮你登录（按钮上方有一行说明）。读之前会先检查剪贴板：不是合法内容、缺字段、或者解析不出用户 ID，都只提示原因，不会写入登录状态。
- 处于「导出登录信息」模式时这个按钮会隐藏。

- **内测包（长按「检查更新」）**：长按设置 → 关于 → 「检查更新」会弹出纯数字内测码输入框（数字键盘 + 输入过滤，粘贴字母会被丢掉）；码会拼成 `https://share.lanol.cn/#/?code=<码>` 形式的分享链接，再到内测分享站（`file.zsapp.asia` / `share.lanol.cn` 两个域名，哪个有包就从哪个下）解析出 APK 直链并直接下载安装。内测包不做版本比较，下载后同样校验包名与签名。**内测码不存在、或对应的文件不是 `.apk`（分享站不校验上传内容，可能是一张图）时，一律只提示「内测码错误」**，不会再去下载；只有真的连不上分享站才提示网络原因。**文件名以 `.txt` 结尾时不装包**，而是把正文按「公告」的样式展示（标题取文件名去掉 `.txt`，页面与公告列表点开的是同一个 `ShowTextActivity`，支持长按复制）。
- 更新源按「Gitee 发行版 → GitHub 发行版」顺序尝试（都是公开仓库，读发行版不需要账号）；按设备 ABI 自动选对应分包的 APK（匹配不到用 universal）。

## 16. 全局基础能力

这些是全局生效的"地基"，不特定于某个页面：

- **全局主题与界面缩放**：7 套主题全局生效；界面大小/边距/Density 全局适配；圆屏适配。
- **禁用返回键**：设置开启后，全局按返回键无效。
- **隐藏/显示元素**：翻动时不加载图片、请求 JPG 图片等全局优化。
- **图片按性能下采样**：机器性能一般时，加载的图片会自动降一点清晰度，换得更流畅、更省流量。
- **性能自适应**：低性能设备自动减少动画、积极清理内存；高性能模式用资源换速度。
- **后台检查更新**：启动时自动检查新版本（可关），非强制更新会直接打开更新页（一个版本只自动打开一次）。
- **后台未读检查**：启动时检查动态/消息未读数，显示在主菜单红点上。
- **隐私模式**：开启后不记录观看状态。
- **长按顶栏打开菜单**：普通页面长按顶部标题栏（整条顶栏，不只是右侧）快速打开菜单列表。误触频繁时可在「设置 → 内容与浏览 → 通用偏好 → 长按顶部标题栏」选三档：**不响应**（全部页面都不响应）、**仅视频详情页**（只有视频详情页保留「关闭所有详情页」）、**全部页面**（默认：普通页面打开菜单列表，视频详情页长按关闭所有详情页）。
- **实体菜单键**：多数页面按实体菜单键=返回/开菜单。

## 17. 外观设置

「设置 → 界面与外观 → 外观设置」是一个独立页面，管六件事：

### 17.0 颜色模式

- 「暗色」（默认）/「亮色」两种模式，由你在这里手动切换（不跟随系统，手表上系统深浅设置不可靠）。7 套主题都有各自的亮色版：底色统一是米白（像纸），每套主题只带一丝自己的色调；经典终端是更深、更暖一点的旧纸色，配半透明卡片（「纸质终端」）。主题之间的区别主要在主色、光晕和玻璃质感上。
- 亮色和暗色一样不走极端：暗色不是纯黑，亮色也不是纯白，而是米白。
- 亮色下图标跟着主题的正文色走（Android 5.0 及以上），主色按钮上的文字是白色，开关的「关」态滑块是中灰。
- 亮色下爱奇艺绿、经典灰的主色加深一档，五彩斑斓的黄色强调色换成琥珀，保证白底上看得清。
- 弥散光晕、玻璃质感在亮色下也各有一套：光晕变成主色的淡彩晕染，玻璃变成白色磨砂。
- 播放器、开屏始终是暗色；短视频与看图页压在画面上的按钮保持白色。

### 17.1 主题配色

- 7 套主题任选：B站粉 / 知乎蓝 / 爱奇艺绿 / 紫色空灵 / 五彩斑斓 / 经典灰 / **经典终端**（黑底、半透明卡片、暖白文字，默认就是它）。
- 点一下立刻生效，不用重启。
- 点赞 / 投币 / 收藏的高亮、输入光标、链接、私信发送按钮、投票选中框、更新进度条等点缀色都跟着主题变，不再固定是粉色。

### 17.1a 弥散光晕

- 开关「弥散光晕」（默认关）：页面边缘铺一层柔和的主题色光晕，往内渐渐回到原来的背景色。
- 「光晕位置」：光晕最亮处可选在上（默认）/ 下 / 左 / 右 / 中间；选中间时光晕从屏幕中心向四周散开。
- 每套主题的光晕都不一样：知乎蓝是居中的深海蓝，紫色空灵多一团右侧余晖，五彩斑斓是左红右青双色，经典终端是酒红。
- 只用静态渐变绘制，没有模糊和动画，开销很小；关掉后与原来完全一样。

### 17.1b 玻璃质感

- 开关「玻璃质感」（默认关，可单独开）：卡片和按钮变成半透明，边缘带一道主题色亮边，光晕能透进来；和弥散光晕一起开效果最好。
- 已点亮的点赞 / 投币 / 收藏，图标背后会多一团小小的主题色光晕。
- 卡片仍保持约八成不透明，手表上小字照样看得清；经典终端只做了轻微调整，保留老版的黑底灰卡。

### 17.2 卡片圆角

- 两种风格：**方角** / **圆角**。喜欢方方正正就选方角，喜欢软一点就选圆角。

### 17.3 自定义字体

- 可以自己挑一个字体文件全局应用（支持 TTF / OTF / TTC）。
- 页面上会显示当前用的是哪个字体，没换过时显示「当前：系统默认」。
- 换错了也不怕：页面上有个常驻的「恢复系统字体」按钮，一点就回到系统字体。
- 这一页的选项都能被设置页顶部的搜索框搜到。

## 18. 通知与提醒

「设置 → 通知设置」是单独拎出来的一个分组，管两件事，默认都是开着的。

### 18.1 新消息通知

- 打开后，有新私信/新回复时会在通知栏提醒一次。
- **什么时候提醒**：只在你打开 App 检查未读、发现"未读数比上次多了"的时候提醒一次，**不做后台定时检查**（所以别指望 App 没打开还实时推）。
- 点通知直接进消息页。

### 18.2 追番更新提醒

- 追的番出了新一集时，在通知栏提醒一次。
- **什么时候提醒**：只在打开 App 时对比一下追番列表，发现最新一集变了才提醒一次，同样不做后台定时检查。
- 点通知直接进追番列表。

## 19. 伪装与安全

被人走近时想把屏幕"关掉又不像关掉应用"用的。**默认关闭**，开关在「设置 → 伪装与安全」。

### 19.1 双击顶栏一键伪装

- 开启后，**双击有顶栏的页面顶部标题栏**，立刻切到伪装页（比退出应用快得多，手上不用离开屏幕）。有少数页面（对话框、崩溃页、教程页等）布局里没有顶栏，那些页面上没有这个手势。
- 顶栏原来的单击（返回上一页 / 打开菜单）与长按（打开菜单列表）行为不变，只是单击会**多等一个双击判定窗口**（约 0.3 秒）——这也是默认关着的原因。

### 19.2 两种伪装样式

| 样式 | 长什么样 | 怎么退出 |
| --- | --- | --- |
| 计算器 | 真的能算的加减乘除计算器（深灰底、橙色运算符） | 输入暗号后按 `=` |
| 蓝牙已断开 | 假的系统提示「蓝牙已断开」，半透明盖在当前画面上，「重新连接」只会转一下 | 长按标题 2 秒 |

- 计算器页的**返回键只当清空**（`C`），不会退出。
- 蓝牙提示页的返回键完全没有反应。

### 19.3 退出暗号

- 默认 `1234`，可在设置里改成 4~8 位数字（改成非数字会提示并不保存——计算器上敲不出来就等于把自己锁在外面）。
- **忘了暗号只能强杀应用**：这是伪装能生效的代价，设置页的说明里也写着这句。

## 20. 反馈与隐私

这一节讲三件事：怎么给开发者提意见、App 会往服务器发什么、以及怎么全关掉。

### 20.1 反馈与建议（直接发给开发者）

- **在哪**：「设置 → 关于与帮助 → 反馈与建议」；关于页里也有一个同样的入口。
- **怎么用**：选一个反馈类型（功能异常 / 功能建议 / 内容问题 / 卡顿·耗电 / 其他），写下想说的话（最多 4000 字，输入框下面实时显示已写多少字），可以顺手留个联系方式方便回复你，然后点「发送反馈」。
- **发送成功**：提示「已收到，反馈编号：N」，输入框自动清空。
- **发送失败**：提示失败原因，你写的内容**还留在输入框里**，处理好网络再点一次就行，不用重新打一遍。
- **不用登录**：这条通道是本项目自己搭的（发到自建服务器，不经过 B 站），没登录也能发。
- **附带账号 ID**：默认**不带**。想带的话，可以在反馈页上打开开关，也可以去设置里全局打开（见 20.2）。
- **附带应用日志（26.10.16 起）**：反馈页上多了一个「附带应用日志」勾选框，**默认不勾**（发不发由你决定，且每次进页面都是关的）。勾上之后，会把你最近的应用运行日志随反馈一起发出去，方便开发者定位问题。日志在送出前已把 token、Cookie 之类的敏感字段打码（覆盖 `键=值`、URL 编码与 JSON 三种常见写法；打码在**落盘之前**做，导出的日志文件同样已打码）；只有你写的内容、版本号、机型和（勾选时的）日志会发出去，账号密码、Cookie 一律不发。
- **导出应用日志（26.10.16 起）**：反馈页上还有「导出应用日志」入口，会把同样的内存日志写成一个 txt 文件，走系统分享面板存到本地或发给别人——**这条只留在你本机、不经过网络**。
- **内容里发什么**：只有你写的内容、版本号和机型；账号密码、Cookie 这些一律不发。反馈页上也写了这段说明。
- 反馈页上还留了 QQ 群作为兜底渠道，习惯去群里说的照旧。
- **开发者可能单独回复你**：需要答复的反馈，开发者会写一条**只给你看**的回复。它以公告的形式出现在公告列表里，并在下次启动时弹给你，**其他用户看不到**。不需要你注册或留下账号——回复是认安装号/设备键下发的。
- **「我的反馈」能回头看，还能接着补充（26.10.16 起）**：你提交过的反馈可以在「我的反馈」里回看，含开发者的回复；对某条还想补充说明时，在详情页点「追加说明」就能接着说，详见 20.4。

### 20.2 匿名使用统计与崩溃自动上报

「设置 → 关于与帮助」里有一个「反馈与统计」小分组，里面三个开关：

- **匿名使用统计**（默认开）：启动时报一次"有人在用"，**一天最多一次**，而且只有上报成功才算数（断网启动不会白白浪费当天的机会）。用来数"有多少人装了、每天有多少人在用"。
- **崩溃自动上报**（默认开）：App 崩溃时自动把错误堆栈、版本号、机型和最近的页面记录发到同一台服务器，方便定位问题。关掉之后，崩溃页上的「手动上传堆栈」按钮照旧可用。
- **反馈附带账号 ID**（默认关）：打开后，你提交的反馈和崩溃报告会附上你的 UID。好处是能定位跟账号有关的问题，代价是这些上报能关联到你本人。

**关于"安装号"**：它是 App 自己随机生成的一串字符，跟你的账号没有关系；卸载重装就会换一个新的。服务器那边只拿 IP 做频率限制（防止被刷），不存 IP、也不存 Cookie。

**关于"设备键"（26.10.14 起）**：普通版和共存版的安装号是两个不同的值，为了让你在一台设备上装了两个版本时**只被算作一台设备**（而不是两台），App 会上报一个由系统匿名标识（ANDROID_ID）经**不可逆哈希**得到的短串。原始标识**不会上传、也不会存下来**，服务器只拿到哈希。恢复出厂设置或切换系统用户后它会变成新值，此时会被算作一台新设备。

### 20.3 隐私说明确认

- 全新安装（以及升级到新版本后）第一次启动时，会弹一次「隐私说明」，把上面两件事原原本本写清楚。
- **点「同意」**：开启匿名使用统计和崩溃自动上报（两个开关一起打开）。
- **点「不同意」**：App 照常使用，只是**什么都不会上报**——两个开关同时关掉；以后想开可以随时去设置里单独打开。
- 点哪个都能正常进 App。
- 这个弹窗只在隐私说明改版时才会再问一次，不会每次启动都烦你。
- 关于页和初始引导里那两句"不会收集任何隐私信息"的承诺文案，也已经按上面这些如实改过了。
- **26.10.14 起（隐私说明第 2 版）**：因为新增了上面说的"设备键"，三处公开承诺文案同步改成了「不上报原始设备标识，只上报一个仅用于设备去重的不可逆哈希」。升级到这一版后你会**再看到一次**隐私说明确认——这是有意的，文案变了就该重新让你过目。

### 20.4 我的反馈（看自己发过的反馈，还能接着补充，26.10.16 起）

- **在哪**：「设置 → 关于与帮助 → 反馈与统计 → 我的反馈」（设置页顶部搜索框搜「我的反馈」也能直达）。
- **能看什么**：你提交过的反馈列表（类型、时间、正文摘要、状态），点进去看单条反馈的完整正文，以及**你和开发者一来一回的对话**。
- **状态只有两种**：「**待受理**」和「**已受理**」。它表示开发者有没有看过、处理过这条反馈，**不是**「已解决 / 已修好」的意思——「无法复现」「不是 bug」这类也会被标成「已受理」，所以别把它当成修没修的结论。
- **追加说明（26.10.16 起）**：详情页底部有「追加说明」，点它弹出一个输入框，可以把复现步骤、补充信息再发给开发者（最多 2000 字）。发出去之后这条反馈会**重新变成「待受理」**，重新回到开发者的待办里——就像 GitHub 上追加评论会把 issue 重新打开一样。
- **对话怎么看**：开发者的回复和你的补充会按时间排在一起，各占一张卡片；你自己写的那些带一圈主题色描边，一眼能分清哪句是自己说的。只有开发者回复过时，小标题是「开发者回复」；一旦有来回，就变成「对话记录」。
- **发失败不丢内容**：网络不通时提示失败，然后**把输入框重新弹出来并填上你刚写的内容**，改好网络再点一次就行。
- **说过的话不能撤回**：没有删除自己补充的入口。这是有意的——中途删掉会让开发者看到的上下文缺一块，排查到一半线索就断了。
- **认领方式**：默认认你这台设备的安装号；如果在反馈页勾了「附带账号 ID」，换设备 / 重装后也能找回、并且能接着补充。没勾就只认本机。
- 这个入口挂在设置页，不需要新菜单项，老用户也能直接找到。
