# 26.11.09 矢量图兼容修复 人工验收单（5 条，约 10 分钟）

- 安装包：`app/build/outputs/apk/coexist/debug/app-coexist-universal-debug.apk`（共存版，不覆盖已装的正式版）
- 版本：debug 包（`appVersionDate` 派生，未发版）；对应提交 `git log --oneline -5 | grep -E "fix\(ui\)|test\(ui\)"`
- 前置：**一台 Android 4.4（API 19）设备最重要**；没有的话，任何 5.x / 6.x 老设备也能验「图标是否齐全」，但复现不了原崩溃。要登录（H01 登录页、H02 播放页都需要账号）
- 回结果：通过写 `- [x]`；不通过留空，并在旁边写一句「看到的是什么」

> 背景一句话：`vectorDrawables { useSupportLibrary true }` 下矢量图只能由 AppCompat 解析，
> 而布局里 `android:src` / `android:drawableStart` 这类原生属性在 API<21 会直接崩。
> 本次把全库 96 处改成 `app:*Compat`、播放页改用自定义控件 `VectorImageButton`。

## H01 过完教程进扫码登录页不再崩（原报障路径）

- **怎么做**：全新安装 → 走完首次教程 → 自动进入登录页（二维码页）→ 等 10 秒，点右上角帮助图标。
- **应该看到**：页面正常显示，二维码在转、帮助图标（问号）正常出现，点击能弹出帮助说明。
  **不应该**再闪退。
- **不算 bug**：没登录时二维码过期重试是正常的，不算。
- **AI 半自动**：AI 能验「进程没死 + 当前 Activity 是登录页」：`adb shell dumpsys activity activities | grep -i -E "LoginActivity|QRLogin"`；
  人判：帮助图标是否显示成问号（不是空白/错位）。
- **预计**：2 分钟

## H02 播放页 18 个按钮图标与高能进度条滑块

- **怎么做**：登录 → 打开任意视频（竖屏手表布局）→ 看底栏与侧栏按钮 → 拖一下高能进度条的滑块。
- **应该看到**：播放 / 暂停、锁定、设置、清晰度等按钮图标**全都在且有颜色**（不是空白方块、不是透明）；
  高能进度条的滑块有可见的圆点。
- **不算 bug**：某个按钮按当前状态被隐藏（比如未登录时不显示某入口）不算。
- **AI 断言**：`adb shell dumpsys activity activities | grep -i PlayerActivity` 能确认页面起来了；
  图标是否画出来只能人看（`screencap` 里能数出来，但 AI 不判「好不好看」）。
- **预计**：3 分钟

## H03 各页行内图标齐全（`MarqueeTextView` 换基类后的回归）

- **怎么做**：依次看：播放页顶栏（返回箭头）、视频详情页（UP 主 / 关注等行内图标）、设置页（搜索框、各分组右侧箭头）、
  账号切换页（右侧前进箭头）、本地缓存页（进入/退出文件夹时顶栏的左/下箭头）。
- **应该看到**：每处图标都正常显示、与文字垂直居中对齐；**不能出现「只有文字没有图标」**。
- **不算 bug**：焦点态颜色略变、按下有水波纹属正常。
- **AI 半自动**：控件树里能读到 TextView 的 `drawableLeft`/`drawableStart` 非空（`adb shell uiautomator dump` 读不到 Drawable，
  只能人看；AI 可验证「文字在、行高没塌」）。
- **预计**：3 分钟

## H04 暗色 / 亮色两套主题下图标颜色都正常

- **怎么做**：设置 → 外观 → 切「亮色」，重进 H02 / H03 的几个页面；再切回「暗色」。
- **应该看到**：两种模式下图标都清晰可见（暗色下是浅色图标、亮色下是深色图标），不会出现「白底白图标」或「黑底黑图标」。
- **不算 bug**：压在视频/图片上的图标按设计始终是白色，不算。
- **AI 判不了**：颜色观感只能人判。
- **预计**：2 分钟

## H05 （可选，仅 API 19 设备）崩溃复现对照

- **怎么做**：用**修复前的包**（`26.11.09` 已发布版本）在同一台 4.4 设备上走一遍 H01。
- **应该看到**：旧包会在进登录页时闪退（`InflateException` / `Resources$NotFoundException`），新包不崩。
  这条只是给「到底修没修好」留个对照。
- **不算 bug**：旧包崩属预期。
- **AI 断言**：`adb logcat -b crash -d | grep -E "InflateException|invalid drawable tag vector"`——
  旧包必有、新包必无。
- **预计**：2 分钟
