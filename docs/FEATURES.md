## 1. 打开 App 与主菜单

### 1.1 启动页（开机画面）

- **开机动画**：打开 App 时，屏幕会以"打字机"效果一个字一个字地打出欢迎语（默认是「欢迎使用 RE:哔哩终端」，内容可在设置里改）。
- **自动检查登录状态**：启动时会后台检查登录信息是否过期，过期会提示重新登录；同时检查有没有新版本、有没有新动态/新消息（用于菜单上的红点数）。

### 1.2 主菜单（首页九宫格）

- **进入各功能**：主菜单列出 14 个入口：推荐、短视频、热门、入站必刷、全站排行榜、热搜、直播、时间线、搜索、动态、我的、消息、缓存、设置。点一下即可进入对应页面。
- **菜单顺序可调**：在「设置 → 内容与浏览 → 菜单设置」里可以调整菜单项顺序、把不常用的移入"未启用"区。
- **未登录时**：菜单顶部会出现「登录」按钮，同时隐藏「动态」「消息」「我的」三个入口。
- **红点提示**：「动态」和「消息」按钮上会显示未读数量（有更新时显示数字）。
- **退出菜单**：按实体菜单键，或点屏幕顶部，即可收起菜单。

### 1.3 用链接打开内容（分享/跳转）

- 从浏览器或其它 App 点击 B 站视频/专栏链接，可以用「RE:哔哩终端」打开（支持 http、https、bilibili 开头的链接）。
- 也支持直接打开指定类型：视频（AV/BV 号）、专栏、用户主页。

## 2. 看视频：推荐 / 热门 / 排行榜等

### 2.1 推荐页

- **往下拉刷新**：手往下拉，换一批新推荐。
- **一直往下滑**：滑到底部会自动加载更多推荐视频。
- **自动去重**：同一个视频不会重复出现在推荐流里（已看过的不会反复推）。
- **首次使用提示**：第一次进推荐页会有新手引导气泡。

### 2.2 热门页

- 看 B 站热门视频，往下拉刷新，滑到底自动加载下一页；滚动时图片按需加载（更省流量、更流畅）。

### 2.3 入站必刷页

- 看「入站必刷」经典视频，用法和热门页一样（下拉刷新、滑动翻页）。

### 2.4 全站排行榜

- 看全站排行榜（一次加载完整榜单，不分页）。
- 说明：当前版本榜单固定为"全站"类别，没有分区切换。

### 2.5 时间线（追番日历）

- 按天展示追番的播出时间线（当前固定展示"追番"类型）。
- 往下拉刷新；没有数据时显示空提示；加载失败会提示。

### 2.6 热搜榜

- 看 B 站热搜词，往下拉刷新。
- 注意：热搜词点击后跳转的行为由列表项自身处理。

### 2.7 短视频（竖屏信息流）

- **上下滑动**：像刷抖音一样上下滑切换短视频，松手自动播放当前视频。
- **预加载**：提前加载后面几条，切换更流畅。
- **单击画面**：显示/隐藏底部控制栏。
- **双击画面**：播放/暂停。
- **长按画面**：打开这条视频的详情页。
- **双指缩放**：双指捏合可把画面放大 1~3 倍。
- **底部控制栏**（不操作 10 秒自动隐藏）：
  - 播放/暂停按钮（快看完时点播放会从头再播）。
  - 弹幕开关（开/关弹幕）。
  - 音量加/减（调系统音量，会提示"音量：N%"）。
  - 倍速（循环切换 0.5~2.0 倍）。
  - 进度条（拖动快进快退）。
  - 顶栏返回（退出）。
- **看完自动循环**：一条播完自动重播。
- **只播当前页**：滑走的视频会暂停，节省流量。

## 3. 视频详情页与播放器

### 3.1 视频详情页（整体）

- **左右滑动翻页**：详情页内可以左右滑动，在「简介 / 评论 / 相关推荐」之间切换（相关推荐可在设置里关闭）。
- **从评论定位**：如果是从某条评论链接进来的，会自动跳到评论区并定位到那条评论。
- **长按顶栏返回首页**：在任意视频详情页长按顶部，可以一键关闭所有详情页、回到主页面。
- **番剧详情**：打开番剧时展示的是番剧版详情页（封面、评分、选集等）。

### 3.2 视频简介页（详情首页）

- **封面**：点封面直接播放（可在设置里改成"点击看大图"）；长按封面看大图。
- **标题徽章**：充电专属、互动视频、全景视频、联合投稿的视频，标题旁有对应小标签。
- **长按复制**：标题、BV 号、简介都可以长按复制。
- **标签**：点一下标签文字可展开/收起全部标签；点单个标签会用这个标签去搜索。
- **点赞 / 投币 / 收藏**：分别点对应图标即可；**一键三连 = 长按点赞图标 2 秒**（期间松手可取消），成功后三个图标全亮。
  - 未登录时点击会提示"还没有登录喵~"。
- **数据统计**：显示播放量、点赞/投币/收藏数（上万会显示成"xx万"）、弹幕数、发布时间、时长；有"独家/争议"提示时会显示提示条。
- **UP 主区**：横向展示全部 UP 主（含联合投稿），点一个进他的主页。
- **简介**：点一下在"3 行 / 全部"之间切换；简介里的网址、@用户名可以直接点；长按复制。
- **播放按钮**：点播放直接进播放器；多 P 视频会先让你选分 P；长按播放按钮可换播放器。
- **稍后再看**：点"稍后再看"加入列表；长按它直接查看稍后再看列表。
- **下载**：点下载开始缓存（会先要存储权限、安卓 13+ 还要通知权限）；多 P 视频先选分 P；长按下载按钮 = 清除这个视频的缓存文件夹。
- **转发**：点转发可以把视频转发成动态（支持 @ 人）；长按转发 = 复制视频链接。
- **AI 视频摘要**（需登录）：点"视频摘要"一键生成这个视频的 AI 内容总结，弹窗显示。
- **合集入口**：视频属于某个合集时显示「合集 · 标题」，点击进合集页。
- **自动上报观看进度**：进入详情页就会预取播放地址并上报播放历史。

### 3.3 相关推荐

- 详情页第三页，展示和当前视频相关的推荐，滑到底加载更多。

### 3.4 番剧详情页

- **基本信息**：封面大图（点开看大图）、标题、地区/类型、评分、播出状态（已完结/连载中）、播放/收藏/追番数、标签、备案号。
- **简介 / STAFF（制作人员）**：点标题头展开/收起。
- **选集**：横向一排分集，点哪集看哪集（评论区也会跟着切到那一集）；也可以点按钮弹窗选"卷/集"。
- **播放**：点播放进播放器；长按播放可换播放器。

### 3.5 添加收藏

- 从视频详情页点"收藏"进入：勾选要加入的收藏夹（能看到每个收藏夹已存/上限数量），点返回即完成；全部取消勾选 = 取消收藏。
- 结果会即时反映在详情页的收藏图标上（收藏成功/删除成功会有提示，可在设置里关）。

### 3.6 视频播放器（最核心的页面）

**进入播放器后，你能做的操作：**

**手势（多数可在设置里开关）：**
- **单击**：显示/隐藏控制栏（4 秒无操作自动隐藏）。
- **双击屏幕中间**：播放/暂停（设置里开了"双击优先还原屏幕"时，横屏下双击先回竖屏）。
- **双击屏幕左右 1/3**：快退/快进（默认 10 秒，秒数可调）。
- **长按画面**：3 倍速快进，松手恢复原速。
- **双指缩放**：画面可放大 1~5 倍。
- **双指/单指拖动**：放大后可以拖动画面位置；快速双击可复位画面。

**控制栏按钮：**
- 播放/暂停；循环（单集循环）；旋转（横竖屏切换）；"更多"菜单（展开第二排按钮）。
- 发弹幕（输入文字，在当前进度发送）；弹幕开关（隐藏/显示弹幕）。
- 字幕（选择字幕轨道，支持 AI 字幕）；听视频模式（关画面只听声音）。
- 分 P 选择（多 P 时出现）；自动连播（多 P 播完自动下一 P）。
- 清晰度切换；分段（看点）跳转；音量加/减。
- 短视频模式下有"查看视频详情"按钮；互动视频有"调试"按钮（需在设置开启）。

**倍速**：控制栏显示当前倍速（如 x1.0），点它弹出滑条，0.5~3.0 倍随便调，松手自动收起。

**进度条**：
- 拖动跳转；显示缓冲进度。
- 高能进度条（设置里开启后显示粉色高能曲线）。
- 续播：上次没看完的，再打开自动从上次位置播放（可设置关闭）。

**弹幕**：
- 自动加载弹幕（新版接口，失败自动退回旧接口）。
- 弹幕样式（行数、字号、透明度、速度、是否重叠、是否合并重复等）都在"内置播放器设置"里调。
- 可以发送弹幕。

**直播模式**：看直播时隐藏进度条等控件，显示在线人数，走直播弹幕通道；弹幕会显示发送者昵称（可关）。

**互动视频**：播放到选项时会弹出选择卡片，选了分支继续播；条件分支按你之前的选项自动跳。

**系统按键（遥控器/实体键）**：
- 确认键：播放/暂停；左右方向键：快退/快进 10 秒；上下方向键：音量。

**其它**：
- 支持系统媒体控制（锁屏/通知栏可控制播放暂停、切 P）。
- 看直播/视频时可显示"实时观看人数"（设置里开）。
- 圆屏手表上播放界面会重新适配布局。
- 退出时把当前进度、弹幕开关、清晰度等状态回传给上一个页面。

### 3.7 分 P 选择、清晰度选择、互动调试

- **分 P 选择**：多 P 视频在详情页点播放/下载时，先弹分 P 列表选择。
- **清晰度选择**：下载视频前选择缓存清晰度（360P/720P/1080P 等）。
- **互动视频调试**：仅开发者/调试场景使用，用于查看互动视频的隐藏变量。

## 4. 搜索

### 4.1 搜索主页

- **搜索框**：输入关键词，点搜索按钮或按键盘回车即可搜索。
- **搜索按钮长按（隐藏技巧）**：长按搜索按钮，可以直接把输入框里的内容当"AV 号 / BV 号 / 用户 ID / 链接"跳转到对应页面。
- **历史记录**：点搜索框自动显示历史搜索词；点历史词回填；长按历史词删除单条；搜索过的词自动记到最前面。
- **搜索建议**：输入时实时出联想词（可关闭），点联想词直接搜。
- **默认搜索内容**：设置里开启后，没输入时搜索框会显示一个默认提示词。
- **分类切换**：顶部是「视频 / 专栏 / 用户 / 音频 / 直播」几个分类，左右滑动切换（分类显示与顺序可在设置里调）。
- **搜索栏自动隐藏**：往下滑列表时搜索栏收起来，往上滑回来。
- **彩蛋**：搜索某些特殊词（比如带"Robin"的某些组合、心理相关的暖心词、特定人名）会弹出彩蛋提示，而不是真的搜索。

### 4.2 各分类搜索结果

- **视频**：视频卡片列表，滑到底加载更多。
- **专栏**：专栏文章卡片列表。
- **用户**：用户列表，点进用户主页。
- **音频**：音频条目（标题、作者、时长），点击直接播放。
- **直播**：直播间列表，点击进入直播间。

### 4.3 热搜

- 查看 B 站热搜词，下拉刷新（热搜一次加载全部，不分页）。

## 5. 动态（B站朋友圈）

### 5.1 动态列表

- **分区 Tab**：顶部可切「全部 / 视频投稿 / 追番 / 专栏」类型；切换时如果还在加载会提示"还在加载中OvO"。
- **下拉刷新 / 上滑加载**：刷新后新动态会插到前面；滑到底自动加载更早的动态。
- **最近更新 UP 主**：列表顶部会显示最近更新的 UP 主横条（可关闭），点一个直接进他的动态。
- **发动态**：右上角发动态，支持文字 + 表情 + @ 人；发布成功后会立刻显示在列表顶部。
- **转发**：可以转发动态/视频（转发时支持 @ 人）。
- **删除联动**：在动态详情里删掉一条，返回列表会自动移除。
- **红点清零**：刷新后动态页的未读红点会消失。

### 5.2 动态详情

- **左右滑动**：在"动态内容"和"评论区"之间切换。
- **点赞 / 评论 / 转发**：动态卡片上的按钮直接操作。
- **删除自己的动态**：长按删除按钮删除。
- **转发子动态**：被转发的内容以子卡片展示，点它跳回原动态。

### 5.3 发动态页

- **未登录提示**：没登录会提示"还没有登录喵~"。
- **输入正文**：支持表情（从表情包选）、转发预览（转发动态/视频时会先展示卡片）。
- **登录状态校验**：Cookie 刷新失败时不允许发送。

## 6. 直播

### 6.1 推荐直播 / 关注直播

- 两个列表页：看推荐的直播间、看自己关注的直播间（关注列表为空时有空提示）。
- 下拉刷新、滑到底加载更多；点卡片进直播间。

### 6.2 直播间详情

- **封面**：点封面看大图。
- **主播信息**：主播卡片，点击进主播主页。
- **信息展示**：标题、观看人数、开播时间、房间号（有短号会显示）、标签、分区、关注数、直播状态（未开播/直播中/轮播中）。
- **标签/简介展开**：点一下展开/收起；房间号、标签、标题长按可复制。
- **播放**：点"播放"进播放器看直播（选好清晰度和线路）。
  - 直播已结束会提示"直播已结束"。
  - 长按播放按钮可换播放器；非内置播放器会提示可能播不了直播。
- **清晰度**：切换清晰度（重新拉取播放地址）。
- **线路（CDN）**：切换"路线1/路线2/..."，网络卡顿可以换线路。

## 7. 我的空间与个人主页

### 7.1 我的空间（个人中心）

- **未登录**：顶部显示"点击登录"；已登录则显示头像、昵称、粉丝数、硬币数、经验值（点击顶部进自己主页）。
- **功能入口**（每个都是一张卡片，点了就进）：
  - 个人信息（自己的主页）、关注、稍后再看、收藏、追番列表、我的歌单、历史记录、创作中心（需在设置开启才显示）、大会员、登录记录、硬币变化记录、经验变化记录、编辑个人资料、修改个人描述。
- **退出登录**：点"退出登录"会要求**再点一次确认**（第一次点会提示"再点一次退出登录！"），第二次才真正退出并清空登录信息。

### 7.2 用户主页（他人主页）

- **四个 Tab**：动态 / 视频 / 专栏 / 收藏夹，左右滑动切换。
- **用户资料头部**（在动态 Tab 顶部）：
  - 头像（点开看原图）、昵称（大会员有专属颜色）、等级徽章、大会员标签（月度/年度/十年/百年）。

## 10. 缓存与下载

### 10.1 本地缓存（缓存管理）

- **两级目录**："未分类区 + 自己建的文件夹"，点文件夹进入，点顶栏/返回键退出。
- **下拉刷新**：重新扫描已下载的视频。
- **文件夹操作**：新建文件夹（名字 ≤30 字、不能有特殊字符）、重命名、拆散（把里面的视频移回未分类）、删除。
- **视频操作**：
  - 点击播放；**虚拟合集连播**：在文件夹里点一个视频，整个文件夹变成合集连续播放。
  - 更新弹幕（重新下载弹幕文件）。
  - 切换清晰度/重新下载（弹画质选择）。
  - 查看详情（进视频详情页）。
  - 删除：点删除按钮（确认）或**长按两次**（4 秒内，免确认）。
  - 移动到文件夹 / 移出文件夹。
- 缓存根目录、图片下载路径等都可以在设置里改。

### 10.2 下载列表（下载管理）

- **屏幕常亮**：下载时屏幕保持亮着。
- **点任务按状态操作**：下载中点一下=暂停；已暂停点一下=继续；失败点一下=重试。
- **长按删除任务**：长按两次确认（会先暂停、删文件、删记录）。
- **底部总进度条**：显示总体进度（已完成/总任务 百分比）、总速度（高速模式有"高速"前缀）、预计剩余时间；多个任务并行时显示"N并行"。
- **实时刷新**：每 0.4 秒自动更新进度。

### 10.3 缓存分 P 选择

- 本地合集视频选分 P 播放；长按分 P（两次确认）删除该分 P。

### 10.4 通用下载页

- 下载 APK/更新包时显示进度；下载完自动调系统安装器安装。
- 没下完就退出会自动清理残留文件。

### 10.5 下载服务（后台）

- **并行下载**：可设置同时下载 1~10 个任务。
- **多线程高速下载**：默认开启（可在设置里关），大文件自动分片多线程下载，失败自动重试；下载中途暂停不会丢进度。
- **DASH 音画分离**：高清视频自动同时下载视频+音频两份，保存为可直接播放的双文件。
- **自动下附件**：封面、字幕（多语言）、弹幕。
- **通知栏进度**：下载时通知栏显示进度；下载完有完成通知。
- **防重复**：同一个视频已经在下载队列里会提示，不会重复加。

## 15. 通用小工具（对话框/看图/表情等）

这些是 App 内部复用的"小零件"，很多页面都会用到：

- **信息对话框**：提示文字，有时带倒计时（倒计时结束才能点"知道了"），必须点按钮关闭。
- **确认对话框**：问"确定/取消"。
- **列表选择对话框**：从列表选一项。
- **文本输入对话框**：弹一个输入框（会预填内容）。
- **列表单选页**：一列选项单选（设置页常用）。
- **图片查看器**：全屏看图，双指缩放（最大 6.25 倍），左右滑切换多图，底部显示"第 x/N 张"；**下载图片**：3 秒内连点两次"下载"按钮（第一次提示"再次点击下载"）保存到图片下载目录。
- **表情选择**：选表情包（按业务区分：评论/动态等），点表情直接插入。
- **文本显示页**：纯文字展示，支持复制；有的内容里还能内嵌视频卡片。
- **复制文本片段**：输入起止位置，复制指定片段（可微调起止）。
- **新手教程弹层**：首次使用某页面时弹出的引导（3 秒后才能点"已阅"，不能跳过返回）。
- **崩溃捕获页**：App 闪退后自动弹出，显示崩溃原因分类（数值转换/库加载/解析/内存/未知），可上传堆栈、重启或退出。

## 16. 全局基础能力

这些是全局生效的"地基"，不特定于某个页面：

- **全局主题与界面缩放**：6 套主题全局生效；界面大小/边距/Density 全局适配；圆屏适配。
- **禁用返回键**：设置开启后，全局按返回键无效。
- **隐藏/显示元素**：翻动时不加载图片、请求 JPG 图片等全局优化。
- **性能自适应**：低性能设备自动减少动画、积极清理内存；高性能模式用资源换速度。
- **后台检查更新**：启动时自动检查新版本（可关），有新版本会提示。
- **后台未读检查**：启动时检查动态/消息未读数，显示在主菜单红点上。
- **隐私模式**：开启后不记录观看状态。
- **长按右上角返回主页**：任意页面长按顶部标题栏右侧，快速回到主页面（视频详情页是关闭所有详情页）。
- **实体菜单键**：多数页面按实体菜单键=返回/开菜单。
