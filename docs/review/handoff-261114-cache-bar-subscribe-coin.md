# 缓存页底部栏 / 订阅取消 / 硬币流水 人工验收单（3 条，约 5 分钟）

- 安装包：`app/build/outputs/apk/standard/debug/app-standard-universal-debug.apk`（共存版同源码，换成 `app-coexist-universal-debug.apk` 也一样）
- 版本：`26.11.09` 的修复包（分支已 rebase 到上游最新 `main`），commit 见本 PR 的 HEAD
- 前置：H03 需要登录；H01 / H02 不用。
- 回结果：通过写 `- [x]`；不通过留空，并在旁边写一句「看到的是什么」。

## H01 缓存页的「多选 / 排序 / 搜索」一排会跟着列表收走

- **怎么做**：进「我的 → 本地缓存」（要有已下载的缓存视频）→ 手指往上滑一屏。
- **应该看到**：底部那一排（多选 / 排序 / 搜索）随手指**收走**，列表多用出一行高度；往回滑到**顶**时，这一排再滑回来。
- **不算 bug**：滑动累计不到一小段（约 12px）时不动，这是防手抖的阈值；快速甩动时动画 180ms，看起来是「唰」地收走。
- **必须一起确认的**：点「多选」进多选态后**再滑列表**，这一排**不许收走**（收走就点不到「操作」了）；「排序」态同理。
- **预计**：1 分钟

## H02 订阅页长按「订阅合集」→ 确定能点到、弹窗正常关

- **怎么做**：进「我的 → 我的订阅」→ **长按**任意一条订阅合集 → 弹窗里点「确定」。
- **应该看到**：弹窗正常关闭、提示「已取消订阅」、该条从列表消失。
- **不算 bug**：取消订阅要联网，慢一点才消失；失败会提示错误码，不会静默失败。
- **这条上游 26.11.13 已经修过**：弹窗按钮从横排改成**每个按钮独占一整行**、整块按钮区永远在滚动区之外，`Sheet` 的 `bottomButtonBar` 参数也一并删了（旧横排下每个按钮只占按钮行右端、左右各留一大段死区，输入层一偏就「点左执行右」）。本包已含上游那个修法，这里只是**顺手复核**，不是本 PR 新修的东西。
- **顺带看一眼**：同页长按一条**收藏夹**订阅（标题通常较短）点「确定」也要一样正常。
- **预计**：1 分钟

## H03 硬币变化记录里「打赏」的变化量不再是 0

- **怎么做**：进「我的 → 硬币变化记录」→ 找到「给视频 xxx 打赏」那几条。
- **应该看到**：变化量显示成官方那种整数（`-1` / `-2`），不再是 `0`。
- **顺手对照一下**：如果同一周有「打赏收入」这类**正的小数**，应该原样显示成 `+0.1` / `+0.2`（不要跟着变成 `+1`）——正数侧按接口原样显示是刻意的。
- **不算 bug**：这条接口**只能查最近一周**；一周内没有打赏记录就看不到现象，等有记录时再看。
- **预计**：1 分钟

## 已知限制

- 底部栏收放是**手感**项：收得太急、或者展开不跟手都算不合格，用文字描述一下感受即可（这类只能人判）。
- 硬币流水那条「0.1 硬币为单位」是**推断**（接口要登录态才能实测，且只能查最近一周）：看到真实数值和官方不一致就回报一张截图，改一处 `util/CoinLogDelta.kt` 即可。
