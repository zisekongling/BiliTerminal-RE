## 1. 装之前先看这几条

1. **两个包都注入了 `private/`（私有功能）**，所以两个包都带可选私有功能，和线上发版包不是逐字节相同；第三方换源 / 第三方弹幕代理在本机**只注入了 `KAZUMI_APPID` / `DANDANAPI_APPID`、没有对应 KEY**，这两项能力若不可用属预期，别当本包缺陷报（见 §7）。
2. **`versionCode` 与线上已发的 `26.11.07.1` 相同**（2611071）：装上去**不会**弹「发现新版本」——这是好事，测试期间不被更新提示干扰；但也意味着这批改动目前**没有任何版本号背书**，测完发版才需要升 versionCode。
3. **普通版可以直接覆盖升级**：同签名同包名，`adb install -r` 即可，登录态、设置、`/Android/media/<包名>/` 缓存都保留。
4. **调试共存版要单独登录**：包名带 `.coexist`，数据天然隔离。如果手表上已经装过**线上共存版 release**（release 签名），debug 包签名不同装不上，得先卸载旧共存版（会清掉那份登录态）。
5. **主功能验收用 release 普通版**（用户视角、R8 混淆后、无调试日志）；**要看日志 / 用调试桥 / 复现崩溃细节时用 debug 共存版**（`BuildConfig.DEBUG` 打开日志开关，`DebugBridge` 只在 debug 包里，见 `agent-test-guide.md` §2）。
6. 装包命令：

   ```powershell
   adb install -r outputs/testbuild-261108/app-standard-arm64-v8a-release.apk
   adb install -r outputs/testbuild-261108/app-coexist-arm64-v8a-debug.apk
   ```
