# 26.11.14-exp.6 补测单（三档跳过设置 / 进度条标记与跳过解耦 / 时间括号 / 详情页胶囊 / 首次加载）

这一版把「跳过」整条链路重做了一遍，同时补了上一版报障的三处。本单只写**这一版要人看的**，
已经验过的老项只列回归勾选。

## 一、版本与安装

| 项目 | 值 |
| --- | --- |
| 版本名 | `26.11.14-exp.6` |
| versionCode | `26111426` |
| 普通版 | `app/build/outputs/apk/standard/release/app-standard-arm64-v8a-release.apk` |
| 共存版 | `app/build/outputs/apk/coexist/release/app-coexist-arm64-v8a-release.apk` |
| 兜底 | 同目录 `…-universal-release.apk`（其它 ABI 或分包装不上时用） |

- **本版是 exp.6**：exp.2 有一处致命问题（「跳过设置」里的档位选完不落盘、行上仍显示「关闭」），exp.3 已修；exp.4 把**进度条标记单独拆成一个设置**并补了参考色块与精彩时刻三角开关；exp.5 把色块挪到「标记哪些类别」页；exp.6 修「第一次进视频有概率加载不出来」。**用 exp.6 测**，exp.2~exp.5 上的现象不必再复现。
- 覆盖安装上一版即可，**不用清数据**：旧的「六档 + 逐类别勾选」会在首次读设置时折算成逐类别三档。
- 手表装 arm64 或 universal；手机一般也是 arm64。

## 二、这一版比 exp.1 多了什么

| 项目 | 变化 |
| --- | --- |
| 跳过档位 | 六档 + 「要跳的类别」子页 → **11 个类别各自三档**（关闭 / 询问我 / 自动跳转），子页删除 |
| 设置入口 | 「完整设置 → 播放器 → 自动跳过」→ **「选择播放器」页的「跳过设置」二级页**（在「播放器界面」与「清晰度」之间） |
| 询问我 | 新增：到点弹一条「这里有广告，要跳过去吗？」+「跳过」按钮 |
| 老存档 | 六档一次性折算成三档，折算前后实际跳的段落一致 |
| 进度条条子 | 加诊断日志；`video_all` 就绪后再重落一次标记（上一版「看不到条子」的怀疑点） |
| 时间括号 | 新增：`00:31 / 01:43 (1:34)` 里的括号＝扣掉要跳的时长后的剩余 |
| 详情页胶囊 | 新增：视频详情页标题前的「广告」/「含广告」 |
| 进度条标记（exp.4） | 与三档**彻底解耦**：条子总开关 + 「标记哪些类别」子页 + 「标出精彩时刻」三角开关，三个各自独立存档 |
| 参考色 | 「标记哪些类别」页里每个类别行左边一个 10dp 色块，就是它在进度条上的颜色（exp.4 起在「跳过设置」的类别行，后按用户要求挪到这一页） |
| 参考色挪位（exp.5） | 色块从「跳过设置」的类别行挪到「标记哪些类别」页的开头，三档行不再带色块 |
| 首次加载（exp.6） | 修「第一次进视频有概率没数据、重进才行」：响应回来强制重建片段表；拿不到 bvid / 网络失败都会在 3s / 15s 后重试；404（没有标注）不再重试 |

## 五、B 组：三档行为（约 8 分钟，主力）

前置：删掉旧数据或直接用 exp.1 升级（两种都要试一次折算，见 E 组）。

| 编号 | 怎么做 | 应该看到 |
| --- | --- | --- |
| B01 | 只把「广告」设成**自动跳转**，其它全关；打开 `BV13yW16VEGT` | 进度条 32% 处一条琥珀条；播到 34 秒直接跳到 47.5 秒，底部留「不准」 |
| B02 | 同上但设成**询问我** | 到 34 秒弹「这里有广告，要跳过去吗？」+「跳过」；点「跳过」才跳走 |
| B03 | B02 弹了**不理它** | 几秒后提示自己消失，继续播完这段；同一段不会反复弹 |
| B04 | 手动拖回 34 秒内再看 | 同一段**不再弹第二次**（本次播放内只问一次） |
| B05 | 全部类别设**关闭**，打开 `BV13yW16VEGT` | 没有任何条子、时间不带括号；日志里**没有** `SponsorBlockApi` 的请求（判据见 §九） |
| B06 | 打开任意**番剧**一集 | 三档完全不生效（不弹询问、不画条子），只有原来的「片头片尾」五档起作用；日志无广告标注请求 |
| B07 | 只把「广告」设自动，看 `BV11Kc2zZEDK`（只有片头标注） | **一条条子都没有**——类别不匹配就该是空的，这不是 bug |
| B08 | B01 之后**不退出播放页**，直接去设置把「广告」改回关闭再返回 | 条子与括号当场消失，不再跳（设置改动即时生效，不必重进播放页） |

## 十、G 组：进度条标记与跳过解耦（exp.4 新增，约 6 分钟，主力）

这一组验的是「条子」和「跳不跳」两件事能不能各干各的。**改设置后回播放页观察即可，不必重装应用**。

| 编号 | 怎么做 | 应该看到 |
| --- | --- | --- |
| G01 | 进「跳过设置」 | 页面变成四块：片头片尾 / 广告片段（10 个类别）/ **进度条标记**（总开关 + 「标记哪些类别」+ 「标出精彩时刻」）/ 清除「不准」记录；三档的类别行**不带**色块 |
| G02 | 进「标记哪些类别」 | 每行左边一个 10dp 色块，10 类颜色互不相同；再对色：把「广告」设自动、播 `BV13yW16VEGT`，条子颜色 = 这一页「广告」那行的色块色；把「自我推广」也设自动后，两类条子颜色一眼能分开 |
| G03 | **只显示不跳**：10 个类别全部「关闭」，只留「标出会被跳过的片段」开着 | 进度条上仍有条子，但播到 34 秒**不跳**、不弹「不准」、不弹「询问」 |
| G04 | **只跳不显示**：三档照旧开着，关掉「标出会被跳过的片段」 | 进度条干净，播到 34 秒照样跳走、「不准」按钮与时间括号都还在 |
| G05 | 「标记哪些类别」里只勾「广告」 | 只画广告那类；把「广告」取消勾选后回播放页，条子当场消失，跳过行为不变 |
| G06 | 从「标记哪些类别」返回「跳过设置」 | 「已勾 N / 10 类」的副标题当场更新（不用退出页面） |
| G07 | 关掉「标出精彩时刻」 | 进度条上不再有蓝色三角，但「看点」卡片里的精彩时刻条目**仍在**；重新打开后三角回来 |
| G08 | 播放途中把三档、条子、三角**全关掉** | 已经画在进度条上的条子与三角当场消失，不留残余色块；全部打开后回来，且不必重进页面 |
| G09 | 全关状态下看日志 | **没有任何** `SponsorBlockApi` 请求（判据见 §十一）——三个开关都是关的时候不该再为它发请求 |

## 十一、H 组：第一次进视频就要有数据（exp.6 新增，约 4 分钟，主力）

这一组验的是「有概率加载不出来」那条报障。**每一条都要在换视频 / 换 P / 冷启动之后，第一次进入时报出结果**——
重进才算正常的话，等于没修好。

| 编号 | 怎么做 | 应该看到 |
| --- | --- | --- |
| H01 | 冷启动应用，第一次打开 `BV1oFxX6VEJP`（片头 `intro` 0~18 秒，档位里「片头」要设成自动） | 进度条 0~7% 处有一条 `intro` 色条，播到 18 秒跳走；**不用退出重进** |
| H02 | 同上，但走「从推荐流点进去」而不是从历史记录进 | 结果一样：第一次进来就有条子 |
| H03 | 播 `BV13yW16VEGT`，进入后立刻退到详情页再进（不清后台） | 两次都能画出条子；第二次不重复出现「正在查询」类日志之外的异常 |
| H04 | 断网 10 秒再恢复（飞行模式开关一次），期间进入一个带标注的视频 | 恢复后**15 秒内**自动补上条子（不需要退出去重进）；日志里能看到一次 `查询失败:` 与随后的成功行 |
| H05 | 连续换 5 个视频，每个只停留 5 秒 | 每个视频都在进去后 1~2 秒内出现条子；日志里每个 cid 只有一组 `原始标注 N 条` |

## 十二、判据与日志

抓日志（USB 连着、Debug 或任意包都行，Release 只在 `Logu` 白名单内打）：

```text
adb logcat -s SponsorBlock:V SponsorBlockApi:V
```

对应的关键行：

| 想确认 | 日志里该看到 |
| --- | --- |
| 到底发请求了没 | `SponsorBlockApi` 里请求成功/失败；全关时应当一行都没有 |
| 拿到几条、留下几段 | `cid=… 原始标注 N 条，可跳 M 段，白名单 K 类，总时长 …s` |
| 条子画了没 | `进度条标记 段=N 点=M max=…`，`max` 必须大于 0 才有条子 |
| 询问我为什么没弹 | 该段必须在「询问」集合里（B05/B07 是类别不匹配，不是 bug） |

## 十三、判「不算 bug」的清单

- 随手点的热门视频没有条子——上游没有该视频的标注。
- 番剧里三档没反应——本版设计就是番剧不走社区标注。
- 「询问我」不理它就不跳——这是设计，不是漏跳。
- 一段都没有时界面不显示「暂无社区标注」——已确认不加提示。
- 进度条上只画**本次真会跳**的片段；类别关闭的片段不画。
