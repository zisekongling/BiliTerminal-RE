# 真机回归测试清单（26.10.10 debug 包）

> 用途：发版前在手表上逐条走一遍，并**随每个发行版一起维护到当前版本**（新功能补条目、失效条目就地标注作废，不删历史，编号只增不改）。条目**原样摘自** `docs/review/fix-progress.md` §十一~§三十一 与 §四十二~§四十三（§四十一 正文已归档到 `docs/archive/review/fix-progress-history.md`）的「真机验证清单」，仅做了重新分组与连续编号；每组的来源小节都标在标题里，需要背景（为什么改、取舍）时回原文看。

- 目标版本：`versionName 26.10.10` / `versionCode 2610102`（debug）
- 安装包：`app/build/outputs/apk/debug/app-arm64-v8a-debug.apk`（多数手表）/ `app-armeabi-v7a-debug.apk`（老款 / 32 位）/ `app-universal-debug.apk` / `app-x86-debug.apk`
- 构建：`:app:clean` + `:app:assembleDebug`（clean 后重建，体积可信）；单测 49 类 / 460 个 `@Test`（`app/src/test` 静态计数，发版前跑一遍 `:app:testDebugUnitTest` 确认全绿）

**测前必读**：

1. **新菜单入口对老用户不会自动出现**（`MenuConfig.loadEnabled` 对已存的 `menu_enabled` 直接返回）。某个新功能入口找不到时，先去「菜单设置」里手动打开。
2. **「自动跳过片头片尾」已于 26.10.22 恢复上线，默认关闭**（`player/SkipOpEdPrefs.kt` 的 `FEATURE_ENABLED = true`、`DEFAULT_ENABLED = false`）：设置 → 播放器里**能看到**该开关，但新装/未动过设置的用户**默认是关的**——不主动开启就不跳、不弹引导，这是预期而非回归。存档里显式开过的老用户恢复后**仍然是开的**，与默认值无关（`getBoolean(key, def)` 只在键不存在时用 `def`）。判据永远是 `SkipOpEdPrefs.isEnabled(...)`，别拿 `DEFAULT_ENABLED` 当证据。正向验证看**第 199、200、215 条**（215 已改成正向）。乱跳的三个根因修复见 `docs/review/fix-progress.md` §3.55。
3. **首次启动会先弹一次「隐私说明」**（26.10.09 新增，`needsPrivacyConsent()`）：全新安装、清数据、以及**覆盖安装的老用户**都会弹一次，点「同意」或「不同意」都能进主界面；不选就进不去（`setCancelable(false)`）。详细回归见第 228~231、236 条。
4. 未登录时部分写操作会提示「还没有登录喵~」/「登录凭证已失效，请重新登录」，属预期。
5. 涉及服务端状态的用例（置顶、分组、收藏夹、定时发布）建议在**网页端或另一台设备上复核一次**，避免只看到本地乐观更新。
