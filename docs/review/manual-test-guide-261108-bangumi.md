# 26.11.08 番剧分区页 · 人工验收单（7 条，约 18 分钟）

- 安装包：`app/build/outputs/apk/standard/debug/app-standard-universal-debug.apk`（共存版同路径的 `coexist` 目录，二者代码相同）
- 版本：`versionName 26.11.07` / 对应 commit `620a0e9`（新增番剧分区页：推荐 / 追番 / 索引 + 动态筛选）
- 前置：H03 需要**先不登录**；其余条目游客态即可。H01 的「老用户回填」最好用一台**装过 26.11.06 或更早版本**的设备升级验证
- 设备形态：手表圆屏优先（192～233dp 可用宽度、可用高度约 200dp）；手机方屏可验内容与逻辑，但页签排版与手感要在手表上判
- 回结果：通过写 `- [x]`；不通过留空，并在旁边写一句「看到的是什么」

> 这一页是本版**新增**的：主菜单多了一个「番剧」入口，点进去是一页三个页签（推荐 / 追番 / 索引），索引页顶部多一行「筛选：…」。改动只新增页面与菜单项，**没有改**番剧详情页、追番列表页等既有页面。

## H01 菜单里出现「番剧」，能点开；自己关掉后不再被加回来

- **怎么做**：①主菜单找「番剧」（默认位置在「热门」之后），点开；②点顶栏回菜单（这页是菜单级页面，点顶栏就是回菜单，不用长按）→ 设置 → 内容与浏览 → 菜单设置，把「番剧」拖进「未启用」区并保存；③杀掉应用（多任务里划掉）再打开，看菜单；④回菜单设置把它拖回「已启用」。
- **应该看到**：①菜单里有一项「番剧」，点开进到标题为「番剧」的页面（左上角是朝下的菜单箭头，点它回菜单）；②菜单设置里「番剧」可排序、可关掉；③**关掉后重启不会自己跑回来**（这是刻意做的判据：用户动过菜单配置就不再回填）；④拖回来立即恢复。
- **不算 bug**：**老用户**第一次升级上来时它会**自动补进**菜单（因为旧存档里没有这一项）——这是给升级用户的回填，只发生一次；新装用户默认就有。菜单项的图标与其它「内容区块」一致，不是工具页样式。
- **AI 断言**：`adb shell uiautomator dump` 后菜单页应出现文字「番剧」；关掉后 dump 里不再出现，重启（`adb shell am force-stop <包名>` 后重新打开）仍然不出现；`adb shell run-as <包名> cat shared_prefs/*.xml | grep menu_bangumi_state` 应能读到 `1` / `0`。人判：菜单里位置是否顺手。
- **预计**：3 分钟

## H02 三个页签的内容与选中态，切换不丢已加载的内容

- **怎么做**：进番剧页，依次点「推荐」「追番」「索引」；每个页签先往下滑两屏，再切走、切回；最后看顶栏标题。
- **应该看到**：①三个页签文字三等分排在顶栏下方，**选中的那个是主题色且加粗**，另外两个是次级灰；②「推荐」是一列番剧卡片（标题 + 评分或「xxx万追番」+「全24话」这类更新进度）；③切走再切回时**原来那一屏还在**、没有重新转圈加载；④顶栏标题始终是「番剧」，不随页签变。
- **不算 bug**：三个页签各自独立记「加载到第几页」，所以切回来看到的是你上次滑到的位置；首次进某个页签会转一下圈，属正常。
- **AI 断言**：`uiautomator dump` 里 `tabRecommend` / `tabFollowing` / `tabIndex` 三个节点同一行、宽度接近三等分；切页签后原来列表的子节点数不变（说明没重建）。人判：选中态是否够明显。
- **预计**：2 分钟

## H03 「追番」未登录时的空态能一键去登录，登录回来自动加载

- **怎么做**：①先确认没登录（设置 → 账号与登录 里显示未登录；已登录就退出）；②进番剧页点「追番」；③点空态里的「点我去登录」，用你自己的账号登录；④登录成功后直接返回（不要手动下拉）。
- **应该看到**：②空态文字是「未登录，无法获取追番列表」，下面一行「点我去登录」，**整块可以点**；③点它进登录页；④登录回来自动开始加载，出现你追的番（不需要手动下拉刷新）。
- **不算 bug**：没追过任何番的账号会显示「还没有追番内容～」（与未登录是两句不同的文案）；登录回来后如果网络失败，会变成「追番加载失败\n点我重试」，点它重试即可。
- **AI 断言**：未登录时 `adb logcat -d | grep -i "getFollowingList"` 不应出现（代码里未登录直接不发请求）；登录回来 `onResume` 之后 dump 里列表子节点数 > 0。人判：空态文字在小屏上有没有被截断。
- **预计**：3 分钟

## H04 「筛选」弹窗：分组单选、45 个选项能滚到底、选完立刻换列表并回显

- **怎么做**：点「索引」页签，看顶部那行「筛选：…」；点它，依次进「排序」和「风格」（风格选项最多）两组，各选一个值；每次选完回列表看一眼顶部那行文字与列表内容。
- **应该看到**：①弹窗第一行是「排序：<当前>」，下面每组一行「组名：<当前值>」，没选过的组只显示组名；②点「风格」后弹出一个可滚动的单选列表，**能一直滚到最后一个选项**（45 个左右），当前值带选中标记；③选完弹窗自动关，**列表立刻按新条件重拉**（先清空再出现新结果，不会把两种条件的条目混在一屏）；④顶部那行变成「筛选：<排序名> · <你选的值>」，全选「全部」的组**不显示**，所以这行不会被 9 个「全部」刷满。
- **不算 bug**：点筛选时如果上一轮请求还没回来，App 会**先记下新条件、等那一轮收尾再按新条件重拉一次**（转圈不会中途停掉，最多多等一两秒）——这是 26.11.08 修掉的「筛选行已经是新条件、列表还是旧条件」竞态，属正常等待，不是卡住。筛选条件由接口下发，所以**组名和选项会随 B 站变化**，你看到的组可能不止 9 个、顺序也可能不同；某组一个选项都没有时不会画出来；第一行只显示「筛选：排序名」是正常的（其它组都是「全部」）。
- **AI 断言**：`uiautomator dump` 里筛选入口的 `text` 应包含「筛选：」；选完某个值后能读到该值的中文名（回显成功），且列表第一屏的标题与换条件前不同。人判：弹窗在 192～233dp 宽度上放不放得下、滚到底费不费劲。
- **预计**：4 分钟

## H05 索引翻到底不会「假装到底」，失败能重试

- **怎么做**：①「索引」页签里把条件筛窄一点（例如年份选今年、地区选一个冷门的），然后一直往下滑到不能再加载；②再开飞行模式，下拉刷新一次；③恢复网络，点屏幕上的提示。
- **应该看到**：①滑到最后一页后列表停住、不再转圈、**不重复出现同一批条目**（没有「没有更多了」这句文案，停住就是到底）；②飞行模式下出现**明确失败**：弹「索引加载失败，请重试」，列表区显示「索引加载失败 / 点我重试」，**不会**变成「没有符合筛选条件的番剧～」（把失败当成「没有结果」是错的）；③恢复网络后点「点我重试」能正常加载出内容。
- **不算 bug**：失败后原来已经加载出来的条目会保留在列表里（空态只在列表为空时才盖上来），所以断网时下拉刷新可能只是一条提示、列表没变；到底没有「到底了」文案，是因为手表屏上它会占掉一行。
- **AI 断言**：`adb logcat -d | grep -E "索引加载失败|BangumiIndexApi"` 能读到失败路径；失败时 dump 里应出现文字「索引加载失败」，恢复后该文字消失且列表子节点数 > 0。人判：提示语与转圈有没有互相叠着。
- **预计**：3 分钟

## H06 返回键、顶栏、方向锁定

- **怎么做**：在番剧页分别试：①点顶栏（左上角朝下的箭头那块）；②按设备的返回键 / 侧滑返回；③把手腕转 90°（或系统里允许旋转时旋转设备）；④按设备的菜单键（有的话）。
- **应该看到**：①点顶栏**打开主菜单**（不是返回上一页）；②返回键**回到主菜单**，不残留半屏、不黑屏；③页面**不跟着旋转**（Manifest 里锁了方向），不会因为旋转重建而丢掉当前页签与已加载的列表；④菜单键也回主菜单，不被系统吞掉。
- **不算 bug**：这一页是菜单级页面，所以顶栏是「打开菜单」而不是「返回」；从番剧页进番剧详情后返回，回来仍是原来那个页签与位置。
- **AI 断言**：`adb shell dumpsys activity activities | grep -i "BangumiActivity"` 能看到 `screenOrientation` 生效后的页面状态；`adb shell settings get system accelerometer_rotation` 为 0 / 1 都不应让这页重建（`adb logcat` 里看 `ActivityTaskManager: Config changes` 是否出现）。人判：旋转时有没有闪一下。
- **预计**：2 分钟

## H07 圆屏与表冠：页签不被切、列表能转着看

- **怎么做**：圆屏手表上打开番剧页，看页签那一行与右下角；三个页签各进一次并用表冠滚动列表；再看顶部的时钟与电量是否完整。
- **应该看到**：三个页签完整可读、不被圆盘切掉（44dp 高的那一行在圆内）；列表用表冠能顺畅上下滚，条目不被圆角切；顶栏的时间、电量正常显示，没有被圆盘压住。
- **不算 bug**：圆屏边缘的装饰性留白本来就是圆的；「圆屏列表」缩放效果需在设置里开启，默认关闭时条目不会缩小变淡。
- **AI 判不了**：圆盘切角、表冠手感与滚动顺滑度只能在真机上看/手上判，方屏 AVD 替代不了。
- **预计**：2 分钟
