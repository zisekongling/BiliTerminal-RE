# 关于页「赞赏」收款码 人工验收单（2 条，约 3 分钟）

- 安装包：`app/build/outputs/apk/standard/debug/app-standard-universal-debug.apk`（共存版同源码，用 `app-coexist-universal-debug.apk` 也一样）
- 版本：`versionName 26.11.06`
- 前置：不用登录。路径：顶栏 → 菜单 → 设置 → 关于与帮助 → 关于。
- 回结果：通过写 `- [x]`；不通过留空，并在旁边写一句「看到的是什么」。
- 背景一句话：「赞赏」是这次新加的行，点它会先弹免责声明，点「同意」才用图片查看器打开收款码；原来的「捐赠列表」行已经按你的要求先藏起来了。

## H01 收款码能被手机扫出来

- **怎么做**：关于页点「赞赏」→ 免责声明里点「同意」→ 图片查看器出现收款码 → 拿手机（微信 / 支付宝的「扫一扫」）对着**手表屏幕**扫。
- **应该看到**：手机能识别出收款码并跳转到付款页；双指在手表上放大图片后，近距离也仍然能扫出来。
- **不算 bug**：屏幕小、反光、亮度低导致第一下没扫上，凑近或调亮度再试；图片打开时需要一两秒加载（走的是网络图）。
- **预计**：2 分钟

## H02 免责声明在圆屏上的可读性

- **怎么做**：在 466×466 的圆屏手表上走一遍 H01 的入口，停在免责声明弹窗。
- **应该看到**：四行正文都能看全（需要滚动也可以），底部「取消 / 同意」两个按钮都点得到；点「取消」什么都不发生。
- **不算 bug**：正文需要上下滑一点才能看到最后一行「点「同意」查看收款码」；弹窗高度随屏高自适应。
- **预计**：1 分钟

## 已知限制

- 「捐赠列表」入口当前是隐藏状态（`activity_setting_about.xml` 里 `sponsor_list` 的 `visibility="gone"`），恢复就是删掉那一行属性，页面和点击绑定都还在。
- 收款码地址写在 `strings.xml` 的 `about_donate_url`，换图只改这一处，不用改代码。
