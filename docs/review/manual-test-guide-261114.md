## 3. 测试清单

每条都是「怎么点 → 应该看到什么」。**判不了就写「判不了」并说明卡在哪**（例如模拟器 / 手表型号），别猜。

### 3.1 沉浸式全屏（改动 1）

- [ ] 进封面页 / 设置页 / 视频详情页 / 菜单页 / 收藏夹页 / 评论页：顶栏是否真顶到屏幕最上沿、底部内容是否铺到最下沿。
- [ ] 进播放页：原来底部那条三键导航栏黑边是否消失、画面是否铺满；唤出控制栏后最上一排按钮与被隐藏的状态栏原位有没有互相压住。
- [ ] **返回要几步**：从屏幕左缘内滑 1 次、2 次、3 次分别发生什么（第一次只是把导航栏唤出来，还是直接返回了）。这是最容易「回不去」的地方。
- [ ] 右滑（窗口级滑动返回）是否仍能退出页面。
- [ ] 播放页内：单击唤出 / 收起控制栏、长按倍速、拖进度条、点弹幕都还正常（系统栏隐藏不该抢走触摸）。
- [ ] 「圆屏适配」+「界面边距」同时开着时，列表最后一项是否仍完整可见。
- [ ] 打开「横屏模式」进出页面：导航栏没被重新显示、内容没被顶偏。
- [ ] 在本页把开关关掉 → 导航栏立刻回来、布局恢复；再打开 → 又消失（两个方向都要试）。
- [ ] 进播放页后**先不碰屏幕等 5 秒**：画面会不会自己跳一下。

### 3.2 顶栏灵动岛（改动 2）

- [ ] 逐个页面看胶囊位置与宽度（首页 / 设置页 / 搜索页 / 消息页 / 详情页）——宽度应完全一致。
- [ ] 播放音频后切到别的页面：一直显示「播放中」不跳回时间；图标呼吸看得出是活的但不晃眼。
- [ ] 暂停 → 呼吸立刻停、退回时间；再播放 → 立刻回播放态并重新呼吸。
- [ ] 播放 + 同时下载：主位「播放中」+ 右侧下载小图标；暂停后只剩下载百分比，小图标不闪。
- [ ] 收到新私信 / 新回复：未读数字短暂弹出约 5 秒后自己退回；未读一直 99+ 时**不反复弹**。
- [ ] 未读清零后再收到新消息：能重新弹一次。
- [ ] 有新公告 / 新版本启动：短播一次后不重复骚扰。
- [ ] 插上充电：电量图标变闪电并慢闪；拔掉恢复普通图标；电量低于 20% 变红（有条件的话）。
- [ ] 轮换间隔切 3 秒 / 10 秒：播放态与「时间 + 电量」对称交替，切换时胶囊不跳位；切回「不轮换」→ 事件一直占着。

- [ ] 「设置 → 界面与外观 → 布局适配」里**没有**第二个灵动岛开关；搜索「未读」「轮换」能跳到灵动岛设置页并高亮。

- [ ] 圆屏表（宽 ≤ 232dp）：胶囊按 31% 封顶、不被圆盘切角；长标题用省略号截断而不是把胶囊撑高。

### 3.4 SponsorBlock（改动 6）

> **先确认三道门，否则「什么都没看到」是正常的**：① 设置 → 播放器 →「自动跳过」里的档位**默认是「关闭」**，关闭时一个第三方请求都不发；② 只有**被观众标注过**的投稿才有数据（绝大多数视频没有标注，`原始标注 0 条`）；③ 番剧/影视（无 BVID）、直播、本地文件一律不查。三条都满足之后仍然没条子，才算 bug。
> 现场判据（`adb logcat -s` 或应用内日志页搜 `SponsorBlock`）：`cid=… 原始标注 N 条，可跳 M 段，白名单 K 类，总时长 …s` 与紧跟着的 `进度条标记 段=M 点=P max=…`。N=0 是没数据；N>0 且 M=0 看白名单是不是没覆盖该类别；M>0 而 `max=0` 说明时长还没就绪。

- [ ] 开档位（如「仅恰饭广告」）播一个有广告标注的视频：进度条**底边**出现琥珀色细条，位置对得上；关档位时完全没有条子。
- [ ] 细条极短（一两秒）时是否仍看得见（保底 2dp），是否挡住高能曲线或拖动热区。
- [ ] 抓到自动跳过后点「不准」：是否**回到被跳过处**、提示里是类别名、这条以后（退出再进）不再跳，同片其他片段仍跳。
- [ ] 「自动跳过」分组底部「清除「不准」记录」：有记录时确认框条数对；清空后被拉黑的那条又跳；没记录时只提示「还没有「不准」记录」。
- [ ] 播一个整片标注（`full`）的视频：顶栏标题前出现主题色胶囊，**不再**弹底部提示；拖回去再放不重复出现；退出重进仍只一个。**胶囊被裁切 / 挡住返回箭头或时钟 / 长标题把胶囊挤没，都算不通过。**
- [ ] 有胶囊后切清晰度 / 切下一 P / 进听视频模式：标题只出现一次胶囊（不能「广告 广告 标题」）；听视频模式的窗口标题与分享标题不带「广告」二字。
- [ ] 有精彩时刻（`poi`）的视频：进度条出现**主题色小三角**（与琥珀色条颜色不同），位置对得上；播完不消失。
- [ ] 「看点」卡片：只有精彩时刻时按钮也出现；精彩时刻排在自带分段之后、只显示「01:15」；点一下跳过去。
- [ ] 点过的精彩时刻当场从列表与进度条消失；同一处重复标注只出现一条；退出再进又都回来（按会话记）。

## 4. 回归重点（这几处最容易连带坏）

1. **播放页弹幕**：本次放宽了时钟步进（改动 5），长视频与短视频共用同一份 `MediaClockSync` / `DrawHandler`，两边都要看一眼。
2. **系统栏隐藏 × 右滑返回**（改动 1）：导航栏没了之后，靠边缘手势返回的 ROM 可能要多滑一次；发现「回不去」立刻记，这比观感优先。
3. **顶栏灵动岛 × 播放器页**：播放器页与短视频页有自己的顶栏、本来就不接灵动岛，别把「播放器页没胶囊」当成 bug。
4. **收藏夹 × 缓存列表**：两者都用整份换 list + adapter 的老套路，收藏夹修了不代表缓存页也修了，缓存页请照旧试一遍翻页。
5. **设置项位置**：灵动岛开关已从「布局适配」搬进「外观 → 灵动岛设置」，别在旧位置找。

## 6. 怎么记录与回报

- 直接在这份文件里把 `- [ ]` 改成 `- [x]`，不通过就写 `- [ ] 失败：<看到什么>`，别另开记录。
- 需要贴图 / 贴日志的，放 `outputs/` 下（已 gitignore），正文里写文件名。
- 要抓日志（崩溃、弹幕时钟、播放器选项）用：

```bash
adb logcat -v time | grep -E "AndroidRuntime|IJKMEDIA|DANMAKU|Inconsistency"
```

- 弹幕时钟相关的异常日志只在偏差超过 500ms 时打，限频 5 秒一次；长时间刷视频没出现这条，基本就可以认为「一跳一跳」这次是真修了。
- 全部过完或卡住时告诉主会话，我把结论并回 `docs/review/fix-progress.md` 与 `docs/review/l2-pending.md`。
