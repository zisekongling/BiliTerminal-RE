## H01 搜索页的翻页提示：出现在进页面时，页数 = 启用的搜索类别数

- **怎么做**：设置 → 搜索设置，确认启用的搜索类别是 5 个（视频 / 番剧 / 专栏 / 用户 / 直播，默认值）；回到菜单进「搜索」。
- **应该看到**：进页面就出现「提示 ←这个页面可以左右翻页喵→（共有 5 页，滑动一下不再显示）」，**不需要先搜一次**；左右滑到第二个类别后提示消失，再退出重进不再出现。
- **不算 bug**：提示盖住整页、点不动是既有设计（`clickable=false`），只能用左右滑动让它消失；关掉某个类别后页数应跟着变成 4。
- **AI 断言**：`adb shell uiautomator dump` 后查 `text_tutorial_pager` 的 text 含「共有 5 页」；`adb logcat -d | grep "已展示页面滑动提示：hint_search"`；`adb shell run-as com.RobinNotBad.BiliClient cat shared_prefs/*.xml | grep tutorial_pager_SearchActivity` 应为 `false`。人判：文案是否被圆角切。
- **预计**：1 分钟

## H02 视频详情页：提示的页数取真实分页数（公开包 2 页）

- **怎么做**：清掉提示存档后进任意视频详情页（`adb shell run-as com.RobinNotBad.BiliClient` 删掉 `tutorial_pager_VideoInfoActivity`，或在「教程管理 → 重置所有页面滑动引导」）。
- **应该看到**：首次进入先弹 `video_main` 教程（若还没看过），关闭教程后出现「（共有 2 页，滑动一下不再显示）」；左右滑到评论区后提示消失。
- **不算 bug**：注入了私有功能（带「演职人员」页）的包应显示 3 页——这是本次改动的目标之一，旧实现写死 3 页，公开包其实只有 2 页；详情页还没加载出内容时提示会稍晚出现（最长约 30 秒），加载完才会显示。
- **AI 断言**：`adb logcat -d | grep "已展示页面滑动提示：hint_video_info"`，括号里的页数应与 `dumpsys` 里 Pager 的页数一致；人判：教程关闭后才出现提示。
- **预计**：2 分钟

## H03 用户主页 / 专栏详情 / 动态详情：各 4 / 2 / 2 页

- **怎么做**：分别进一次「用户主页」「专栏（Opus）详情」「动态详情」。
- **应该看到**：分别出现「共有 4 页」「共有 2 页」「共有 2 页」的提示；滑动一次后各自消失；退出重进不再出现。
- **不算 bug**：这三个页面需要真实内容才能加载出分页，游客态打开可能停在 loading；提示要等分页建好才出现。
- **AI 断言**：`adb logcat -d | grep "已展示页面滑动提示"`，应能看到 `hint_user_info（4 页）` / `hint_opus_info（2 页）` / `hint_dynamic_info（2 页）`。
- **预计**：2 分钟

## H04 教程管理页：5 条页面滑动引导的「通过 / 清除 / 重置」仍然有效

- **怎么做**：设置 → 关于与帮助 → 教程管理，找到「页面滑动引导」分组；对某一条点「清除」，回对应页面；再回来点「通过」，再回页面；最后点「重置所有页面滑动引导」。
- **应该看到**：清除后回页面会重新出现该提示；通过后回页面不再出现；重置后 5 条全部变回「未完成」。
- **不算 bug**：管理页卡片只显示标题与状态，没有「重看」（HINT 不是全屏页，无法重看内容）。
- **AI 断言**：每次操作后 `adb shell run-as com.RobinNotBad.BiliClient cat shared_prefs/*.xml | grep tutorial_pager_` 的键存在与否应与卡片状态一致。
- **预计**：2 分钟

## H05 老用户不被重弹（存档兼容）

- **怎么做**：模拟老用户——`adb shell run-as com.RobinNotBad.BiliClient` 往 `shared_prefs` 里写 `tutorial_pager_SearchActivity=false`（回到应用前先 force-stop），再进搜索页。
- **应该看到**：提示**不出现**（旧存档认作已看过）。
- **不算 bug**：删掉这个键（等价「清除进度」）后应重新出现。
- **AI 断言**：页面控件树里 `text_tutorial_pager` 不存在或 `visibility` 为 gone。
- **预计**：1 分钟
