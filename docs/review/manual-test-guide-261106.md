# 新功能测试手册（26.11.06 测试版 · 普通人版）

> **这份手册是给谁看的**：不用懂代码、不用看日志的人。只要会点屏幕、会看结果，就能照着一条条测。
> **它测什么**：26.11.06 这一轮从兄弟分支移植过来的新功能，加上顺手修的几个毛病。
> **怎么用**：从上往下做，每条做完在 `- [ ]` 里打勾。看不明白的地方先跳过，做完把结果告诉开发者。

## 开始之前

**要准备的东西：**

1. 一台装了 26.11.06 测试包的设备（手表优先，手机也行）。装之前建议先卸载旧版，避免旧设置干扰。
2. 一个能正常登录的 B 站账号（第二、三部分要用；第一部分不用登录）。
3. 能上网的 Wi-Fi；第三部分有两条需要**关掉 Wi-Fi 用移动数据**。
4. 一副能连手机的蓝牙耳机（可选，只有一条要用）。
5. 一张自己手机相册里的普通照片（只有「背景图」那条要用）。

**记结果的方式：**

- 通过：在方框里打 `x`，写成 `- [x]`。
- 不通过：方框留空，在旁边写一句「看到的是什么」，比如「点了没反应」「直接退回上一页」「数字没变」。
- 拿不准：写「不确定」，并说明哪里不确定。

**三条通用提醒（省得白测）：**

1. **设置类改动很多是「下次进入才生效」**，不是点完立刻变。每条都写了要退出再进，别急着判失败。
2. **第一次进某个页面慢一点是正常的**，尤其是老手表；等 3 秒还没反应才算有问题。
3. **网络不好会误伤**：所有「加载不出来」的问题，先换 Wi-Fi 或等网络稳定再复测一次，还是不行才算不通过。

## 第一部分：不用登录就能测（约 25 分钟）

### T01 推荐页能一直往下翻

- **怎么做**：打开 App → 进「推荐」→ 手指一直往上滑，滑过 5～6 屏。
- **应该看到**：内容不断追加，能一直往下看；不会出现「同一批视频反复出现」；滑到底不会卡住不动。
- **不算 bug**：偶尔一条视频在很后面又出现一次（服务端重推），只要不是连着重复就不算。

### T02 换一张背景图

- **怎么做**：设置 → 界面与外观 → 外观设置 → 找到「背景图」→ 点「选择背景图」→ 从相册挑一张 → 退回上一页 → 再随便进几个页面。
- **应该看到**：所有页面背景都变成这张图；退出 App 再进还在；「适配方式」切「填满（裁切边缘）/ 适应（显示全图，留底色）」后画面跟着变；「遮罩强度」切「不遮罩 / 75%」时，75% 下卡片和字更清楚。
- **再试清除**：点「清除背景图」→ 背景恢复成原来的纯色。

### T03 光晕和背景图能同时开

- **怎么做**：接着上一条（背景图别清掉）→ 外观设置里打开「弥散光晕」→ 退出再进来。
- **应该看到**：屏幕边缘/顶部有一层淡淡的主题色光，**同时背景图还在**（不是变成纯色，也不是完全看不到光）。
- **反过来**：关掉光晕 → 背景图仍然在。

### T04 播放器设置页多出来的几项

- **怎么做**：设置 → 播放器 → 长按「内置播放器」那张卡片 → 进入内置播放器设置，往下翻。
- **应该看到**这几项，并且点了能改、退出再进来还是刚才选的：
  - 「长按上下划切换视频」（默认开）
  - 「长按倍速提示尺寸」（默认 100%，可选 80/100/120/150%）
  - 「本人弹幕边框」（默认开）
  - 「自动跳过片头片尾」：点进去是五个选项——关闭 / 仅片头 / 仅片尾 / 片头+片尾 / 询问我
  - 「弹幕缓存上限」（默认 64 MB，可选 关闭 / 16 / 32 / 64 / 128 MB）

### T05 存储空间页

- **怎么做**：设置 → 缓存与下载 → 存储路径 → 点「存储空间」。
- **应该看到**：图片缓存、临时文件、更新安装包、可用空间四个数字；三个清理按钮。
- **试一下**：点「清理图片缓存」——没东西可清时应该提示「没有需要清理的内容」；有东西时先问一句再清，清完数字变小。
- **注意**：这一页只清图片缓存和临时文件，**不会动你下载的视频**。清完视频还在就是对的。

### T06 清晰度能按 Wi-Fi / 移动数据分开设

- **怎么做**：设置 → 播放器 → 下方的「清晰度设置」。
- **应该看到**：除了原来的清晰度列表，多出「Wi-Fi 默认清晰度」和「移动数据默认清晰度」两行，都能选「跟随默认 / 360P / 720P…」。
- **试一下**：把 Wi-Fi 那行选成 720P，返回后该行显示「当前：720P」。
- **真正生效要等第三部分 T28**（要切换网络才能看出来）。

### T07 看一张很长的图

- **怎么做**：找一条带长图/条漫的图文动态（或评论区里的长截图）→ 点图放大 → 上下拖动看。
- **应该看到**：能正常放大、能拖动看完，不白屏、不闪退、不卡死。
- **不算 bug**：放到最大时边缘有点糊，这是为了省内存故意降的清晰度。

### T08 设置搜索能搜到新功能

- **怎么做**：设置首页的搜索框，分别搜「背景图」「本人弹幕边框」「弹幕缓存」。
- **应该看到**：都能搜到对应条目，点一下能直接跳到那个设置项。

## 第二部分：登录后测（约 40 分钟）

> 这一部分都要先登录。登录后如果提示「登录凭证已失效」，重新登录一次再继续。

### T09 连播队列（播放页多了个「连播」按钮）

- **怎么做**：打开一个多 P 视频（比如赛事回放、番剧合集）→ 进播放页 → 控制栏里找「连播」按钮 → 点它。
- **应该看到**：弹出四个模式：顺序 / 倒序 / 随机 / 单曲。
- **试一下**：选「顺序」→ 让它播完 → 自动进下一个；选「单曲」→ 播完重复当前这一条。
- **再试一下**：退出播放页再回来，模式还是刚才选的那档。

### T10 主菜单的「继续播放」

- **怎么做**：随便看一个视频，看到 30 秒以上 → 退出播放页 → 回到主菜单。
- **应该看到**：主菜单最上面多出一项「继续播放」。
- **点它**：从上次退出的位置接着播（差几秒是正常的）。
- **不算 bug**：看的不足 5 秒、或者超过 7 天没看，这项就不出现——这是故意的。

### T11 自己发的弹幕有边框

- **怎么做**：播放一个视频 → 发一条弹幕 → 等它出现在屏幕上（或者退出重进这个视频）。
- **应该看到**：自己发的那条弹幕外面有一圈主题色边框，别人的没有。
- **再试一下**：去设置里把「本人弹幕边框」关掉 → 重新进视频 → 自己的弹幕没有边框了。
- **不算 bug**：未登录、或者这条弹幕是匿名/认不出是谁发的，就不会有边框。

### T12 点带时间的弹幕能跳进度

- **怎么做**：找一个弹幕里有人发「01:23」这种时间的视频 → 在画面上点那条弹幕。
- **应该看到**：进度直接跳到 01:23。
- **不算 bug**：点「1080P」「1:2」「99:99」这类不是时间的弹幕，什么都不会发生。

### T13 片头片尾的五档设置

- **怎么做**：打开一集有片头/片尾的番剧 → 设置里把「自动跳过片头片尾」选成「询问我」→ 从头播，等播到片头快结束。
- **应该看到**：弹一次确认框问你要不要跳过；**你不点它就不会跳**；同一集只问一次。
- **再试**：改成「片头+片尾」→ 自动跳过去，屏幕下方留一个「撤回」，点一下回到跳之前的位置。

### T14 番剧每集进度

- **怎么做**：看番剧第 2 集，看到一半退出 → 再从番剧页点进第 2 集。
- **应该看到**：从上次的位置接着播，不是从 0 开始。
- **注意**：第 3 集应该是从头播，别把「每集各记各的」当成 bug。

### T15 评论加载更稳

- **怎么做**：打开一个评论很多的视频 → 进评论区 → 来回切页、连续下拉刷新几次。
- **应该看到**：评论正常加载，不重复出现同一条，不闪退，也不会突然变成空白。

### T16 评论点赞/删除，返回列表也同步

- **怎么做**：在评论列表里点开某条评论的详情 → 给它点赞 → 返回列表。
- **应该看到**：列表里那一条也显示已赞（不用再点一次）。
- **再试**：删掉自己的一条评论 → 返回列表，那条应该消失。

### T17 回复评论时没有「加图」按钮

- **怎么做**：在评论区点「回复」某条评论（楼中楼）→ 看输入框旁边。
- **应该看到**：**没有**图片按钮。
- **对照**：发一条普通评论（不是回复别人）时，图片按钮在。
- **为什么**：B 站楼中楼本身不支持带图，以前是选完图才失败，现在直接不给入口。

### T18 收藏夹里能搜索

- **怎么做**：我的 → 收藏夹 → 进一个视频比较多的收藏夹 → 顶部筛选条里点「搜索收藏夹」→ 弹框里输入关键词（标题或 UP 名）→ 确定。
- **应该看到**：只显示匹配的视频；点「清除搜索」后恢复全部。
- **不算 bug**：搜不到时提示的是「没有匹配的收藏内容」，不是「收藏夹是空的」。

### T19 「全部收藏」

- **怎么做**：我的 → 收藏夹（收藏夹列表页）。
- **应该看到**：列表里多出一项「全部收藏（最近）」→ 点进去是所有收藏夹的视频合在一起（按最近收藏排序），顶部还会写「共 N 条，来自 M 个收藏夹」。
- **不算 bug**：同一个视频同时收在两个夹里，会出现两次——这是合并的正常结果。

### T20 收藏夹批量下载

- **怎么做**：收藏夹里长按一条视频 → 菜单里选「多选」→ 勾几条（不超过 20 条）→ 点「下载」→ 选清晰度。
- **应该看到**：提示已加入下载；去下载列表能看到这些任务。
- **注意**：一次最多下载 20 条，多勾的会被跳过——弹窗里会写「另有 N 条…已跳过」。

### T21 历史记录里能搜索

- **怎么做**：我的 → 历史记录 → 顶部筛选条里点「搜索记录」→ 弹框输入关键词（标题或 UP 名）→ 确定。
- **应该看到**：列表只剩匹配的记录，并且提示里写明了「仅在本页已加载的 N 条记录中搜索」。
- **不算 bug**：更早的历史搜不到——B 站没有给搜索接口，只能搜已经加载出来的。

### T22 历史记录多选删除

- **怎么做**：历史记录里长按一条 → 菜单里选「多选删除」→ 在弹出的勾选面板里勾几条 → 点删除。
- **应该看到**：被勾的从列表消失；清掉搜索词后也不会「复活」。

### T23 动态卡片上的「评论」入口

- **怎么做**：主菜单进「动态」→ 看每条动态卡片底部的操作栏。
- **应该看到**：有一个「评论」和数字；点它直接进这条动态的评论。
- **不算 bug**：没有人评论的动态只显示「评论」两个字、没有数字，是正常的。

### T24 定时发布的「自定义时间」

- **怎么做**：发动态 → 选定时发布 → 「自定义时间…」→ 输入一个时间。
- **应该看到**：
  - 输入「现在 + 3 分钟」→ 提示太早（要求至少 6 分钟后）；
  - 输入「现在 + 8 天」→ 提示太晚（最多 7 天）；
  - 输入合法时间（比如明天中午）→ 按钮上显示预定时间，能正常发出去。

### T25 私信能发表情

- **怎么做**：消息 → 打开一个私信对话 → 输入框旁边找表情按钮 → 点开面板 → 选一个表情。
- **应该看到**：表情插入到光标位置，发出去后对方（或自己这边）能看到表情图案。

### T26 用户主页显示性别和 IP 属地

- **怎么做**：打开任意一个用户的主页。
- **应该看到**：昵称下方有性别和 IP 属地（比如「男 · 广东」）。
- **不算 bug**：对方没公开或者 B 站没给这两项时，就不显示——不是 bug。

### T27 关注/粉丝列表里的「互关」标记

- **怎么做**：我的 → 关注 或 粉丝 → 看列表里每个人。
- **应该看到**：互相关注的人旁边有「互关」标记；只有单向关注的人没有。

## 第三部分：需要特别条件（约 20 分钟）

### T28 移动数据和 Wi-Fi 各用各的清晰度

- **前提**：手机上先设好——Wi-Fi 默认清晰度 = 720P，移动数据默认清晰度 = 360P。
- **怎么做**：连 Wi-Fi 播一个视频，看起播清晰度 → 关掉 Wi-Fi 用移动数据播同一个视频，再看。
- **应该看到**：Wi-Fi 下 720P，移动数据下 360P。
- **注意**：开了 VPN 或者系统识别不出网络类型时，会按「跟随默认」走，这时两边一样是正常的。

### T29 蓝牙耳机能切下一条

- **怎么做**：连蓝牙耳机 → 播放（最好是有连播队列的多 P 视频/合集）→ 按耳机上的「下一首」。
- **应该看到**：按连播队列切到下一条；按「上一首」回到上一条。
- **注意**：只有一条视频时按了没反应是正常的。

### T30 别的 App 抢声音时会暂停

- **怎么做**：正在播放 → 用另一台手机给自己打电话（或打开别的音乐 App 播放）。
- **应该看到**：我们的播放自动暂停。
- **然后**：电话挂断 / 别的 App 停掉之后，**不会自动接着播**，需要手动点一下播放——这是故意的设计，不是 bug。

### T31 直播弹幕停留更久

- **怎么做**：先在 设置 → 播放器 → 长按「内置播放器」里，把「直播弹幕停留倍率」调成 3.0x → 回主菜单进一个直播间，看弹幕。
- **应该看到**：弹幕在屏幕上待的时间明显变长（默认 2.0x）。调回 1.0x 会更快。
- **注意**：这个只影响直播，不影响录播的「弹幕速度」。

### T32 长按后上下划切视频

- **怎么做**：播放一个有多 P 或合集队列的视频 → 手指长按画面（会进入倍速）→ **保持长按**向上划。
- **应该看到**：切到下一条；向下划回到上一条。
- **不算 bug**：只有一条视频时划了没反应；手指横向偏移太大时不会切（怕和横滑调进度打架）。

### T33 长按倍速提示能变大变小

- **怎么做**：设置里把「长按倍速提示尺寸」设成 150% → 回播放页长按画面。
- **应该看到**：长按时出现的「x 3.0」提示明显变大；设成 80% 会变小。

### T34 老设备自动降档（可选，只有低端手表要测）

- **怎么做**：找一台配置较低的手表，**不要手动设清晰度**，直接播一个视频。
- **应该看到**：起播清晰度比较保守（低端机 360P 左右），同屏弹幕行数也更少，但播放更流畅。
- **注意**：如果你之前手动设过清晰度，会以你设的为准——这是设计。

## 已知限制（测了「不对劲」也不算 bug）

1. **从主菜单「继续播放」进去时，「下一个」可能不能用**：这条路进播放器时播放列表还没加载完，队列会被丢掉。想切下一条请从视频页正常进入。这是已知项，本轮没修。
2. **历史搜索只搜「已加载的」**：翻得越深搜得越多，但不可能搜到没加载过的记录。
3. **「全部收藏」可能有重复**：同一个视频在多个收藏夹里就会重复出现。
4. **未登录不记进度**：不登录也能看，但观看进度和「继续播放」不会保存（服务端没记录）。
5. **直播清晰度不跟 Wi-Fi/移动数据分档**：直播间清晰度还是走它自己那套。
6. **背景图第一次显示可能慢半拍**：老设备上第一次解码要几百毫秒，属正常。
7. **大图放到最大有点糊**：长图是分块加载的，边缘会降清晰度省内存。
8. **新设置项对老用户不会自动变**：比如片头片尾，以前关着的升级后还是关着（会自动迁移成「关闭」），需要自己打开。

## 发现问题怎么报

一条好的问题描述包含五样东西，缺一样开发就得回来问：

1. **设备**：什么手表/手机、系统版本（设置 → 关于 里能看到）。
2. **App 版本**：26.11.06（测试版）。
3. **你做了什么**：按顺序写，比如「设置→播放器→长按内置播放器→点本人弹幕边框→退出→进视频」。
4. **你看到什么**：原话，比如「开关点了没变」「直接退回主菜单」「卡了 5 秒」。
5. **你本来期望什么**：对照本手册里那条「应该看到」。

有截图或录屏最好附上。**别只说「不行」**，那样没法查。
