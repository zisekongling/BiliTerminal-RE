## H01 私信输入框不再被右侧图标盖住（反馈 #157）

- **怎么做**：消息 → 任一会话进私信页 → 点输入框，打一句 20 字以上的话（长到要换行）
- **应该看到**：提示语与打出来的字**完整可见**，到右侧三个图标（表情 / 图片 / 发送）左边就换行，不再压到图标底下；三个图标位置不变，表情面板能打开、发送能发出去
- **不算 bug**：输入框长到约 4 行后内部自己滚动（`maxHeight 128dp`）是原有行为
- **AI 断言**：半自动——人判重叠与否；机器可补一半：`uiautomator dump` 里 `msg_input_et` 的 `bounds` 右边缘应 **小于** `emote_btn` 的 `bounds` 左边缘（改前两者重叠）
- **预计**：1 分钟

## H02 复制文本页精确调整时能看见选中的是哪一段（反馈 #158）

- **怎么做**：视频详情页长按一条评论 → 操作面板选「复制文字」进复制文本页 → 手指点下面「起始下标」输入框，把起始改成 `0`、结束改成 `5`
- **应该看到**：正文里 0~5 这一段**有底色高亮**，且焦点在下标框里时也一直看得见；点回正文时高亮交还给系统原生选区（颜色一致，不出现两层深浅不一）
- **不算 bug**：起止相等 / 下标非法 / 超出长度时不高亮（刻意只清不画）；自绘底色与系统选区可能差 1px 边界
- **AI 断言**：人判：底色在不在——`uiautomator dump` 读不到颜色，机器做不到
- **预计**：1 分钟

## H03 长按整条评论 / 楼中楼都弹操作面板，不再误进详情页

- **怎么做**：视频详情页评论区，分别长按 ①昵称 ②时间 ③整条卡片右侧空白 ④楼中楼卡片里的空白处
- **应该看到**：四处都弹「操作面板」（内含「复制文字」等），**不跳到评论详情页**；面板里对楼中楼**没有**「置顶 / 取消置顶」这两项
- **不算 bug**：设置里把长按面板关掉后回到旧行为（长按正文只复制、不弹面板），这是刻意保留的开关
- **AI 断言**：人判：弹的是面板还是跳了页（手感 + 画面）。机器只能补一半：`adb logcat -s "MsgUtil>showMsg"` 里无异常提示
- **预计**：2 分钟

## H04 合集续看：标记与定位（复检，实现已换成 main 那套）

- **怎么做**：登录 → 打开任一台合集（视频详情页的「合集」入口或 UP 主合集）→ 看列表当前停在哪一集、哪一集带标记 → 播第 5 集 → 返回合集详情页
- **应该看到**：列表**自动停在**第 5 集附近，第 5 集标题前有「[上次看到]」；只滚一次，不会来回跳；从没播过的合集停在顶部、无标记
- **不算 bug**：合集详情页停留在返回栈里时，回来是 `onResume` 重新定位，可能有一下轻微跳动；自己滑到第 20 集后接个电话回来**不该**被拽回第 5 集（若被拽回，是真 bug）
- **AI 断言**：半自动——`uiautomator dump` 里带「[上次看到]」的条目的 `bounds` 应落在屏幕可视区内；标记与滚动是否「自然」仍需人判
- **预计**：2 分钟

## H05 从「请选择分页」/ 播放器内换集起播也算续看

- **怎么做**：接上一条——从同一合集里点「请选择分页」进去，选第 7 集起播；再在播放器里点选集卡片换到第 8 集；退出回合集详情页
- **应该看到**：标记落在**第 8 集**（改前这类入口完全不记录，仍停在第 5 集）
- **不算 bug**：下载后从本地播放不写记录（刻意，避免本地文件污染合集的在线进度）
- **AI 断言**：人判：标记停在哪一集
- **预计**：2 分钟

## H06 没有 id 的合集（收藏夹虚拟合集 / UP 主投稿队列）不会串集

- **怎么做**：从收藏夹的虚拟合集或 UP 主投稿队列里连续播两三个视频 → 再从**另一个**合集进详情页
- **应该看到**：另一个合集**不会**被错误标成「上次看到」某个根本不在它里面的视频；回到刚才那个队列里标记正常
- **不算 bug**：这类拿不到 `ugc_season.id` 的场景只有一条**全局**降级记录，跨多个无 id 合集来回播时精度有限，只在「那一集仍在本合集内」时才采用
- **AI 断言**：人判：有没有标到不在本合集的条目上
- **预计**：2 分钟

## H07 属于合集的多 P 视频，选集卡片里有「进入合集」

- **怎么做**：从合集里点开某一集（它本身是多 P 投稿）→ 播放器里点选集卡片
- **应该看到**：卡片里多出「进入合集」一行，点了能进该合集的详情页；在这个真实多 P 视频里换 P（切别的分 P）时这一行**不会被清掉**
- **不算 bug**：不是从合集进来的视频没有这一行（刻意）
- **AI 断言**：人判：这一行在不在、点了去哪
- **预计**：1 分钟

## H08 「顶栏高度」设置项正常出现且真的生效

- **怎么做**：设置 → 界面与外观 → 找「顶栏高度」这一项 → 改成 `40` 之类明显不同的值 → 回首页看顶栏
- **应该看到**：设置项按正常顺序排在开关之后、点开能输入数值并保存；回到首页顶栏**高度真的变了**（不是只出现一行不起作用的输入框）
- **不算 bug**：`0` 表示「跟随内容」、等于改动前的默认高度，这是设计语义
- **AI 断言**：半自动——`uiautomator dump` 读得到「顶栏高度」标题与输入框的 `bounds`；顶栏变没变只能人看
- **预计**：1 分钟
