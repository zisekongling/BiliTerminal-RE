# 消息页「私信列表」玻璃质感 人工验收单（3 条，约 5 分钟）

- 安装包：`app/build/outputs/apk/standard/debug/app-standard-universal-debug.apk`（共存版同源码，用 `app-coexist-universal-debug.apk` 也一样）
- 版本：`versionName 26.11.09`（`appVersionDate`）/ 改动基于 commit `6532288c`
- 前置：**需要登录**（私信列表要有会话才有卡片可看，随便有两个互关或历史会话即可）；「设置 → 外观设置」里**打开玻璃质感**（默认关），主题用默认的暗色即可；「弥散光晕」开不开都行。
- 回结果：通过写 `- [x]`；不通过留空，并在旁边写一句「看到的是什么」。
- 背景一句话：消息页顶部那四张入口卡本来就有玻璃质感，只有下面「私信列表」的用户会话卡一直是不透明深灰板；现在应该和顶上四张同一种材质。

## H22 玻璃开时，私信会话卡变成玻璃

- **怎么做**：打开玻璃质感 → 进「消息」页 → 看「私信列表」里的会话卡（头像 + 昵称 + 最后一条消息那一行）。
- **应该看到**：会话卡是**半透明**的（页面背景能透出来），并和同一屏顶部「回复我的 / @我 / 收到的赞 / 消息设置」四张卡是同一种材质、同一种圆角。
- **不算 bug**：卡片仍是约八成不透明，昵称与摘要小字照样看得清；没开背景图时「透出来」的只是底色，所以变化比开了背景图时更细。
- **预计**：1 分钟

## H23 玻璃关时，必须和以前一模一样

- **怎么做**：「设置 → 外观设置」关掉玻璃质感 → 重新进「消息」页。
- **应该看到**：会话卡是**不透明的深灰板**、没有亮边、圆角看起来略圆（12dp），卡片底下有一点点淡阴影。跟升级前完全一样。
- **不算 bug**：无
- **预计**：1 分钟

## H24 卡片交互没被改坏

- **怎么做**：在「私信列表」点任意一张会话卡；再回列表长按任意一张卡（如该入口支持长按）；顺带试一下表冠 / 上下滑动列表。
- **应该看到**：点卡进入对应的私信会话；按住时有水波纹反馈（玻璃开 / 关都要有）；列表能正常滚动、不出现整页闪烁或错位。
- **不算 bug**：按下水波纹是系统的方形涟漪，颜色与玻璃卡片的亮边略有差别（改之前就这样）。
- **预计**：2 分钟

## 已知限制

- 「选好友」页（视频详情的「转发 → 私信」里那一页）复用同一个列表适配器，因此也一起变成玻璃卡；这次没单独为它出验收项，看到它跟着变是正常的。
- 这次只动「私信列表」这一处卡片，消息页顶部的四张入口卡、以及私信会话**详情页**（聊天气泡那一页）都没改——详情页的气泡底色不属于卡片体系，一直是自己的规则。
