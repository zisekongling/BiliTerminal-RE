## H01 徽章出现在对的人旁边

- **怎么做**：主菜单 → 我的 → 关注（或从自己的头像进关注列表）。上下翻一遍，找到你特别关注的人、互关的人、以及普通关注的人各一个。再切到「粉丝」列表看一遍；最后点开任意别人的关注列表看一遍。
- **应该看到**：①自己的关注列表里，特别关注的人昵称旁有金色「特别关注」，互关的人旁有粉色「互关」，两个条件都满足时两个徽章同时出现；②自己的粉丝列表里，你特别关注过的那位粉丝同样有金色徽章；③看别人的关注 / 粉丝列表时，两种徽章一个都不出现。
- **不算 bug**：在用户主页改了「特别关注」状态后返回列表，徽章不会立刻变——列表数据是进页面时拉的，退出重进（或下拉刷新，如果有）后才更新。
- **AI 断言**：登录态下 `adb shell uiautomator dump` 查 `text="特别关注"` 的节点数，应等于该页里自己特别关注的人数；看别人列表时该节点数应为 0。本机无登录态，这一步交人核对。
- **预计**：3 分钟

## H02 金色徽章与两个徽章同排时的观感

- **怎么做**：在暗色和亮色（设置 → 外观 → 颜色模式）两种模式下各看一遍关注列表；找一个昵称很长、同时又是互关 + 特别关注的人，看昵称行。
- **应该看到**：暗色下金色清楚可读；昵称被截断成「…」但不压住徽章，两个徽章不重叠、不换行、不出屏幕；列表上下滚动时徽章不会串到别人那行。**亮色模式是重点**：金色取当前主题的 `GOLD`，只有「彩虹幻境」的亮色表换成更深的 `#E6A800`，默认主题亮色下仍是 `#FFB800`，浅色卡片上可能偏淡——看不清就照实记下来，按你的观感判这一条。
- **不算 bug**：小屏手表上昵称本来就会截断得比较早；特别关注 + 互关同时出现时更明显。
- **AI 判不了**：颜色对比、截断位置与挤压感只能人看。
- **预计**：2 分钟
