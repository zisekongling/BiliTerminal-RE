## H01 方向设置失败不再崩页面（§3.142）

**需要**：一台 Android 8.0（sdk26）手表，越接近复现机越好——本次复现机是 huawei `LEO-DLXXU`，崩在进收藏夹页。

1. 让窗口处于**非全屏**状态：分屏 / 悬浮窗 / 自由窗口（手表上通常没有入口，退化做法是把「横屏」设置打开后再进页面，或在开发者选项里开「强制活动可调整大小」）。
2. 连续进出几个子页：收藏夹、搜索、私信、视频详情。
3. 检查：

- [ ] 不再出现 `java.lang.IllegalStateException: Only fullscreen activities can request orientation`
- [ ] `logcat` 里能看到 `BaseActivity` 的 W 级日志「设置屏幕方向失败（窗口非全屏），按系统方向显示」
- [ ] 页面按系统方向正常显示、能正常返回
- [ ] 全屏状态下进入同样页面，行为与改前完全一致（该设置照常生效）

## H02 下载失败后再也下不动（§3.143，反馈 #136）

**需要**：一台真机 + 登录态；若要验「历史残留清理」，得是**升级上来的**设备（26.11.09 之前留下过失败任务）。

1. 用 26.11.09 之前失败过的那个视频（下载列表里状态是失败 / 红字的那条）：
   - [ ] 打开「下载列表」页后，失败任务的目录残留被清掉（该条不再卡在「已在下载队列」）
   - [ ] 回到视频详情页点下载，**能重新进入队列**（不再只提示「已在下载队列中」）
   - [ ] 这一次能下完
2. 再点一个从没下过的视频：正常下完。
3. 清空缓存 / 杀掉 App 重进：已下载的视频仍显示「已下载完成」，未完成的能继续。
4. 可选（要等线路出问题才有机会看到）：`logcat` 里出现 `DownloadService>下载失败，换备用线路重试（2/N）`，且最终下完。

## H03 关闭表冠适配后的详情页滚动速率（§3.144，反馈 #132）

**需要**：小米 Watch 5（或任意走「系统优先」的手表）。

1. 设置里保持「表冠适配」**关闭**，进视频详情页，转表冠：
   - [ ] 每格滚动距离与**开启**表冠适配时基本一致（改前只有 1/3）
   - [ ] 连续快速转动不打嗝、不重叠加速
   - [ ] 详情页外层与内层（简介 / 评论列表）交替滚动时，不出现「一次转两屏」
2. 顺手看列表页（推荐 / 搜索）是否仍正常（这部分改前就正常，属回归检查）。
3. 若偏慢 / 偏快：调 `RotaryEventPolicy.SYSTEM_FIRST_TARGET_SCALE`（建议 1.1~1.25 区间试）；若打嗝：把 `RotaryEncoderSupport` 里补位那一行的 `smoothScrollBy` 改成瞬时 `scrollBy`。
