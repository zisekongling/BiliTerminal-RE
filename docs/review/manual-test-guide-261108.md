## H01 顶栏灵动岛轮流显示事件，不动时不闪

- **怎么做**：设置 → 界面与外观 → 布局适配 → **单独打开「顶栏灵动岛」**（它在「圆屏适配」下面一条，**不需要开圆屏适配**；两个开关互不影响）。依次制造四种状态：①正常停在首页什么都不做；②播一个视频后按返回键退到后台播放；③缓存里下一个视频让它下载中；④（可选）等电量 ≤20% 或插上充电线。每种状态下盯着顶栏那块 1～2 分钟。然后在**方屏**上（灵动岛开、圆屏适配关）换几个**长短不同**的标题页各看一眼胶囊宽度；最后分别单独关掉「顶栏灵动岛」、以及「开着圆屏适配但关掉灵动岛」各看一次。
- **应该看到**：①没有事件时**恒显示当前时间**（与系统时间一致）；②后台播放时显示「播放中」类文字，连续显示约 30 秒后切回时间约 5 秒，再切回事件，如此往复；③下载中显示下载状态，下载完成后不再一直挂着；④未读 / 低电 / 充电 / 新公告 / 有新版本时**文字前多一枚小图标**（信封 / 电池 / 闪电 / 喇叭 / 更新箭头），电量状态直接显示百分比（如「15%」）、充电时闪电图标**慢闪**——这类突发内容只弹约 10 秒，**不会一直压着播放状态不放**；⑤亮屏、切页、退后台再回前台之后，事件文字**不会被时间冲掉**；⑥**宽度统一**：方屏上不掉圆屏也能用，且**所有页面、所有状态胶囊宽度一致**（72dp，小屏按屏宽 31% 封顶），长标题由省略号截断、不压住标题、不挤出屏；圆屏上同样是这个宽度、不压右侧图标；⑦关掉「顶栏灵动岛」后恢复成普通时钟（**开着圆屏适配也一样**）；开着灵动岛但关掉圆屏适配时依然工作；⑧老用户迁移：升级前就开着「圆屏适配」的账号，进设置页应看到灵动岛**已经是开**（只需看一次，不用重装）。
- **不算 bug**：灵动岛只在顶栏那一小块里滚动文字，长内容会被截断；公告/更新类只在 App 启动那次轮询里出现，退出重进才会再弹；「充电闪电慢闪」只在充电事件那 10 秒里闪，之后胶囊回落成时间。
- **AI 半自动**：`adb shell uiautomator dump` 读顶栏节点文本可验「有事件时出现播放中/下载中」「无事件时是 HH:mm」这两半；**宽度也能读**：同一次 dump 里 `resource-id` 以 `:id/timeText` 结尾的节点，`bounds` 的左右差应恒等于 72dp（density 3.0 的屏是 216px；屏宽不足 232dp 时按屏宽 31% 封顶），换页面、换状态都不该变（26.11.10 已在本机实测四个页面一致）。但「30 秒 / 5 秒的插播节奏」「亮屏回来不被覆盖」「关掉开关后恢复」「充电闪电的闪烁节奏与观感」属于时序与观感，人判。设备上需先打开「顶栏灵动岛」并保持前台。
- **预计**：4 分钟

## H02 再进同一个合集，自动滚到上次看的那一集

- **怎么做**：找一个**分节**的合集（例如某 UP 主的「合集和列表」里分节的），进这个合集点开第 5～8 集里任意一集，看完/直接返回；然后从「我的 → 收藏」或同一个 UP 主的合集入口**重新进这个合集**再看一次。再找一个**只有卡片、不分节**的合集（很多「收藏的合集」是这种）重复一遍。最后随便删掉/找一个记录里那集已下架的合集试一次。
- **应该看到**：①再进合集时列表**自动滚到刚才那一集**，不用手动翻；分节与不分节两种形态都要定位；②那一集已不在本合集时，落在入口视频附近而不是卡在列表顶部；③滚动过程中不出现「先停在顶部、再跳一下」的闪动；④同一个合集进第二次，仍定位到最近一次看的那一集。
- **不算 bug**：只记住最近一次的那一集，不记「看到第几分钟」；清 App 数据后会丢。
- **AI 半自动**：`adb shell uiautomator dump` 可读当前可见列表项文本，判断是否落在目标集上（第①③④条能验）；「两种形态都覆盖」「记录失效回落」需要真实账号里的不同合集，人挑合集点一遍更快。
- **预计**：4 分钟

## H03 「点赞卡片描边」开关关掉后，两处卡片都不再描边

- **怎么做**：设置 → 内容与浏览 → 详情页设置，找到「点赞卡片描边」，先确认它默认是**开**的；随便开一个视频看动作区那排「点赞 / 投币 / 收藏」卡片；关掉开关，回同一个视频看一次；再去动态 / 文章末尾看同一套卡片；最后杀掉 App 重进，检查开关是否仍是关。
- **应该看到**：①开着时卡片外圈有一圈粉色描边；②关掉后视频详情页与文章/动态末尾的卡片**都不再有描边**，卡片底色和文字颜色不变；③重启后开关保持关闭状态；④（可选，手机方屏更方便）浅色主题下关掉描边后，卡片边界仍能分辨。
- **不算 bug**：描边只在动作卡片上，不涉及其他卡片样式；开关默认是开，所以老用户升级后观感不变。
- **AI 半自动**：`adb shell uiautomator dump` 能读设置项开关的 `checked` 状态（验「默认开」「重启后保持」）；「描边有没有、底色变没变」是纯画面，人判。
- **预计**：2 分钟

## H04 浅色主题下表情页标题栏不再是一条黑带

- **怎么做**：设置 → 界面与外观 → 外观设置 → 配色（颜色模式），切到「知乎蓝」或其他**浅底**主题；进任意视频详情 → 表情（或从评论输入框进表情页），看一眼页面顶部标题栏。再切回默认暗色主题进同页面看一次。
- **应该看到**：①浅底主题下，表情页标题栏跟着主题底色走，**不再是纯黑一条**；②暗色主题下观感与修复前一致（不要变成灰条或亮条）。
- **不算 bug**：表情页内容区底色仍可能是深色（内容与标题栏不同层，属既有观感）。
- **AI 半自动**：`adb shell screencap` 后取标题栏区域像素值可断言「浅底主题下不再等于 `#FF000000`」；「观感对不对」仍需人扫一眼。
- **预计**：2 分钟
