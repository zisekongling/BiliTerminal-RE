# 搜索「用户」页玻璃质感 人工验收单（5 条，约 6 分钟）

- 安装包：`app/build/outputs/apk/standard/debug/app-standard-universal-debug.apk`（共存版同源码，用 `app-coexist-universal-debug.apk` 也一样）
- 版本：`versionName 26.11.06` / commit `23ef4da`
- 前置：不用登录（H05 除外）；「设置 → 外观设置」里**打开玻璃质感**（默认关），主题用默认的暗色即可；「弥散光晕」开不开都行。
- 回结果：通过写 `- [x]`；不通过留空，并在旁边写一句「看到的是什么」。
- 背景一句话：修之前只有「用户」这个 tab 的卡片是不透明灰板（其它 tab 都是半透明玻璃），现在应该和其它 tab 一致。

## H01 玻璃开时，用户页卡片变成玻璃

- **怎么做**：搜索页搜任意关键词（例如 `原神`）→ 滑到「搜索-用户」页（或先记住视频页的卡片样子）。
- **应该看到**：用户卡变成**半透明**（页面背景能透出来）+ **一圈主题色细亮边**，跟同一时间「搜索-视频 / 番剧」页的卡片是同一种材质。
- **不算 bug**：卡片仍是约八成不透明，小字照样看得清；用户卡的行距比视频卡略高一点（没有投影后视觉高度变化）。
- **预计**：1 分钟

## H02 玻璃关时，用户页必须和以前一模一样

- **怎么做**：「设置 → 外观设置」关掉玻璃质感 → 重新进搜索页 → 搜同一个词 → 到「搜索-用户」。
- **应该看到**：卡片是**不透明的深灰板**、**没有亮边**、圆角看起来比 H01 更圆（12dp）、卡片底下有一点点淡阴影。跟升级前完全一样。
- **不算 bug**：无
- **预计**：1 分钟

## H03 圆角档位跟着走

- **怎么做**：「设置 → 外观设置」把「卡片圆角」切到「圆角」（玻璃质感保持开）→ 重进搜索页搜词 → 到「搜索-用户」。
- **应该看到**：用户卡的圆角变圆，和同屏其它卡片**同一个圆角**（不是一种圆角一种方角）。
- **不算 bug**：切圆角档位需要重进页面才生效（原本就是这样）。
- **预计**：1 分钟

## H04 用户卡还能点开

- **怎么做**：在「搜索-用户」页点任意一张用户卡。
- **应该看到**：进入该用户的个人空间（不是没反应，也不是跳到别的页）。
- **不算 bug**：按下时的高亮是系统的方形水波纹，颜色和玻璃卡片的涟漪略不同（改之前就这样）。
- **预计**：30 秒

## H05 关注分组的成员行（需登录）

- **怎么做**：登录后进「我的 → 关注/关注分组」（或在用户主页长按关注加入分组后回来看）→ 展开任一分组。
- **应该看到**：分组里的成员行与 H01 的用户卡是同一种玻璃卡片；玻璃关掉时恢复成不透明的深灰行。
- **不算 bug**：分组相关的入口在未登录时进不去（会直接退回），这是原本的限制。
- **预计**：2 分钟

## 已知限制

- 「搜索-用户」页卡片与相邻 tab 的**描边绘制位置**差 2px（主题卡片画在内侧，这里的玻璃面板居中画），颜色与粗细一致，正常视距看不出来。
- 这次没动搜索框、搜索历史、搜索建议的底色（它们本来就半透明且跟随亮 / 暗色），所以开关玻璃质感时它们外观不变。
