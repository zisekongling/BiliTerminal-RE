# 26.11.11 自动跳过广告片段（SponsorBlock）人工验收单（S01～S06）

> 对应改动：`docs/review/fix-progress.md` §1「26.11.11 接入 BilibiliSponsorBlock 自动跳过广告片段」。
> L0 已过：`:app:assembleDebug` BUILD SUCCESSFUL；`:app:testStandardDebugUnitTest` 新增两套纯函数单测共 26 例（`SponsorSkipPolicyTest` 17 例、`SponsorBlockApiTest` 9 例），`failures="0" errors="0"`（26.11.11 本机实测）。
> 预计 18 分钟；**需要一个能出网的设备**（要对 `bsbsb.top` 发一次 HTTPS 请求），不需要登录 B 站。

## 这次加的是什么（先理解再看画面）

数据来自第三方志愿者标注服务 BilibiliSponsorBlock：观众手工标出「哪一段是恰饭广告 / 三连提醒 / 片头」，播放器拿到这些区间后像自动跳过片头片尾一样自动 seek 过去，屏幕下方留「撤回」。它**不是 B 站官方数据**，只覆盖标注过的视频（绝大多数视频没有标注，那样就什么都不会发生，也不会报错）。

档位（设置 → 视频播放器 → **自动跳过** 分组里的「跳过广告片段（SponsorBlock）」，默认**关闭**；「自动跳过片头片尾」同组）：

| 档位 | 会跳的类别 |
| --- | --- |
| 关闭 | 什么都不查（**一个请求都不发**） |
| 仅恰饭广告 | `sponsor` |
| 广告 + 自我推广 | 上面 + `selfpromo` |
| 推荐（默认推荐档） | 上面 + `interaction` / `intro` / `outro` |
| 全部类别 | 上面 + `preview` / `filler` / `music_offtopic` / `exclusive_access` / `chapter` |
| 自定义 | 由同组「要跳的类别」子页里勾的那些决定（默认勾的就是「推荐」那五类） |

`poi_highlight`（精彩时刻）**任何档位都不跳**——它是跳转点，不是一段广告。静音型（`mute`）与整段视频标签（`full`）本版也不处理。

## S01 默认关闭：不查、不跳、不弹

前置：设置里把「跳过广告片段（SponsorBlock）」留成 **关闭**（新装默认）。

1. 播下面这个有明确广告标注的视频，进度条拖到 **5:00** 附近（广告区间是 5:17～6:27）：`BV1KLgkzzEb1`
   - [ ] 播到 5:17 之后**画面连续往下走**，没有被拽走
   - [ ] 全程没有出现过任何 SponsorBlock 相关提示
   - [ ] 起播、拖动、切集都正常（关闭档等于这个功能不存在）
2. 设置页搜「跳过广告」：
   - [ ] 能搜到「跳过广告片段（SponsorBlock）」这一项，点进去就是那条六档选择
   - [ ] 也能搜到分组名「自动跳过」与子页名「要跳的类别」
   - [ ] 进「自动跳过」组，能看到「自动跳过片头片尾」和这一条上下排在一起（两条互不影响）

## S02 仅恰饭广告：跳一次，能撤回

1. 档位改成 **仅恰饭广告**，回到 `BV1KLgkzzEb1`，拖到 **5:00**，让它自然播到 5:17。
   - [ ] 到 ~5:17 自动跳到 **~6:27**（区间末尾），画面没有卡住、弹幕跟着走（跳完弹幕不是空白）
   - [ ] 屏幕下方出现一条提示，文案是「已跳过广告」，「撤回」按钮可点
   - [ ] 点「撤回」→ 回到 5:17 之前，并且**不会立刻又被拽走**（自己再拖进这段也不会被弹走，只有当集第二次才可能再跳其它段）
   - [ ] 同一次播放里，这一段只跳一次（不会来回跳）
2. 再播一个没有标注的视频（随便点个首页视频）：
   - [ ] 什么都没发生，也没有任何报错弹窗（无标注 = 空表，静默）

## S03 档位改宽：同一集里补跳新类别

1. 档位改成 **推荐**，播 `BV11Kc2zZEDK`，从 **0:00** 开始。
   - [ ] 开头 0～21 秒（`intro` 标注）被自动跳过，提示文案是「已跳过片头」
   - [ ] 提示里的类别名与设置里的档位说明对得上（片头 / 片尾 / 三连提醒等，中文而非英文 ID）
2. 播放中退出去把档位从「推荐」改回「仅恰饭广告」，再回来继续播同一个视频：
   - [ ] 不崩、不重复跳已经跳过的段

## S04 长视频多段 + 与片头片尾共存

1. 档位 **全部类别**，播 `BV1Pb3uzyEmT`（5 段标注，最长 27 分钟），拖到 **7:10** 附近看 437~457 秒那段。
   - [ ] 自动跳过去，撤回正常
   - [ ] 该视频有 **5 段相邻/重叠**的标注（1265s、1270s、1591s、1592s 附近有重叠段）：播到那里**不会连续多次乱跳**、不会跳回已看过的位置
2. 番剧 / 影视（随便一集）：
   - [ ] 番剧**完全不查** SponsorBlock（只有原有的片头片尾跳过），不出现「已跳过广告」
3. 直播、本地视频：
   - [ ] 同样不查、不跳、不报错

## S05 异常与边界

1. 飞行模式（或断网）下播 `BV1KLgkzzEb1` 拖到 5:17：
   - [ ] 正常播放，**没有弹出任何错误**（查不到就当没标注）
   - [ ] 恢复网络后继续播，最多等一分钟这个功能会自己恢复（不需要重启播放器）
2. 换 P / 换集（多 P 视频或番剧连播）：
   - [ ] 换集后上一集的广告区间不会带到新的一集（新一集该跳的照跳，不该跳的不跳）
3. 缓存/历史入口进播放（这些入口原本不带 BVID）：
   - [ ] 能从历史记录里正常起播，广告照跳（内部按 aid 现查一次 BVID），起播没有明显变慢
4. 高能进度条（顺带修的老问题）：
   - [ ] 从历史记录 / 缓存入口进播放页时，进度条上的高能曲线**能显示出来**（改前这些入口拿不到 BVID，曲线是空的）

## S06 自定义档：逐类别勾选

1. 设置 → 视频播放器 → **自动跳过** → 点「要跳的类别」：
   - [ ] 列表里是 10 个类别开关（广告 / 自我推广 / 三连提醒 / 片头 / 片尾 / 前情回顾 / 离题闲聊 / 非音乐段 / 抢先看 / 章节），**没有「精彩时刻」**
   - [ ] 第一次进来时打勾的是「推荐」档那五类（广告 / 自我推广 / 三连提醒 / 片头 / 片尾）
   - [ ] 页底有一行说明，讲精彩时刻不跳、静音型与整段标签本版不处理
2. 只留「广告」一个勾，返回上一页：
   - [ ] 档位那一行自动变成「自定义」（不需要自己再去选档位）
   - [ ] 回到 `BV11Kc2zZEDK` 从头播：`intro` 那 21 秒**不再**被跳（因为只勾了广告），画面连续
   - [ ] 回到 `BV1KLgkzzEb1` 播到 5:17：广告那段照跳
3. 再把「片头」也勾上，返回同一集继续播：
   - [ ] 不用重启播放页，重新进这一集时片头开始被跳过
4. 把所有勾都取消：
   - [ ] 档位仍是「自定义」，但什么都不跳（等于临时关掉）
5. 在勾选页停留不动直接退出播放器再重进设置：
   - [ ] 勾选保留（存的是布尔项，不随档位重置）

## 判据

- **该跳的跳、不该跳的不跳**是主要判据；提示文案里的类别名必须是中文。
- 只要出现「跳完后又弹回去」「同一段反复跳」「无标注的视频也弹提示」，就是 `sponsorDecider` 的 handled / 撤回判定出了问题，先看 `SponsorSkipPolicy.buildSegments` 的区间过滤与 `SkipDecider.applyLoaded` 的 `segmentsChanged` 语义，别先怀疑网络。
- 「跳完弹幕空白」属于弹幕链的问题（`DanmakuStreamLoader`），不是这个功能引入的，但要记下来，因为 seek 走的是同一条 `seekToPosition`。
