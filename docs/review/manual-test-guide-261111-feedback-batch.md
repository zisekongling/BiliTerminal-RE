# 26.11.11 反馈批次人工验收单（P01~P42）

> 本批改动来自控制台反馈 26.11.11 一批 19 条（需求口径 [`docs/specs/feedback-261111.md`](../specs/feedback-261111.md)，实现落点见该文 §9）。
> **L0 已过**：26.11.11 本机 `:app:assembleDebug`（standard / coexist 双 flavor）+ `:app:testStandardDebugUnitTest --rerun` = 218 suites / 2369 tests / 0 失败 0 错误。
> 本机没有手表 / 模拟器，下面所有项目都是 **L2 待人工**：结论只能靠看画面 / 听声音 / 判手感。
> 全局前置：装 Debug 包（普通版或共存版均可）；需要登录态的项目已单独标注。打勾请写日期与机型。

## 一、播放器（反馈 #117 / #135 / #139② / #143）

| 编号 | 步骤 | 期望 | 结果 |
| --- | --- | --- | --- |
| P01 | 设置 → 播放器 → 手势，确认新开关「返回键退出播放页」**默认开**；进任意视频，播放中按返回键 | 直接回到上一页（详情页 / 首页），不是「什么也没发生」 | ☐ |
| P02 | 把上面那个开关**关掉**，重新进播放器：①在画面上横滑调进度，再按返回键；②从屏幕左缘右滑 | ①不退出（横滑优先，这是有意的旧语义）；②不退出。这两条不是回归 | ☐ |
| P03 | 开关开着，但把播放器设置里的「滑动调进度」关掉，再从屏幕左缘右滑 | 能返回（窗口右滑返回恢复） | ☐ |
| P04 | 点锁定按钮锁屏，等 10 秒以上不碰屏幕 | 解锁按钮**压暗但一直在**（不是 3 秒后消失），一眼能看出「锁了」而不是「卡死」；按返回 / 右滑弹一次提示，连按不刷屏 | ☐ |
| P05 | 网络弱时进入视频（画面在转圈缓冲），按返回键 | 能退出，且不出现「无响应」弹窗 | ☐ |
| P06 | 播到 10 分钟以上暂停，退出播放页，回首页点「继续播放」 | 进度回到 10 分钟那一刻（改前可能回到 0） | ☐ |
| P07 | 播放中长按 / 拖进度条跳到很后面（跨 6 分钟以上），观察画面 | 跳完弹幕仍在且密度正常（改前跳完弹幕就没了）；再切到 2× 倍速、切回 1×，弹幕仍正常 | ☐ |
| P08 | 进播放器后立刻断网（关 WiFi），继续播放并跳转 | 弹幕请求快速失败、不长时间无响应；恢复网络后跳转能补上弹幕 | ☐ |
| P09 | 设置 → 界面与外观，打开「横屏模式」，进播放器；再关掉重进 | 打开时播放器横屏、关掉时竖屏；播放器设置里「默认方向」的默认值提示与之一致 | ☐ |

## 八、本批不做、别当回归报

- 「返回键退出」开关关掉后按返回不退出、窗口右滑也不退出 —— **有意保留旧语义**（反馈 #139 的①③④、#122 私有功能边界等按 spec 不做）。
- 多段视频在**播放器里**仍只播第一段（下载已修，播放侧记遗留，见 spec §9.2）。
- 专栏 `<b>/<i>/标题` 只出文字、不加粗放大（转换器要保持纯 JVM 可单测，样式留待人工决定）。
- 直播弹幕**只发文本**：表情 / 礼物 / 进场特效不做（spec §6 定的范围）。
- 私信发的是**文本「标题 + 链接」**，不是 B 站那种分享卡片：服务端文档写明只接受 `msg_type` 1/2/5，卡片是 7（`bilibili-api-notes.md` §17），所以看到的是纯文本属预期。
- 动态页（`DynamicHolder`）的转发入口**没动**，仍是纯动态转发。
