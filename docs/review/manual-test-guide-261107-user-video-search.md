## H01 排序切换真的改变列表顺序

- **怎么做**：用户主页 → 视频 Tab → 点搜索栏左侧的排序图标 → 选「最多播放」；再点一次选回「最新发布」。
- **应该看到**：列表回到第一页并重排——「最多播放」时第一条应是该 UP 播放量最高的投稿（卡片上「xx万观看」的数字最大）；排序图标在非「最新发布」档位时变成主题色；切回「最新发布」后第一条恢复成最新投稿。
- **不算 bug**：切换瞬间列表会闪一下（重拉第一页）；UP 主只有一条投稿时看不出顺序变化，换一个投稿多的用户。
- **AI 半自动**：`adb shell uiautomator dump` 读第一张卡片文本里「观看」前的数字，切换前后对比；图标是否染成主题色需人判（PNG 着色）。
- **预计**：2 分钟

## H02 关键词搜索：搜得到、搜得空、清得掉

- **怎么做**：在搜索框输入该 UP 某条投稿标题里的两个字，回车或点右侧搜索图标；再把关键词改成不可能匹配的字符（如 `zzzz`）搜一次；最后清空输入框再搜。
- **应该看到**：①有结果时列表只剩匹配的投稿，空态不出现；②不匹配时列表隐藏并显示「没有搜到相关稿件~」；③清空后再搜，列表回到全部投稿，「视频系列」入口重新出现。
- **不算 bug**：关键词是服务端过滤（`space/wbi/arc/search` 的 `keyword`），标题里没有的词也可能匹配到（B 站按标题 / 简介匹配）；搜不到时不会自动退出搜索态。
- **AI 半自动**：`adb shell uiautomator dump` 里查 `emptyTip` 文本；中文输入需要设备装 ADBKeyboard，否则只能人打。
- **预计**：3 分钟

## H03 搜索栏随列表滚动（scroll|snap）

- **怎么做**：在视频列表上向上滑一段再松手；然后下滑回顶部。
- **应该看到**：上滑时搜索栏按滚动量移出屏幕（不遮卡片），松手后归位——要么完全可见、要么完全隐藏，不会停在「半收起」；回到顶部时搜索栏重新出现并可点。
- **不算 bug**：手表用表冠滚动时应该是同样表现；搜索栏收起时点不到它（先滑回顶部）。
- **AI 判不了**：跟手与吸附手感只能人看。
- **预计**：2 分钟

## H04 切换主题 / 字体大小后，输入框里的关键词与列表一致

- **怎么做**：先搜一个能出结果的关键词，然后到 设置 → 外观 换一套主题（或改字体大小），回到该用户主页 → 视频 Tab。
- **应该看到**：输入框里仍是那个关键词，列表也是该关键词的结果（不是全部投稿）；列表最多重新转一次圈。
- **不算 bug**：换主题会重建页面，列表会重新请求一次。
- **AI 半自动**：`adb shell settings put system font_scale 1.3` 触发重建后，dump 输入框 text 与第一张卡片，比对是否仍是筛选后的结果。
- **预计**：1 分钟
