## H05 长按进多选，勾选 / 取消的视觉与操作语义

- **怎么做**：进「缓存 → 下载列表」（或主菜单的下载列表），确保至少 2 条任务；**长按**其中一条 → 进入多选并勾中它；再点另一条；再点一次刚才那条取消勾选；最后按返回键。
- **应该看到**：①顶部出现「退出多选 / 删除(n)」，`n` 随勾选数变化；②勾中的条目保持原亮度、标题前出现「✓ 」，未勾的条目整体压暗、标题前是全角空格占位；③每条只会有一个「✓ 」，来回点 5 次不会叠前缀，取消勾选后条目**真的重新变暗**；④多选态下点条目/长按条目只勾选或取消，不会暂停/恢复任务、也不会离开页面；⑤按返回键只退出多选，仍停在下载列表。
- **不算 bug**：没有「全选」；进多选时会弹一次「点条目勾选，再点『删除』」的 Toast；刷新时已经消失的任务会自动从勾选里剔掉，列表变空会自动退出多选。
- **AI 半自动**：`adb shell uiautomator dump` 可读顶部「退出多选」「删除(n)」与条目标题里的「✓ 」；「压暗 / 变亮」是纯色差，人判。
- **预计**：2 分钟

## H06 删除确认框居中，确认后条目与文件一起消失

- **怎么做**：多选 2 条任务（其中 1 条是已下完、确认过缓存目录里有文件的）；点「删除(n)」看弹窗；先点「取消」；再点一次「删除(n)」并确认。删完去缓存页找同一条视频，再用文件管理器（或 `adb shell ls`）看原来的任务目录是否还在。
- **应该看到**：①确认框在**屏幕中间**弹出，标题「删除下载」，正文「将删除已下载文件（N 项），此操作无法恢复。」，按钮「取消 / 删除」；②点「取消」后列表与文件都不变；③确认后选中的条目从列表消失，**磁盘上的任务目录也真的不存在**（不是只删了数据库记录）；④未选中的任务继续下载 / 保持原状态；⑤结束时退出多选、列表刷新，并提示「已删除 N 条」。
- **不算 bug**：如果文件被系统占用 / 位于只读公共目录，记录会删掉但文件可能仍在，此时提示「已删除 X 项，Y 项文件未能删除」——按提示去文件管理器手动删即可；正在下载的任务会先暂停再删，其他并行任务不受影响。
- **汇总提示有四种形态**（别把多出来的那句当成重复提示）：全成功「已删除 N 条」；只有文件没删干净「已删除 X 项，Y 项文件未能删除」；只有记录删除失败「已删除 X 项，Y 项失败」（复用缓存页同款文案）；**两种都命中时合并成一句「已删除 X 项，Y 项失败，Z 项文件未能删除」**，不是弹两次。
- **AI 半自动**：`adb shell uiautomator dump` 可读弹窗标题/正文与按钮；`adb shell ls "<缓存根>/<任务标题>"` 应返回 `No such file or directory`；`adb logcat -s "MsgUtil>showMsg"` 可读删除汇总原文。确认框是否「居中」需人看（控件 bounds 只能证明大致居中，视觉效果人判）。
- **预计**：3 分钟

## H07 空选提示 / 返回键 / 开启「禁用返回键」后仍不退出页面

- **怎么做**：进入多选后把唯一勾选项再点一次（变成 0 项）；点「删除」；然后按返回键；再去 设置 → 内容与浏览 → 通用偏好 → 交互优化 → 打开「禁用返回键」，回到下载列表，重新进多选，按返回键。
- **应该看到**：①0 项时「删除」按钮变半透明，点它只提示「先选几条吧~」，不弹删除确认框；②多选态按返回键只退出多选，**仍停在下载列表**，再按一次才按系统返回规则处理（默认退出页面）；③打开「禁用返回键」后，多选态按返回键同样只退出多选、不离开页面；退出多选后再按返回键也不退出页面（该开关的既有行为）。
- **不算 bug**：「禁用返回键」开着时其他页面同样按返回不退出，这是该开关的既定语义，不是本功能引入的；如需离开可用顶栏返回或菜单退出。
- **AI 半自动**：`adb logcat -s "MsgUtil>showMsg"` 可读「先选几条吧~」；`adb shell dumpsys activity activities` 可确认返回后栈顶仍是 `DownloadListActivity`；「按钮变半透明」人判。
- **预计**：3 分钟
