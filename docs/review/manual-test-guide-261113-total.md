## T01 下载：分段、拼接校验、失败原因、真实速度、重试

覆盖 `693e05f0`（分段清单下载 + 拼接后校验）、`599611e9`（失败换备用线路，反馈 #136）、`970c86ab`（速度与进度按真实字节）、`88cb3773`（列表多选删除）、`6c0fdc31`（缓存文件夹改独立页面）。

- **怎么做**：要登录。①找一条会分多段的视频（1080P 或番剧某集）下载到底；②再开一条大的，下到一半杀掉 App 再打开继续；③下一条时开飞行模式，看失败提示；④在下载列表长按进多选，删一条；⑤进缓存文件夹再右滑退出。
- **应该看到**：进度条按真实字节走，速度数字与总大小的增量对得上（1024 进制，不是 1000）；失败提示能区分「第几段失败 / 拼接失败 / 校验不过 / 写盘失败」，不再是笼统「下载失败」；断线那条会自动换备用线路重试，仍失败后点重新下载能重新入队；多选删除前弹确认；缓存文件夹是独立页面，右滑退出列表不从顶部重建。
- **不算 bug**：番剧 / 大会员片源没权限时直接失败属正常；只有一段 `durl` 的片子走老路径，看不到「第 N 段」字样；缓存文件夹里的旧任务来自老版本时，字段可能不全。
- **AI 断言**：`adb logcat -d` 里 `DownloadService` 应打印分段数与每段完成；失败时出现 `text_download_fail_segment` 对应中文（「第 %d 段」）。人判：速度数字是否合理、右滑退出后滚动位置是否保留。
- **预计**：5 分钟

## T02 播放器：退不出、弹幕变少、横屏、按钮行

覆盖 `015ba3eb`（反馈 #117 / #135 / #139 / #143）、`d521f5e6`（影子按钮不再共用 Drawable）、`28a0d78e`（按钮自定义：空组格隐藏、「更多」可自摆）、`bd878007`（弹幕窗口独立开关）、`7ae4509a`（PlayData 带 BVID）、`cd3da184` 的「自动跳过」分组归位。

- **怎么做**：播一个长视频，用表冠 / 拖动把弹幕进度条拉很远再看弹幕数量；反复按返回退出播放页；切横屏模式再回竖屏；进播放器设置看底部按钮行图标与「自动跳过」分组。
- **应该看到**：返回能退到上一页（不再卡在播放页）；弹幕拖远之后条数与拖动前一致，不会越拖越少；横屏模式开关真的生效且能切回；底部按钮行四区图标大小一致、居中，影子按钮不糊；「更多」按钮可以自己摆到任意格子，空出来的格子自动隐藏；播放器设置里「自动跳过」把番剧片头片尾和投稿广告放在同一组。
- **不算 bug**：弹幕超过 5000 条默认不自动加载（点弹幕按钮才加载）；直播弹幕延迟属正常；改变底色时影子按钮观感有差异。
- **AI 断言**：`adb logcat -d | grep -E "DanmakuStreamLoader|windowReady"` 每次进入应只有一次窗口装载。人判：图标是否一致、按钮能否摆。
- **预计**：6 分钟

## T03 SponsorBlock：自动跳过广告片段

覆盖 `cd3da184`（默认关闭、五档）与 `SettingSponsorCategoryActivity`（自定义勾选）。逐条做法见 S01~S06。

- **怎么做**：设置 → 播放器 → 自动跳过 → 「跳过广告片段（SponsorBlock）」先选「仅恰饭广告」，播一条带广告标注的视频；跳过后点「撤回」；再把档位改成「推荐」，重新播同一集；最后进「自定义」逐项勾。
- **应该看到**：默认档位下不查、不跳、不弹任何提示；跳到广告段末尾时底部提示「已跳过广告」并带「撤回」，点撤回回到原位置；档位改宽后同一集里会补跳新类别；自定义页可逐项勾选十类，「精彩时刻」不可勾且任何档位都不跳。
- **不算 bug**：数据来自第三方 BilibiliSponsorBlock，没人标注过的视频不会跳；没网或第三方服务不可用时静默不跳、不报错；静音型与整段视频标签本版不处理。
- **AI 断言**：`adb logcat -d | grep -i sponsor` 应能看到类别数量与跳过区间。人判：提示文字、是否真跳、撤回后位置。
- **预计**：6 分钟

## T04 消息 / 私信 / 动态 / 关注（要登录）

覆盖 `d8bccf45`（私信输入框 #157）、`8d44886d`（私信列表玻璃质感）、`f158a6a7`（收到的赞翻页 #150、拦截提示可关）、`b0f99dc6`（视频页转发入口 #133）、`a329f61f`（动态头像灰边）、`7bf18489`（关注页去抬高）。

- **怎么做**：①私信页把文字打到一行末尾再看输入框右侧；②「收到的赞」下拉两次、翻两页；③视频详情页点「转发」，选「发给好友」挑一个好友发出去（要两台设备或让对方看）；④滚一遍动态页与关注列表。
- **应该看到**：输入框文字不被表情 / 图片 / 发送按钮盖住，光标不藏到图标下面；收到的赞翻页不重复、下拉刷新后顺序不乱；转发弹「转发到动态 / 发给好友」两项，发给好友后对方收到一条带视频标题的私信；动态页头像旁不再有灰色描边；关注列表项不再有卡片阴影暗边。
- **不算 bug**：「发给好友」在对方关闭私信 / 未互关时发不出去，会退化成「已复制链接」提示；私信列表的玻璃质感在纯黑主题下差异很小。
- **AI 断言**：`adb shell uiautomator dump` 读私信页输入框 bounds，右边界应小于表情图标的左边界。人判：质感、暗边、转发菜单。
- **预计**：6 分钟

## T05 搜索：清空记录、翻页与刷新

覆盖 `295b616c`（记录一键清空 #148）、`931fc83f`（翻页重复 / 刷新错乱 #123）、`SearchApi.appendSeid`（回退旧接口带 seid）。

- **怎么做**：搜索页搜两个词留下历史，点历史右边的清空按钮；对同一个词下拉刷新两次、再往下翻两页。
- **应该看到**：清空前弹确认，确认后历史清空，输入框与当前结果不受影响；翻页没有整页重复的视频；下拉刷新后按最新排序，旧页不会插到前面。
- **不算 bug**：搜索接口自身偶发重复卡片，去重后某一页可能比上一页条数少；从热搜点进去的搜索不进历史。
- **AI 断言**：`adb shell uiautomator dump` 读结果列表的标题，同屏不应出现完全相同的两条。人判：清空确认框文案、刷新后顺序。
- **预计**：3 分钟

## T06 专栏正文与合集续看

覆盖 `4553174f`（专栏 HTML 兜底 #142）、`e750be5c` / `562b40b7`（合集续看 #151 / #152）。H04~H07 是同一批的细化条目。

- **怎么做**：①打开一篇老 cv 号专栏；②在某合集里看到第 3 集后退出，回该合集页；③再打开一条没有合集 id 的视频（UP 主投稿队列 / 收藏夹虚拟合集）；④从「请选择分页」或播放器内换一集。
- **应该看到**：专栏正文能读出来（不再「无法加载」或整页空白），风控与空正文的提示分开；合集页第 3 集标题前有「[上次看到]」，进合集页自动滚到第 3 集；播放器内换集、分页起播也会更新标记；没有合集 id 的视频不会把别的合集的位置串掉。
- **不算 bug**：被风控的专栏会提示「被风控」而不是正文；合集续看写盘走 `SharedPreferencesUtil.putString`（异步 `apply`），**刚看完立刻断电源式重启**可能丢最后一次写入——旧单 P24 写的「同步落盘」在本版不成立，不算回归。
- **AI 断言**：`adb shell run-as com.RobinNotBad.BiliClient.coexist cat shared_prefs/*.xml | grep collection_resume` 应看到 `collection_resume_last_played_v1` 值为 `aid 制表符 时间戳`。人判：标记文字、自动滚动到第几集。
- **预计**：5 分钟

## T07 评论长按与复制文本选区

覆盖 `7976822b`（长按整条评论 / 楼中楼都弹面板）、`9660e43b` / `673517a0`（复制文本选中区间 #158），以及**出包之后补的一次修复**（2026-11-13 `fix(reply): 长按评论不再误进详情页，详情页也挂整卡长按`——26.11.13-exp.1 的 APK **不含**它，本轮新增的第 ③④ 项要重新出包才能验）。H02 / H03 是细化条目。

- **怎么做**：①长按一条评论正文、再长按它的楼中楼；②进这条评论的详情页，长按**昵称 / 时间 / 卡片留白**（不是正文）；③设置 → 偏好设置 → 关掉「长按打开操作面板」，同时关掉同一页的「长按复制」；④进复制文本页，选一段，再拖下标框精确调整起止位置。
- **应该看到**：长按评论任何位置都弹操作面板，不再误进详情页；**详情页里长按昵称 / 时间 / 留白与长按正文表现一致**（都弹面板，不出现「按正文有、按留白没反应」）；**面板与复制都关掉后**，长按任何位置都不再跳进评论详情页（有复制时有内容的评会直接进复制界面，没有复制时什么都不发生），而同一行末尾的删除键长按照样弹面板；复制文本页首帧、聚焦下标框、拖动调整时都画出选中区间高亮，高亮范围与下标数字一致。
- **不算 bug**：「置顶」只对楼主的根评论出现；超长文本滚动时高亮可能有一帧延迟。
- **AI 断言**：`adb shell uiautomator dump` 长按后应出现面板项文字（回复 / 复制 / 举报 等）。人判：高亮区间与手指位置是否对得上。
- **预计**：3 分钟

## T08 UI 与手感：多选、弹窗、短视频、顶栏

覆盖 `cd704592`（引导符 + 600ms 长按 + 全选全不选 #94 / #121 / #140）、`de0374e8`（弹窗按钮点不中 #125）、`d7ac79d9`（短视频双指平移 #129）、`6501c3f4`（顶栏高度设置）、`5ccb7973` / `22146825`（玻璃胶囊分段条 + 横向拖动）、`5b2c70ac`（设置搜索高亮）、`941acb1a`（长按顶栏震动）、`8829cd67`（灵动岛宽度）。

- **怎么做**：①下载列表 / 缓存列表长按进多选，快速滑动列表，再多选一条、点「全选」；②设置 → 外观 → 「顶栏高度」调到最大，返回再进；③设置页搜索「弹幕」并点结果；④短视频页捏合放大后用两根手指搓动画面；⑤打开任意带「取消 / 确定」的弹窗（如清空搜索记录）；⑥在分段条（首页 / 动态 / 关注页顶部）左右拖动。
- **应该看到**：多选态标题前是「▸」（选中，主题主色）或「›」（未选中，约 70% 灰）；快速滑动不再一滑就误进多选；多选条上有「全选 / 全不选」，按当前可见（含搜索过滤）范围生效；顶栏高度调大后顶栏变高、长按顶栏的手势范围变大，返回重进仍然生效；搜到的目标行短暂高亮；短视频放大后两指搓动能平移看边角，松手不复位、双击才复位；弹窗「取消 / 确定」在 300×300 等小屏上能点中、不被裁掉；分段条可横向拖动切换、行高 40dp、胶囊有玻璃光晕。
- **不算 bug**：引导符在极暗主题下对比度偏低是设计取舍；顶栏高度拉满时个别页面标题会挤成两行；光晕在低亮度屏上不明显。
- **AI 断言**：`adb shell uiautomator dump` 读多选条按钮文字应为「全选」/「全不选」，弹窗按钮 bounds 右边界应 ≤ 屏宽。人判：手感、对比度、光晕观感、平移是否跟手。
- **预计**：6 分钟
