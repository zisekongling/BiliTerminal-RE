## H08 点文件夹打开的是独立页面，且只显示夹内视频

- **怎么做**：进「缓存」，记住当前列表滚动位置；点一个夹内有多条视频的文件夹。
- **应该看到**：①页面整体切到新的一页（不是原地把列表内容换掉），标题变成文件夹名、左上角是返回箭头；②列表只有这个夹里的视频，「下载列表」入口、「新建文件夹」按钮和其它夹的条目都不出现；③夹内分区标题写的是文件夹名 + 「N个」；④底部多选 / 排序 / 搜索三条按钮仍在，且只作用于夹内视频。
- **不算 bug**：夹内页不显示「下载列表」入口（与改动前进入文件夹后一致）；空文件夹会显示「啥都木有~」一行。
- **AI 半自动**：`adb shell dumpsys activity activities` 里栈顶应是 `LocalFolderActivity`（回到缓存页后是 `LocalListActivity`）；`adb shell uiautomator dump` 可读标题与列表条目。
- **预计**：2 分钟

## H09 四条退出路径都不卡，退回后缓存页的滚动位置还在

- **怎么做**：在文件夹页里上下滚到中间，然后分别用这四种方式退出（每次重新进夹再试下一条）：①手表右滑返回；②按返回键；③点顶栏返回箭头；④点列表里那个写着文件夹名的分区标题。
- **应该看到**：①四条路径都能立刻退回缓存页，**退出瞬间不再出现整页卡一下 / 先白一下再画出整张列表**；②退回后缓存页的滚动位置与进夹前一致（不是被拉回顶部）；③缓存页顶部标题是「缓存」、箭头朝下，列表里文件夹与未分类视频都还在；④四条路径行为一致，没有哪一条把整个 App 退掉。
- **不算 bug**：右滑在部分手表上由系统「窗口层」直接处理，转场动画本身可能有一点系统动画时间；判据是**不再出现列表整屏重建的卡顿**，不是要求零动画。开「禁用返回键」后右滑 / 返回键不退出属于该开关既有语义，可先关掉再测。
- **AI 半自动**：`adb shell dumpsys activity activities` 退出后栈顶应是 `LocalListActivity`；`adb logcat -s "ActivityTaskManager"` 可看转场耗时；「卡不卡」与滚动位置只能人看。想量化卡顿可在 `adb shell dumpsys gfxinfo <包名> framestats` 对比进 / 退夹时的掉帧。
- **预计**：3 分钟

## H10 夹里删一条或移出文件夹，退回缓存页能立刻看见变化

- **怎么做**：进夹，长按一条视频 →「删除视频」并确认（或用多选删 1 条）；再进夹，长按另一条 →「移出文件夹」；每次操作完都退回缓存页。
- **应该看到**：①删除后退回缓存页，该条视频不再出现在任何分组里；再进夹也看不到它；②「移出文件夹」后退回缓存页，该条视频出现在「未分类视频」区，夹内不再有它；③退回时缓存页会重新扫描一次（能看到短暂的刷新圈），随后列表与磁盘一致；④删除失败（文件被占用 / 只读目录）时提示失败原因，条目仍在——这是如实反馈，不是 bug。
- **不算 bug**：退回时的重扫会让缓存页重新绑定条目（这是数据真的变了，应该发生）；「移出文件夹」只改归属，不删文件。
- **AI 半自动**：`adb shell ls "<缓存根>/<视频标题>"` 应为 `No such file or directory`；`adb shell run-as <包名> cat <缓存根>/.folders_info.json` 可看归属；`adb logcat -s "MsgUtil>showMsg"` 可读提示原文。
- **预计**：3 分钟

## H11 只在夹内翻看、不动数据，退回时缓存页不重扫

- **怎么做**：进夹，上下滚动翻看、点开一条视频播放几秒再返回、再退出文件夹页（右滑或返回键）。
- **应该看到**：①退回缓存页是**瞬间**的，不出现刷新圈、不出现整张列表重新绑定封面的闪动；②缓存页的滚动位置、搜索词（如果进夹前搜过）、多选 / 排序状态都与进夹前一致。
- **不算 bug**：「更新弹幕」只改弹幕文件、不改列表，退回时不重扫；在夹内下拉刷新只重扫当前页、不置脏，退回缓存页时同样不重扫。
- **AI 半自动**：`adb logcat -s "SwipeRefreshLayout"` 看不到刷新圈日志（无埋点），主要靠看画面；也可用 `adb shell dumpsys gfxinfo` 看退回时是否有一帧整屏重绘。
- **预计**：2 分钟

## H12 从文件夹页长按顶栏切栏目，返回栈里不残留旧缓存页

- **怎么做**：进夹，**长按顶栏**打开菜单（若你的设置里长按顶栏不是「打开菜单」，先到 设置 → 界面与外观 → 顶栏长按 改成「打开菜单」）；点「推荐」（或任意另一个栏目）；到了新栏目后按返回键。
- **应该看到**：①菜单页标题标的是「缓存」（说明文件夹页把 `from` 透传下来了）；②点了「推荐」后，从推荐页按返回**不会再掉回那张旧的缓存页**（应回到打开缓存前的那一层，或按系统规则退出）；③再进「缓存」时是全新的一页，滚动位置回到顶部、文件夹与视频都在。
- **不算 bug**：如果从缓存**顶层**长按顶栏切栏目，行为与改动前一致（旧缓存页被收掉）；切换「当前已经所在的栏目」时不重启页面，属于既有 `killAndJump` 规则。
- **AI 半自动**：`adb shell dumpsys activity activities` 在推荐页按返回后，栈里不应再有 `LocalListActivity`；切栏目后新栈顶应为目标栏目页。
- **预计**：2 分钟
